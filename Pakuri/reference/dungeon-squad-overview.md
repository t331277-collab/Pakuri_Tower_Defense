# Dungeon Squad 전체 시스템 분석 개요

> 목적: Dungeon Squad의 전체 구조, 런 흐름, 전투 후 선택, 스킬 성장, 조작 방식을 하나의 문서로 정리한다.

## 1. 게임 정체성
- 장르: 슈터 디펜스 로그라이크
- 플랫폼: 모바일(Android / iPhone)
- 기본 구조: 적을 막아내는 방어형 전투 + 반복 플레이 기반 성장 + 런 내 조합 빌드 구성

## 2. 상위 구조
Dungeon Squad는 크게 아래 2축으로 나뉜다.

### 2-1. 아웃 게임 성장
- 런 밖에서 진행되는 성장 구간
- 기질 강화
- 가이던스 스톤
- 해금 계열
- 기타 장기 성장 요소

### 2-2. 런 내부 진행
- 런 진입 및 스쿼드 준비
- 일차별 전투 반복
- 전투 후 포로 기반 선택
- 스킬 / 몬스터 / 유물 강화
- 보스 전투
- 런 종료 후 정산

## 3. 런 내부 기본 형식
- 총 4개의 스테이지가 있다.
- 각 스테이지는 11일 단위로 진행된다.
- 5일과 10일에는 중간보스가 등장한다.
- 11일에는 최종 보스와 전투한다.

즉, 한 런은 "일차 진행 → 전투 → 포로 획득 → 선택 → 강화 → 다음 일차" 흐름이 반복되는 구조다.

## 4. 코어 루프
Dungeon Squad의 코어 루프는 다음 순서로 반복된다.

1. 아웃 게임 성장 상태에서 런을 준비한다.
2. 메인 몬스터와 스쿼드를 구성한다.
3. 런 내부에서 일차별 전투를 진행한다.
4. 전투 후 포로와 보상을 얻는다.
5. 포로와 보상으로 스킬, 몬스터, 유물 관련 선택을 한다.
6. 다음 일차로 진행한다.
7. 11일 단위 스테이지를 끝내고 보스를 상대한다.
8. 런 종료 후 아웃 게임 성장으로 다시 돌아간다.

## 5. 전투 후 선택의 핵심 자원
전투 후에는 포로를 중심으로 선택이 발생한다.

- 포로는 강화 포인트처럼 작동한다.
- 포로로 신규 몬스터를 얻을 수 있다.
- 포로로 기존 몬스터의 스킬을 강화할 수 있다.
- 포로로 기존 몬스터의 능력을 덮어쓰는 동화를 할 수 있다.
- 포로 관련 선택은 현현, 공양, 동화, 고문 / 타락 같은 분기로 이어진다.

## 6. 포로 선택 흐름
포로는 전투 후 다음 네 가지 방식으로 활용된다.

1. 현현
2. 공양
3. 동화
4. 고문 / 타락

### 6-1. 현현
- 신규 몬스터를 소환하는 방식이다.
- 소환 실패 확률은 30%다.
- 성공 시 새로운 몬스터를 확보할 수 있다.

### 6-2. 공양
- 기존 몬스터에게 포로를 먹여 강화하는 방식이다.
- 강화 선택지 3개 중 1개를 고른다.
- 미습득 스킬과 강화 선택지를 섞어 3개를 보여준다.
- 액티브 3개, 패시브 3개를 모두 배웠다면 더 이상 미습득 액티브 / 패시브는 나오지 않는다.
- 개별 스킬의 선택지를 다 쓰면 그 스킬도 더 이상 나오지 않는다.
- 후보가 모두 소진되면 무작위 액티브 스킬 레벨이 오른다.

### 6-3. 동화
- 기존 몬스터에 해당 포로의 스탯과 특수 능력을 적용하는 방식이다.
- 기존에 동화했던 능력은 모두 삭제된다.
- 새 포로의 동화 능력치만 남는다.

### 6-4. 고문 / 타락
- 포로를 고문하거나 타락시켜 아군으로 회유하는 방식이다.
- 현재는 추후 추가 예정 콘텐츠다.

## 7. 스킬 시스템
### 7-1. 기본 구조
- 몬스터는 액티브 / 패시브 구조를 가진다.
- 각 몬스터는 액티브 스킬 5개, 패시브 스킬 5개를 가진다.
- 실제로 배울 수 있는 개수는 액티브 3개, 패시브 3개다.

### 7-2. 선택 규칙
- 공양에서 미습득 액티브, 미습득 패시브, 강화 선택지를 모두 섞는다.
- 그중 무작위 3개를 보여준다.
- 액티브 3개를 모두 배웠다면 미습득 액티브는 더 이상 나오지 않는다.
- 패시브 3개를 모두 배웠다면 미습득 패시브는 더 이상 나오지 않는다.

### 7-3. 마스터리
- 액티브 스킬은 강화 선택지 5개 중 3개를 배우면 마스터리 강화가 추가로 등장한다.
- 마스터리는 2가지 선택지 중 1개를 고른다.
- 마스터리는 다른 액티브 진행 상태와 무관하게 해당 스킬 기준으로 등장할 수 있다.

## 8. 플레이어 조작
### 8-1. 전투 중
전투 도중 플레이어가 할 수 있는 일은 매우 제한적이다.

- 화면의 특정 부분을 누른다.
- 그러면 해당 부분을 모든 몬스터가 공격한다.

즉, 전투 중 플레이어 입력은 공격 지점 지정이 핵심이다.

### 8-2. 전투 후 / 런 도중
전투 후에는 더 많은 조정이 가능하다.

- 이미 선택한 포메이션에서 아군 위치를 재조정할 수 있다.
- 선택지 결정을 할 수 있다.
- 기본적인 강화 행동을 진행할 수 있다.

## 9. 기획적 의미
Dungeon Squad의 핵심은 전투 자체보다 전투 후 선택이 더 중요한 구조라는 점이다.

- 전투는 자원을 얻기 위한 과정이다.
- 포로는 다음 선택을 여는 핵심 자원이다.
- 선택은 스킬, 몬스터, 유물, 포메이션에 영향을 준다.
- 누적된 선택이 빌드를 완성한다.

## 10. 정리
Dungeon Squad의 전체 흐름은 다음처럼 요약할 수 있다.

- 아웃 게임 성장으로 런을 준비한다.
- 런 내부에서 일차별 전투를 반복한다.
- 전투 후 포로를 얻고, 포로를 기반으로 성장 선택을 한다.
- 현현 / 공양 / 동화 / 고문·타락으로 포로를 사용한다.
- 스킬과 몬스터 조합을 누적해 빌드를 만든다.
- 11일 단위 스테이지와 보스 전투를 거치며 런을 진행한다.
- 런 종료 후 아웃 게임 성장으로 다시 돌아간다.
