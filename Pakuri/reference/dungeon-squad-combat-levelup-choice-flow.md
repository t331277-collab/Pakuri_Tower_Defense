# Dungeon Squad 전투 후 포로 선택 흐름

> 목적: 전투 후 획득한 포로를 어떤 방식으로 사용할 수 있는지 정리한다.
> 주의: 이 문서는 포로를 중심으로 한 런 내부 선택 구조를 설명한다.

## 1. 기본 개념
Dungeon Squad의 전투 후 강화는 포로를 기반으로 진행된다.

전투 후 획득한 포로는 단순한 재화가 아니라, 여러 선택지를 여는 핵심 자원이다.

## 2. 포로로 열리는 주요 선택지
포로는 다음 네 가지 방식으로 활용된다.

1. 현현
2. 공양
3. 동화
4. 고문 / 타락

## 3. 현현
- 신규 몬스터를 소환하는 방식이다.
- 소환 실패 확률은 30%다.
- 성공 시 새로운 몬스터를 확보할 수 있다.

현현은 스쿼드 확장을 위한 선택지다.

## 4. 공양
- 기존 몬스터에게 포로를 먹여서 강화하는 방식이다.
- 선택 시 강화 선택지가 3개 제시된다.
- 그중 1개를 고를 수 있다.

공양은 기존 몬스터의 성장을 밀어주는 방식이다.

## 5. 동화
- 기존 몬스터에 해당 포로의 스탯과 특수 능력을 적용하는 방식이다.
- 단, 기존에 동화했던 능력은 모두 삭제된다.
- 새 포로의 동화 능력치(스탯, 특수 능력)만 남는다.

동화는 기존 몬스터의 상태를 덮어쓰는 방식의 강화다.

## 6. 고문 / 타락
- 포로를 고문하거나 타락시켜 아군으로 회유하는 방식이다.
- 현재는 추후 추가 예정 콘텐츠다.

이 선택지는 향후 스쿼드 확장 또는 포로 전환 계열 콘텐츠로 확장될 수 있다.

## 7. 기획적 의미
포로 시스템의 핵심은 하나의 자원을 여러 방향으로 해석할 수 있다는 점이다.

- 현현은 신규 확보
- 공양은 기존 강화
- 동화는 능력 덮어쓰기
- 고문 / 타락은 추후 확장형 선택지

즉, 포로는 단순 보상보다 **전투 후 빌드 방향을 결정하는 분기 자원**이다.

## 8. 정리
전투 후 포로 선택 구조는 다음처럼 이해하면 된다.

1. 포로를 획득한다.
2. 포로로 다양한 선택지를 연다.
3. 현현으로 신규 몬스터를 소환할 수 있다.
4. 공양으로 기존 몬스터를 강화할 수 있다.
5. 동화로 기존 몬스터의 능력을 재구성할 수 있다.
6. 고문 / 타락은 추후 확장 예정이다.
