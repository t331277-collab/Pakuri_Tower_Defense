# Dungeon Squad 지역 / 적 / 조우 구조 분석

## 1. 전투 대상인 영웅 구조
영웅은 몬스터를 공격하고, 전장 돌파 시 Devil Stone을 공격한다.

기본 규칙:
- 모든 영웅을 제거하면 스테이지 승리
- 스쿼드가 전멸해도 Devil Stone이 버티면 역전 가능
- Hero Acolyte가 살아남아 돌입하면 즉시 패배에 가까운 치명적 실패 발생

## 2. 영웅 분류
- Normal Heroes
- Elite Heroes
- Boss Heroes
- Named Bosses / Midbosses
- Hero Acolytes / Stage Bosses
- Nonstandard 특수형

## 3. 영웅 이동/사거리 분류
- Melee
- Short Range
- Long Range
- Nonstandard

이 구분은 적이 어디까지 전진한 뒤 공격을 시작하는지와 직접 연결된다.

## 4. 지역/스테이지 구조 해석
현재 공개 자료상 정확한 전체 지역표는 추가 수집이 필요하지만,
대략 아래 흐름이 읽힌다.
- 침공 런은 여러 전투 노드와 이벤트 노드로 이어지는 여정형 구조다.
- 일반 전투 / 엘리트 전투 / 보스 / 특수 조우가 섞여 있다.
- 특정 전투는 추가 적, Named Hero, 특수 규칙을 동반한다.

## 5. 조우 구조 특징
- 빨간 링 단계 등 특정 시각 표식이 엘리트 전투와 연결됨
- Named Boss 및 Hero Acolyte는 단순 스탯 강화판이 아니라 패배 리스크 자체를 바꾼다.
- 전투는 적 타입 그 자체보다 ‘포로 확보 가능성’과 ‘보상 기대치’까지 포함한 선택 문제가 된다.

## 6. 포로 시스템과 조우의 연결
영웅을 생포할 수 있다는 점이 이 게임의 조우 구조를 일반 디펜스와 크게 다르게 만든다.

영웅 격파 결과는 단순 처치가 아니라:
- 스킬 업그레이드 재료
- 팀 교체 자원
- 성향 교체 자원
- 오염 영웅 제작 자원
으로 전환된다.

즉 적은 처치 대상이면서 동시에 성장 자원이다.
