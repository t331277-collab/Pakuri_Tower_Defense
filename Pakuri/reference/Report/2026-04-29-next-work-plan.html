2. 최우선 작업 큐

우선순위 작업 해야 할 일 이번 작업에서 제외 완료 기준
1순위 상태 효과 공통 모델 1차 감전, 추위/빙결, 슬로우, 취약, 보호막처럼 이미 Eve 런타임에서 다룬 상태를 공통 상태 모델로 정리한다. 상태 지속시간, 스택, 피해 보정, 시각 표시 책임을 어디에 둘지 고정한다. 모든 몬스터의 모든 상태를 한 번에 구현하지 않는다. 먼저 Eve 구현에서 이미 등장한 상태와 다음 스킬 쌍에 필요한 상태만 다룬다. 선택지 효과가 특정 적에게 상태를 부여하고, 피해 계산 또는 이동/표시 변화에 실제로 반영된다.
2순위 한 몬스터 기준 B~E/F~J 런타임 연결 5몬스터 전체가 아니라 한 몬스터를 먼저 골라, B~E 액티브와 그에 연결된 G~J 패시브 중 작은 쌍을 실제 전투 효과로 연결한다. 현재 보고서 추천처럼 Eve B/G 또는 Ariel 방어막 계열이 후보가 된다. 모든 스킬 연출, 마스터 스킬 전체, 모든 강화 선택지를 동시에 완성하지 않는다. 포로 공양 선택지에서 배운 스킬/패시브가 RunSession 선택 기록을 거쳐 전투 중 실제 효과를 낸다.
3순위 스킬 효과 디스패처 정리 현재 선택지 데이터의 RewardId, SkillId, PassiveId를 전투 런타임 효과로 연결하는 디스패처를 만든다. 몬스터별 하드코딩이 불가피한 부분과 공통 처리 가능한 부분을 분리한다. 아직 문서 수치가 모호한 효과를 임의로 추정 구현하지 않는다. 새로운 스킬 하나를 추가할 때 UI 선택지, 세션 기록, 전투 효과 연결 위치가 명확하다.
4순위 시각/에셋 적용 점검 몬스터/적 SO의 UnitSprite, ProjectileSprite, 스킬별 SkillIcon, SkillEffectPrefab 필드가 런타임/UI에서 어디까지 쓰이는지 점검하고, 누락된 표시 경로를 정리한다. 새 이미지 제작이나 전체 UI 리디자인은 제외한다. 사용자가 할당한 이미지가 tint 없이 보이고, 아이콘/이펙트 필드의 사용 여부가 명확해진다.
