4. 상태이상 enum과 라벨 표시

중앙 enum

StatusEffectKind.cs:5에서 Shock, Chill, Freeze, Slow, Vulnerable, Shield를 정의한다. StatusEffectUtility.GetDefinition(...)은 id, 표시명, 기본 지속시간, 최대 stack, permanent 여부를 반환한다.

런타임 저장소

BaseUnitRuntimeModel은 UnitStatusRuntimeSet Statuses를 가진다. Apply, Tick, Has, GetStacks, Remove가 enum 기반으로 동작한다.

표시 형식

StatusEffectUtility.BuildDisplaySuffix(...)는 활성 상태를 [감전 +4/취약 +2] 형식으로 만든다. Actor는 이름 뒤에 이 suffix를 붙인다.

갱신 타이밍

InGameCombatManager.ApplyStatus, RemoveStatus, TickUnitStatuses는 상태가 바뀌면 RefreshUnitActor를 호출한다. 따라서 적용, 제거, 만료 시 라벨이 갱신된다.

5. Projectile Blueprint

현재 projectile 구조는 "데이터 -> 런타임 스킬 데이터 -> 선택지 snapshot -> executor -> projectile actor -> combat mutation"의 6단계로 정리된다. 이후 나머지 투사체형 스킬은 이 경로를 먼저 태우고, 경로 밖 동작만 hook 또는 새 modifier 필드로 분리한다.

CSV source row monster_skills.csv - runtime_kind = MagazineProjectile or CooldownProjectile - base_damage / coefficient / attribute / magazine / reload / shot_interval / status_effect_id InGameSkillDefinitionMapper - CreateTransient<ProjectileSkillData>(...) - Projectile.MagazineSize / ReloadTime / ProjectilesPerShot / ProjectileSpeed - Damage spec - OnHitStatus = CreateStatusApplication(...) SkillRuntimeFactory / SkillRuntimeInstance - learned active set - magazine, reload, cooldown, tick interval - CanCastWithSnapshot(...) - TryBeginCast(snapshot) SkillChoiceResolver / SkillExecutionSnapshot - chosen choice IDs - modifier rows by choice_id - damage multiplier, magazine, additional projectile, pierce - reload / shot interval - branch chance/count/damage/search radius - status tag/chance/stacks ProjectileSkillExecutor - resolve target and direction - resolve damage - resolve projectile count and pierce - resolve on-hit status spec - resolve branch spec - instantiate projectile prefab or direct fallback damage InGameProjectileActor - moves projectile - detects hit through relay/collider path - ApplyDamage(target) - TryApplyStatus(target) - TrySpawnBranches(hitTarget)

데이터만으로 가능한 경우

원하는 효과 현재 사용 가능한 필드 예시
기본 피해/계수/속성 변경 base_damage, attack_power_coefficient, spell_power_coefficient, attribute Ariel-A: Holy projectile, Vega-A: Physical projectile, Eve-A: Lightning projectile
탄창, 재장전, 발사 간격 magazine_capacity, reload_seconds, shot_interval_seconds, choice modifier의 magazine_bonus, reload_time_multiplier, shot_interval_multiplier Eve-A trait 1~4
추가 투사체와 관통 additional_projectile_bonus, pierce_bonus Eve-A trait 2~4, Eve-A master 2
on-hit 상태이상 status_effect_id, choice modifier의 status_tag, status_chance_bonus, status_stacks_set Eve-A shock, Eve-A master 2 shock 2 stacks
분기 투사체 branch_chance_bonus, branch_chance_set, branch_count, branch_damage_multiplier, branch_search_radius Eve-A trait 5, Eve-A master 1

새 hook 또는 새 modifier 필드가 필요한 경우

요구 효과 왜 현재 데이터만으로 부족한가 권장 구현 방식
마지막 탄환만 강화 현재 snapshot은 전체 cast/shot에 같은 multiplier를 적용한다. magazine의 "마지막 탄환" 판별 조건이 없다. SkillRuntimeInstance 또는 projectile spec에 shot index / magazine remaining 정보를 전달하고 last_shot_damage_multiplier 필드를 추가한다.
지연 잔상 투사체 현재 branch는 on-hit 시 주변 target을 찾아 즉시 projectile을 만든다. 발사 후 같은 궤도에 delay spawn하는 개념은 없다. ProjectileSkillExecutor에 delayed projectile spawn spec을 추가하거나 별도 DelayedProjectileSkillEffectActor를 둔다.
처치 시 표식 이전 현재 projectile actor는 hit 처리 후 damage/status/branch를 수행하지만 on-kill event hook은 없다. ApplyDamage 결과 또는 death cleanup에서 killer/source skill context를 전달하는 on-kill hook을 추가한다.
마지막 탄환 2회 폭발 현재 projectile actor는 단일 hit 피해와 branch projectile 중심이다. 범위 폭발, 반복 폭발, 마지막 탄환 조건이 없다. projectile impact AoE spec, explosion count, last shot predicate를 공통화한다. Ariel-A master 1은 이 hook을 사용한다.
보유 shield 수에 따른 피해 증가 현재 damage snapshot은 owner/party의 shield 상태를 조건으로 읽는 dynamic modifier가 없다. damage calculation 단계에 runtime condition modifier를 추가하고, BaseUnitRuntimeModel.Resources.Shield 또는 party roster를 조회한다.

6. Vega-A, Ariel-A 적용 방식

Vega-A 기본형

monster_skills.csv:33의 vega-a는 이미 MagazineProjectile이고 Physical, base damage 9, attack coefficient 0.4, magazine 5, reload 4.8, shot interval 0.55다. 기본 발사는 Eve-A와 같은 projectile executor를 사용한다.

다만 monster_skill_choices.csv:156~:159의 마지막 탄환 강화, 지연 잔상, 처치 시 표식 이전은 현재 공통 modifier만으로는 부족하다.

Ariel-A 기본형

monster_skills.csv:3의 ariel-a는 MagazineProjectile이고 Holy, base damage 18, spell coefficient 1, magazine 7, reload 4.6, shot interval 0.36이다. 기본 신성 투사체는 Eve-A blueprint를 그대로 사용 가능하다.

monster_skill_choices.csv:8~:9의 마지막 탄환 2회 폭발, 신성 노출은 impact AoE / status enum 확장 또는 새 status kind가 필요하다.

7. 구현 우선순위

  1. 공통 projectile 조건 필드 확장: last shot, delayed echo, impact AoE, on-kill trigger처럼 Vega/Ariel도 공유할 수 있는 조건을 먼저 설계한다.
  2. 상태이상 enum 확장: Ariel의 신성 노출, Vega의 이름표식처럼 실제 런타임에 남아야 하는 효과는 StatusEffectKind에 추가하고 display name / stack / duration 정책을 중앙화한다.
  3. damage calculation modifier 층: shock target damage, shield count damage, status stack damage 같은 조건부 피해 증폭은 projectile actor 내부가 아니라 공통 damage 계산 단계에서 처리한다.
  4. NewRunUnitSpawnManager 책임 유지: 이후 스폰 관련 기능은 EntryManager로 되돌리지 않고 UnitSpawnManager 또는 Stage-owned lifecycle service로 확장한다.
