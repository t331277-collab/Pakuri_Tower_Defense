2. 로드맵 단계별 비교

로드맵 단계 로드맵 의도 현재 결과 판정 근거
1. 전투/런 루프 안정화 큰 동작 변경 없이 전투/적/보상/HUD 책임을 분리한다. EveVerticalSliceController가 CombatRuntimeController와 partial 파일들로 분리된 상태다. 완료 BLACKBOARD.md의 Combat Runtime Controller Split 블록. 사용자 Play Mode 검증 완료 기록 있음.
2. 런 일차/전투 타입 모델 일차와 전투 타입을 RunSession에 표현한다. RunDayModel, RunCombatType, RunSession.CurrentDayModel, CurrentCombatType가 추가된 상태다. 완료 BLACKBOARD.md의 Run Day Combat Type And Material Rewards 블록.
3. 전투 보상 실제화 포로, 골드, 어둠의 흔적 지급을 실제 세션에 반영한다. 보상 버튼 클릭으로 재화/포로가 세션에 반영되고, 포로 패널이 열리는 흐름까지 구현됐다. 완료 RunSession.ClaimMaterialReward(), ClaimPrisonerReward(), RunCombatUiController 보상 클릭 흐름.
4. 포로 사용: 공양과 스킬 선택지 풀 포로 공양 시 신규 액티브/패시브/강화/마스터 후보를 하나의 풀로 만든다. 기존에는 현재 몬스터 데이터와 초기 보상 선택지 중심이었고, 오늘 구조 확장 후 액티브 강화, 패시브 강화, 마스터 스킬 후보가 선택지 풀에 들어갈 수 있게 됐다. 완료 RunCombatUiController.AddActiveEnhancementOfferingChoices(), AddPassiveEnhancementOfferingChoices(), AddMasterSkillOfferingChoices().
5. 몬스터 A~J 스킬 데이터 정리 5종 몬스터의 A~J 데이터, A 기본 습득, B~E/F~J 선택/해금 관계를 정리한다. 문서 기준으로 5개 몬스터 SO에 A~E 액티브, F~J 패시브, 강화/마스터 선택지, 설명 텍스트, 아이콘/이펙트 참조 필드가 들어갔다. 오늘 완료 SkillDefinition.cs, PakuriGameDataSeeder.cs, Assets/Data/GameData/Monsters/*.asset.
6. 상태 효과 기반 확장 감전, 빙결, 화상, 취약, 신성 방어막 등 상태 효과를 공통 모델로 구현한다. 상태 효과 이름과 설명은 데이터에 들어갔지만, 공통 상태 머신과 효과 계산은 아직 구현되지 않았다. 남음 현재 전투 런타임은 A 투사체 중심이며, B~E/F~J 효과 적용 로직은 없음.
7. 2~4스테이지 적 데이터 스테이지 2~4 적 자산과 스테이지별 후보 풀을 만든다. 오늘 작업 범위가 아니다. 현재 diff에는 stage1 enemy asset에 sprite 필드 추가가 보이지만 2~4스테이지 적 생성은 없다. 남음 git status --short와 Assets/Data/GameData/Enemies 변경 범위.
8. 정예 전투와 이벤트 정예 접두/이벤트 판정을 전투 시작 흐름에 연결한다. 오늘 작업 범위가 아니다. 남음 관련 신규 스크립트/자산 변경 없음.
9. 상점과 유물 후보 상점, 유물 후보, 골드 구매를 구현한다. 보상 UI에 Artifact 템플릿은 남아 있지만 유물 효과/상점 구현은 아직 없다. 남음 BLACKBOARD.md의 보상 작업 블록에서 artifact 효과 제외가 명시됨.
10. 포메이션 데이터와 시작 포메이션 선택 15개 슬롯과 포메이션 선택을 런 시작에 연결한다. 오늘 작업 범위가 아니다. 남음 포메이션 관련 신규 코드/자산 변경 없음.
11. 메타 저장과 심연 강화 어둠의 흔적 저장, 승급, 메타 노드를 구현한다. 오늘 작업 범위가 아니다. 남음 Save/Meta 관련 신규 코드 변경 없음.

4. 오늘 작업 중 로드맵 외 지원 작업

작업 결과 로드맵과의 관계
몬스터/적 SO 이미지 참조 MonsterDefinition, EnemyDefinition에 유닛/투사체 sprite 참조를 추가하고 런타임 렌더러에서 사용하도록 연결했다. 로드맵 5번의 스킬/몬스터 데이터 정리와 직접 맞물리는 표시 데이터 기반 작업이다.
RunScene 배경 이미지 수정 가능 CombatRuntimeController에 배경 sprite/color/auto-fit 필드를 추가하고, 수동 scale이 보존되도록 수정했다. 로드맵의 핵심 단계는 아니지만 RunScene 검증 편의와 시각 자산 적용 기반이다.
색상 white 고정 유닛, 투사체, HP bar, 마커, 배경 렌더러 색을 white로 유지하도록 수정했다. 이미지 자산이 tint 없이 보이게 하는 렌더링 안정화 작업이다.
