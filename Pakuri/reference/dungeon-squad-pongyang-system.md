# Dungeon Squad 공양 로직 분석

> 목적: 공양 시 뜨는 3개 선택지가 어떻게 구성되는지 정리한다.

## 1. 선택지 생성 원리
공양에서 뜨는 3개 선택지는 아래 후보들을 섞어서 무작위로 뽑는다.

- 아직 배우지 않은 액티브 스킬
- 아직 배우지 않은 패시브 스킬
- 이미 배운 스킬의 강화 선택지

즉, 공양 선택지는 액티브와 패시브를 모두 포함한 "미습득 스킬"과 "기존 스킬 강화"를 하나의 풀로 섞은 뒤, 그중 3개를 보여주는 방식이다.

## 2. 액티브 / 패시브 스킬이 모두 배워진 경우
액티브 스킬 3개를 모두 배운 상태라면, 더 이상 배우지 않은 액티브 스킬은 선택지에 등장하지 않는다.
패시브 스킬 3개를 모두 배운 상태라면, 더 이상 배우지 않은 패시브 스킬은 선택지에 등장하지 않는다.

이 경우에는 남아 있는 기존 스킬 강화 선택지만 후보가 된다.

## 3. 개별 스킬의 선택지 소진
한 스킬의 추가 강화를 완료하면, 그 스킬의 선택지는 더 이상 나오지 않는다.

즉, 각 스킬은 독립적으로 선택지 소진 상태를 가진다.

## 4. 최종 선택지 수
남아 있는 후보 수가 3개보다 적을 수 있다.

- 후보가 2개면 화면에 2개만 표시한다.
- 후보가 1개면 화면에 1개만 표시한다.
- 후보가 0개면 더 이상 선택지를 만들지 못한다.

## 5. 후보가 모두 소진된 경우
선택지가 더 이상 남아 있지 않으면, 몬스터가 보유한 액티브 스킬 중 무작위 스킬의 레벨이 오른다.

이 경우의 스킬 레벨 상승은 단순 강화 보정이며, 데미지가 % 단위로 오른다.

## 6. 정리
공양 선택지 로직은 다음처럼 이해하면 된다.

1. 미습득 액티브, 미습득 패시브, 강화 선택지를 모두 섞는다.
2. 그중 무작위 3개를 보여준다.
3. 액티브 3개를 모두 배웠다면 미습득 액티브는 더 이상 나오지 않는다.
4. 패시브 3개를 모두 배웠다면 미습득 패시브는 더 이상 나오지 않는다.
5. 개별 스킬의 선택지를 다 쓰면 그 스킬도 더 이상 나오지 않는다.
6. 후보가 2개면 2개만, 1개면 1개만 표시한다.
7. 후보가 모두 소진되면 무작위 액티브 스킬 레벨이 오른다.
