# Dungeon Squad 전투 플레이어 조작

> 목적: 전투 중과 전투 후에 플레이어가 무엇을 할 수 있는지 정리한다.

## 1. 전투 중 조작
전투 도중 플레이어가 할 수 있는 일은 매우 제한적이다.

- 화면의 특정 부분을 누른다.
- 그러면 해당 부분을 모든 몬스터가 공격한다.

즉, 전투 중 플레이어 입력은 공격 지점 지정이 핵심이다.

## 2. 전투 중 조작의 의미
전투 중에는 복잡한 직접 조작이 없다.

- 이동 조작 중심이 아니다.
- 개별 몬스터를 직접 컨트롤하는 구조가 아니다.
- 플레이어는 공격 지점을 지정하는 방식으로만 개입한다.

## 3. 런 도중 전투 후 조작
전투 후, 런 도중에는 더 많은 조정이 가능하다.

- 이미 선택한 포메이션에서 아군 위치를 재조정할 수 있다.
- 선택지 결정을 할 수 있다.
- 기본적인 강화 행동을 진행할 수 있다.

## 4. 기획적 의미
Dungeon Squad의 플레이어 조작은 전투 중과 전투 후로 역할이 나뉜다.

- 전투 중: 공격 지점 지정
- 전투 후: 위치 재조정과 강화 선택

이 구조는 실시간 전투의 긴장감과 선택 기반 성장의 비중을 함께 유지한다.
