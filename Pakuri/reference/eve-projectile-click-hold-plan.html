이 문서는 현재 구현된 이브 전투 프로토타입을 기준으로, 문서에 맞게 왼쪽 클릭 유지 기반 연속 발사와 실제 투사체 충돌 기반 피해 처리로 수정할 때 어떤 순서와 구조로 작업할지 정리한 설계 문서다. 아직 구현한 문서가 아니라, 현재 코드와 reference 문서의 차이를 근거로 만든 변경 계획이다.

짧은 결론

현재 버전은 클릭 1회로 공격 집중 지점을 바꾸고, 이브가 즉시 피해를 넣는 자동 타격형이다. 사용자가 요청한 수정 방향은 왼쪽 클릭 유지 중 연속 발사, 아크 볼트가 실제 투사체로 이동, 투사체가 적과 닿을 때만 피해 적용으로 바뀌어야 한다.

따라서 이번 수정의 핵심은 단순 수치 조정이 아니라, 입력 처리, 발사 처리, 투사체 런타임, 충돌 시 피해 처리를 분리하는 구조 변경이다.

현재 코드와의 충돌 지점

  • 현재 코드 입력은 wasPressedThisFrame / GetMouseButtonDown(0) 기준이라 누르고 있는 상태를 사용하지 않는다.
  • 현재 코드 FireArcBolt(...)가 적을 고른 직후 target.CurrentHealth -= result.FinalDamage를 호출해 즉시 피해를 넣는다.
  • 현재 코드 투사체 런타임 자료구조, 투사체 이동 업데이트, 적과의 충돌 판정 루프가 없다.
  • 현재 코드 InputTarget은 조준 포인트 마커로만 쓰이고 있으며, 발사체 경로 계산과는 직접 연결돼 있지 않다.

이번 수정에서 둘 핵심 해석

항목 이번 수정 해석 근거
입력 방식 왼쪽 클릭을 누르고 있는 동안 발사 가능 상태를 유지하고, 손을 떼면 신규 발사를 멈춘다. 사용자 요청의 "왼쪽 클릭 유지 시 연속 발사" 조건
공격 지점 지정 마우스를 누르고 있는 동안 현재 포인터 위치를 계속 읽어 currentAttackPoint를 갱신한다. reference의 "공격 지점 지정" 개념을 hold 입력으로 확장
발사 방식 이브는 즉시 타격하지 않고, 자신의 위치에서 InputTarget 방향으로 아크 볼트 투사체를 생성한다. 아크 볼트가 "투사체 / 탄창형"이라는 문서 정의
데미지 적용 시점 투사체가 적의 충돌 반경에 닿을 때만 피해를 적용한다. 사용자 요청의 "투사체에 적이 닿으면 데미지"
InputTarget 역할 없애지 않고 유지한다. 이후에는 "선택 대상"이 아니라 "현재 투사체 발사 방향/집중 지점 표시기"로 쓴다. 현재 씬 구조를 최대한 보존하면서 의미만 정리

수정 후 전투 루프

  1. 플레이어가 왼쪽 클릭을 누르면 현재 마우스 위치를 월드 좌표로 바꾸고 currentAttackPoint를 갱신한다.
  2. 왼쪽 클릭을 누르고 있는 동안, 이브는 shotCooldown, reloadRemaining, currentShotsRemaining 조건을 검사한다.
  3. 사격 가능하면 EveUnit 위치에서 아크 볼트 투사체를 1개 생성한다.
  4. 투사체는 currentAttackPoint - eveAnchor.position 방향으로 정규화된 벡터를 받아 전진한다.
  5. 투사체는 매 프레임 이동하면서 적 리스트와 충돌 반경을 검사한다.
  6. 충돌하면 그 순간에만 피해, 치명타, 감전 판정을 적용하고 투사체를 소멸시킨다.
  7. 아무 적도 맞히지 못하고 최대 사거리 또는 전장 바깥까지 나가면 투사체를 소멸시킨다.
  8. 마우스를 떼면 새 투사체 생성만 멈추고, 이미 날아간 투사체는 끝까지 진행한다.

현재 프로토타입에서 버릴 로직

  • 적을 먼저 고른 뒤 즉시 피해를 넣는 SelectTarget() -> FireArcBolt(target) 흐름은 메인 전투 루프에서 제거한다.
  • 현재의 "가장 가까운 적을 자동 선별" 로직은 투사체형 1차 준수 패스에서는 우선순위를 낮춘다.
  • 즉시 데미지 기반 피격 플래시는 더 이상 발사 시점에 나오지 않고, 투사체 적중 시점으로 이동한다.

구현 1단계

  • hold 입력 판정 추가
  • InputTarget 실시간 추적 유지
  • 마우스 해제 시 신규 발사 중지

구현 2단계

  • 투사체 런타임 자료구조 추가
  • 발사 간격/탄창/재장전은 기존 수치 유지
  • 투사체 속도는 문서값 15.0 반영

구현 3단계

  • 적 충돌 시 피해 적용
  • 감전 15%를 적중 시점으로 이동
  • 맞히지 못한 투사체 소멸 처리

검증 체크리스트

  • 왼쪽 클릭을 짧게 눌렀을 때 1발만 나가는지 확인
  • 왼쪽 클릭을 누르고 있으면 0.35초 간격으로 연속 발사되는지 확인
  • 탄창 6발 소모 후 4초 재장전에 들어가는지 확인
  • 투사체가 적에 닿기 전에는 피해가 적용되지 않는지 확인
  • 투사체가 적과 닿았을 때만 HP 감소와 피격 플래시가 발생하는지 확인
  • 전장 밖으로 날아간 투사체가 정상 정리되는지 확인

이번 패스에서 일부러 안 묶는 것

  • 정식 적 히트박스/Collider2D 컴포넌트 기반 물리 충돌
  • 문서 전체 수준의 속성별 방어력 데이터 모델 완성
  • 분기 번개, 관통, 추가 투사체 같은 상위 특성 효과
  • 정식 UI 캔버스 전환

이유는 현재 vertical slice의 최소 목표가 투사체형 발사 준수이기 때문이다. 먼저 입력-발사-충돌-피해의 축을 바로잡고, 그 다음에 속성 저항 테이블과 고급 탄도 로직을 붙이는 편이 리스크가 낮다.

Code Builder handoff 메모

  • 현재 즉시 피해 구조를 유지한 채 시각 효과만 추가하는 식으로는 안 된다. 반드시 투사체 적중 시점으로 피해 적용 시점을 옮겨야 한다.
  • InputTarget은 삭제 대상이 아니다. 이번 수정 후에도 조준 포인트 마커로 계속 유지한다.

  • 작업 후에는 플레이 모드에서 hold 발사, 탄창/재장전, 적중 시 피해, 미적중 시 소멸을 실제로 검증해야 한다.
