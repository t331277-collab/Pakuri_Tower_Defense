# 심연의 제단 화면 UI 기획서

## 화면 구성

| 구역 | 요소 | 기능 |
|---|---|---|
| 상단 | 보유 재화 | 어둠의 흔적 표시 |
| 좌측 | 캐릭터 목록 | 강화할 캐릭터 선택 |
| 중앙 | 강화 목록 | 선택 캐릭터의 강화 항목 표시 |
| 우측 | 선택 정보 | 선택한 강화 항목의 상세 정보 표시 |
| 하단 | 강화 버튼 | 선택 항목 강화 시도 |
| 우측 상단 | 닫기 버튼 | 타이틀 화면으로 돌아가기 |

## 입장 조건

| 항목 | 내용 |
|---|---|
| 해금 조건 | 어둠의 흔적 해금 트리에서 캐릭터 강화 관련 노드 1개 이상 해금 |
| 잠금 상태 | 타이틀 화면의 심연의 제단 버튼을 어둡게 표시 |
| 잠금 안내 | 버튼을 누르면 해금 조건 안내 창 열기 |

## 좌측 캐릭터 목록

| 항목 | 내용 |
|---|---|
| 표시 | 캐릭터 아이콘과 이름 |
| 선택 | 캐릭터를 누르면 중앙 강화 목록 갱신 |
| 잠긴 캐릭터 | 어둡게 표시하고 잠금 아이콘 표시 |
| 정렬 | 보유 캐릭터를 위쪽에 표시 |

## 중앙 강화 목록

```text
┌──────────────────────────────────────────────┐
│ 심연의 제단                         [닫기]   │
│ 어둠의 흔적 0000                             │
├──────────┬───────────────────────┬───────────┤
│ 캐릭터   │ 강화 목록             │ 선택 정보 │
│ [이브]   │ [스킬 각성]           │ 항목 이름 │
│ [린]     │ 스킬 A     Lv.1 / 5   │ 현재 단계 │
│ [세인]   │ 스킬 B     Lv.0 / 5   │ 다음 효과 │
│ [아리엘] │                       │ 현재 효과 │
│          │ [스탯 강화]           │ 강화 후   │
│          │                       │ 성공 확률 │
│          │                       │ [강화 시도 500]│
│          │ [액티브 스킬]         │           │
│          │ 스킬 A     Lv.1 / 5   │           │
│          │ 스킬 B     Lv.0 / 5   │           │
└──────────┴───────────────────────┴───────────┘
```

| 항목 | 내용 |
|---|---|
| 액티브 스킬 각성 | 선택 캐릭터의 액티브 스킬별 변주 선택 |
| 스탯 강화 | 체력, 공격력, 주문력, 위력, 모든 속성 피해 |
| 액티브 스킬 강화 | 선택 캐릭터의 액티브 스킬별 화력 강화 |
| 단계 표시 | 현재 단계와 최대 단계 표시 |
| 강화 가능 | 필요한 어둠의 흔적이 있으면 활성 표시 |
| 강화 불가 | 재화 부족 또는 미해금 항목은 어둡게 표시 |
| 확률 표시 | 다음 단계 성공 확률 표시 |
| 목록 이동 | 항목이 많으면 세로로 넘겨 확인 |

## 강화 탭

| 탭 | 표시 조건 | 사용 조건 |
|---|---|---|
| 액티브 스킬 각성 | 액티브 스킬 각성 해금 후 표시 | 선택 캐릭터가 대상 액티브 스킬 보유 |
| 스탯 강화 | 캐릭터 스탯 강화 해금 후 표시 | 바로 사용 가능 |
| 액티브 스킬 강화 | 액티브 스킬 강화 해금 후 표시 | 선택 캐릭터의 모든 스탯 강화 완료 |

해금 트리에서 탭을 해금하면 탭 이름은 보인다.
다만 캐릭터별 사용 조건을 만족하지 못한 항목은 잠금 상태로 표시한다.
최종 탭 순서는 `각성`, `스탯`, `액티브`를 기본으로 한다.

## 잠금 표시

| 상태 | 표시 |
|---|---|
| 액티브 스킬 각성 미해금 | 각성 탭 잠금 |
| 액티브 스킬 각성 해금 / 대상 스킬 미보유 | 각성 후보 잠금 또는 숨김 |
| 스탯 강화 미해금 | 스탯 강화 탭 잠금 |
| 액티브 스킬 강화 해금 / 스탯 강화 미완료 | 액티브 스킬 강화 탭은 보이지만 항목 잠금 |
| 조건 완료 | 강화 또는 각성 버튼 활성 |

## 선택 정보

| 항목 | 내용 |
|---|---|
| 항목 이름 | 선택한 강화 항목 이름 |
| 현재 단계 | 현재 강화 단계 |
| 다음 단계 | 강화 후 단계 |
| 현재 스탯 | 강화 전 주요 수치 |
| 강화 후 스탯 | 강화 성공 후 주요 수치 |
| 성공 확률 | 다음 단계 강화 성공 확률 |
| 강화 비용 | 강화 시도 버튼 안에 필요한 어둠의 흔적 수량 표시 |
| 적용 대상 | 선택 캐릭터 또는 선택 스킬 |
| 잠금 이유 | 조건을 만족하지 못한 경우 표시 |

## 버튼

| 버튼 | 위치 | 기능 | 눌렀을 때 |
|---|---|---|---|
| 강화 시도 | 우측 정보 하단 | 선택 항목 강화 시도와 비용 표시 | 성공하면 단계 상승, 실패하면 단계 유지 |
| 캐릭터 선택 | 좌측 | 강화 대상 변경 | 중앙 강화 목록 갱신 |
| 닫기 | 우측 상단 | 화면 닫기 | 타이틀 화면으로 돌아가기 |

## 강화 결과 표시

| 결과 | 표시 |
|---|---|
| 성공 | 강화 성공 문구와 상승한 단계 표시 |
| 실패 | 강화 실패 문구와 현재 단계 유지 표시 |
| 최대 단계 | 완료 문구 표시, 강화 버튼 비활성 |
| 재화 부족 | 강화 시도 버튼은 비활성, 부족한 어둠의 흔적 표시 |

## 화면 이동

| 선택 항목 | 결과 |
|---|---|
| 캐릭터 | 해당 캐릭터 강화 목록 표시 |
| 강화 항목 | 선택 정보 표시 |
| 강화 | 선택 항목 강화 시도 후 결과 표시 |
| 각성 후보 | 누른 각성 후보 정보 표시 |
| 닫기 | 타이틀 화면 |
