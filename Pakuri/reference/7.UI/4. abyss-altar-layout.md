# 심연의 제단 화면 UI 기획서

## 화면 구성

| 구역 | 요소 | 기능 |
|---|---|---|
| 상단 | 보유 재화 | 어둠의 흔적 표시 |
| 좌측 | 캐릭터 목록 | 강화할 캐릭터 선택 |
| 중앙 | 강화 목록 | 선택 캐릭터의 강화 항목 표시 |
| 우측 | 선택 정보 | 선택한 강화 항목의 상세 정보 표시 |
| 하단 | 강화 버튼 | 선택 항목 강화 |
| 우측 상단 | 닫기 버튼 | 타이틀 화면으로 돌아가기 |

## 입장 조건

| 항목 | 내용 |
|---|---|
| 해금 조건 | 어둠의 흔적 해금 트리에서 캐릭터 강화 관련 노드 1개 이상 해금 |
| 잠금 상태 | 타이틀 화면의 심연의 제단 버튼을 어둡게 표시 |
| 잠금 안내 | 버튼을 누르면 해금 조건 안내 창 열기 |

## 좌측 캐릭터 목록

| 항목 | 내용 |
|---|---|
| 표시 | 캐릭터 아이콘과 이름 |
| 선택 | 캐릭터를 누르면 중앙 강화 목록 갱신 |
| 잠긴 캐릭터 | 어둡게 표시하고 잠금 아이콘 표시 |
| 정렬 | 보유 캐릭터를 위쪽에 표시 |

## 중앙 강화 목록

```text
┌──────────────────────────────────────────────┐
│ 심연의 제단                         [닫기]   │
│ 어둠의 흔적 0000                             │
├──────────┬───────────────────────┬───────────┤
│ 캐릭터   │ 강화 목록             │ 선택 정보 │
│ [이브]   │ [공통 스탯]           │ 항목 이름 │
│ [린]     │ 체력       Lv.1 / 5   │ 현재 단계 │
│ [세인]   │ 공격력     Lv.0 / 5   │ 다음 효과 │
│ [아리엘] │ 주문력     Lv.2 / 5   │ 필요 재화 │
│          │ 이동속도   Lv.0 / 5   │ [강화]    │
│          │                       │ [초기화]  │
│          │ [액티브 스킬]         │           │
│          │ 스킬 A     Lv.1 / 5   │           │
│          │ 스킬 B     Lv.0 / 5   │           │
└──────────┴───────────────────────┴───────────┘
```

| 항목 | 내용 |
|---|---|
| 공통 스탯 | 체력, 공격력, 주문력, 이동속도 등 |
| 액티브 스킬 | 선택 캐릭터의 액티브 스킬별 강화 |
| 단계 표시 | 현재 단계와 최대 단계 표시 |
| 강화 가능 | 필요한 어둠의 흔적이 있으면 활성 표시 |
| 강화 불가 | 재화 부족 또는 미해금 항목은 어둡게 표시 |
| 목록 이동 | 항목이 많으면 세로로 넘겨 확인 |

## 선택 정보

| 항목 | 내용 |
|---|---|
| 항목 이름 | 선택한 강화 항목 이름 |
| 현재 단계 | 현재 강화 단계 |
| 다음 단계 | 강화 후 효과 |
| 필요 재화 | 필요한 어둠의 흔적 수량 |
| 적용 대상 | 선택 캐릭터 또는 선택 스킬 |

## 버튼

| 버튼 | 위치 | 기능 | 눌렀을 때 |
|---|---|---|---|
| 강화 | 우측 정보 하단 | 선택 항목 강화 | 단계 상승 |
| 초기화 | 우측 정보 하단 | 선택 캐릭터의 투자 재화 반환 | 초기화 확인 창 열기 |
| 캐릭터 선택 | 좌측 | 강화 대상 변경 | 중앙 강화 목록 갱신 |
| 닫기 | 우측 상단 | 화면 닫기 | 타이틀 화면으로 돌아가기 |

## 화면 이동

| 선택 항목 | 결과 |
|---|---|
| 캐릭터 | 해당 캐릭터 강화 목록 표시 |
| 강화 항목 | 선택 정보 표시 |
| 강화 | 선택 항목 단계 상승 |
| 초기화 | 초기화 확인 창 |
| 닫기 | 타이틀 화면 |
