# 도감 팝업 화면 UI 기획서

## 화면 참고 이미지

![[도감.png]]

## 화면 구성

| 구역 | 요소 | 기능 |
|---|---|---|
| 전체 | 도감 팝업 화면 | 기존 화면 위를 전부 덮음 |
| 좌측 | 카테고리 버튼 목록 | 도감 분류 선택 |
| 상단 좌측 | 현재 카테고리 이름 | 선택한 카테고리 표시 |
| 중앙 | 내용 영역 | 목록, 상세 정보, 스킬 특성 표시 |
| 우측 상단 | 닫기 버튼 | 이전 화면으로 돌아가기 |

## 카테고리 버튼

| 순서 | 카테고리 | 기능 |
|---:|---|---|
| 1 | 아군 몬스터 | 아군 몬스터 목록 표시 |
| 2 | 적 | 적 목록 표시 |
| 3 | 유물 | 유물 목록 표시 |
| 4 | 포메이션 | 포메이션 목록 표시 |

## 카테고리 표시

| 항목 | 내용 |
|---|---|
| 배치 | 좌측에 세로로 배치 |
| 아이콘 | 카테고리별 아이콘 표시 |
| 선택 표시 | 선택한 카테고리 버튼 강조 |
| 알림 표시 | 새로 등록된 항목이 있으면 카테고리 버튼에 표시 |
| 변경 | 카테고리 버튼을 누르면 중앙 목록과 상단 카테고리 이름 변경 |

## 중앙 내용 영역

| 항목 | 내용 |
|---|---|
| 목록 상태 | 선택한 카테고리의 항목을 격자로 표시 |
| 상세 상태 | 선택한 항목의 상세 정보를 같은 영역에 표시 |
| 스킬 상태 | 선택한 스킬의 특성 목록을 같은 영역에 표시 |
| 돌아가기 | 상세 상태에서는 목록으로 돌아가는 버튼 표시 |
| 목록 이동 | 항목이나 특성이 많으면 아래로 넘겨 확인 |

## 항목 목록 상태

| 항목 | 내용 |
|---|---|
| 배치 | 중앙 영역에 격자로 배치 |
| 아이콘 | 항목별 대표 이미지 표시 |
| 이름 | 아이콘 아래에 항목 이름 표시 |
| 잠금 항목 | 미발견 항목은 어두운 실루엣과 물음표로 표시 |
| 선택 | 항목을 누르면 중앙 내용 영역이 상세 상태로 변경 |

### 스킬 특성 화면 정보

| 영역 | 표시 방식 |
|---|---|
| 스킬 제목 | 스킬 아이콘과 이름을 함께 표시 |

| 특성 한 줄 | 특성 아이콘, 특성 이름, 한 줄 효과 표시 |
| 선택한 특성 | 선택한 특성 아래에 상세 효과 영역을 펼쳐 표시 |
| 스킬 미리보기 | 스킬 범위나 형태를 간단한 그림으로 표시 |

| 항목 | 내용 |
|---|---|

| 팝업 위치 | 누른 상태 효과 이름 근처에 표시 |
| 팝업 내용 | 상태 효과 이름, 핵심 효과, 행동 제한 또는 중첩 정보 |

## 포메이션 슬롯 배치도

| 항목 | 내용 |
|---|---|
| 전체 슬롯 | 공용 타워 배치 후보 15개 표시 |
| 열 구분 | 후열, 중열, 전열 3열로 표시 |
| 행 구분 | 상단, 중상단, 중앙, 중하단, 하단 5행으로 표시 |
| 사용 슬롯 | 해당 포메이션이 사용하는 5개 슬롯만 강조 |
| 슬롯 번호 | 선택된 5개 슬롯에 1번부터 5번 번호 표시 |
| 슬롯 선택 | 슬롯을 누르면 하단 효과 설명 갱신 |
