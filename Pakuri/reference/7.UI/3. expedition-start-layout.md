# 원정 시작 화면 UI 기획서

## 화면 참고 이미지

![[docs/png/reference/ui/expedition/expedition-start-step-layout.png]]

## 화면 구성

| 구역 | 요소 | 기능 |
|---|---|---|
| 상단 | 원정 시작 제목 | 현재 화면 표시 |
| 중앙 상단 | 난이도 선택 | 시작 난이도 선택 |
| 중앙 중단 | 스타트 몬스터 선택 | 첫 아군 몬스터 선택 |
| 중앙 하단 | 포메이션 선택 | 시작 포메이션 선택 |
| 우측 | 선택 요약 | 선택한 난이도, 몬스터, 포메이션 표시 |
| 우측 하단 | 원정 시작 버튼 | 선택한 조건으로 런 시작 |
| 우측 상단 | 닫기 버튼 | 타이틀 화면으로 돌아가기 |

## 선택 순서

| 순서 | 항목 | 기능 |
|---:|---|---|
| 1 | 난이도 선택 | 런 시작 난이도 선택 |
| 2 | 스타트 몬스터 선택 | 첫 아군 몬스터 선택 |
| 3 | 포메이션 선택 | 시작 포메이션 선택 |

## 난이도 선택

| 항목 | 내용 |
|---|---|
| 표시 방식 | 가로 카드 목록 |
| 표시 항목 | 난이도 이름, 추천 전투력, 보상 배율 |
| 선택 표시 | 선택한 난이도 카드 강조 |
| 잠금 표시 | 미해금 난이도는 잠금 아이콘 표시 |

## 스타트 몬스터 선택

| 항목 | 내용 |
|---|---|
| 표시 방식 | 가로 카드 목록 |
| 표시 항목 | 몬스터 이미지, 이름, 속성, 역할 |
| 선택 표시 | 선택한 몬스터 카드 강조 |
| 상세 표시 | 선택한 몬스터의 기본 정보와 주요 스킬 요약 |

## 포메이션 선택

| 항목 | 내용 |
|---|---|
| 표시 방식 | 가로 카드 목록 |
| 표시 항목 | 포메이션 이름, 미니 슬롯 배치도, 핵심 효과 |
| 선택 표시 | 선택한 포메이션 카드 강조 |
| 상세 표시 | 선택한 포메이션의 1~5번 효과 요약 |

## 선택 요약

| 항목 | 내용 |
|---|---|
| 난이도 | 선택한 난이도 표시 |
| 스타트 몬스터 | 선택한 몬스터 표시 |
| 포메이션 | 선택한 포메이션 표시 |
| 시작 가능 여부 | 3개 선택이 모두 완료되면 원정 시작 버튼 활성화 |

## 버튼

| 버튼 | 위치 | 기능 | 눌렀을 때 |
|---|---|---|---|
| 원정 시작 | 하단 중앙 | 선택 조건으로 런 시작 | 전투 진입 |
| 닫기 | 우측 상단 | 화면 닫기 | 타이틀 화면으로 돌아가기 |

## 화면 이동

| 선택 항목 | 결과 |
|---|---|
| 난이도 카드 | 선택 난이도 변경 |
| 몬스터 카드 | 스타트 몬스터 변경 |
| 포메이션 카드 | 시작 포메이션 변경 |
| 원정 시작 | 런 시작 |
| 닫기 | 타이틀 화면 |
