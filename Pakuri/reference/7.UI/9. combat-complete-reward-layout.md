# 전투 완료 후 보상 화면 UI 기획서

## 화면 목적

전투 완료 후 보상 화면은 방금 끝난 전투의 결과와 지급 보상을 한 번에 확인하고, 필요한 보상 선택을 마친 뒤 다음 일차로 넘어가는 화면이다.

플레이어는 이 화면에서 전투가 끝났다는 사실과 획득한 골드, 어둠의 흔적, 포로, 유물 보상을 아이콘 목록으로 확인한다.

## 화면에 필요한 정보

| 정보 | 필요한 이유 | 표시 방식 |
|---|---|---|
| 전투 완료 상태 | 전투가 끝났고 보상 확인 단계라는 것을 알려줌 | 상단 큰 제목 |
| 현재 일차와 전투 종류 | 일반 전투, 정예 전투, 중간보스, 보스 전투를 구분 | 제목 아래 짧은 줄 |
| 처치한 보스 | 포로 확정 포함 규칙을 이해하게 함 | 상단 보조 줄에 표시 |
| 넥서스 남은 체력 | 전투 결과를 짧게 확인하게 함 | 상단 보조 줄 또는 작은 게이지 |
| 획득 골드 | 다음 상점 이용 가능성을 판단하게 함 | 중앙 보상 아이콘 |
| 획득 어둠의 흔적 | 런 외부 성장 보상을 확인하게 함 | 중앙 보상 아이콘 |
| 포로 보상 | 스킬 습득, 강화, 동화 선택의 시작점 | 중앙 보상 아이콘 |
| 정예 추가 포로 | 정예 전투 선택 보너스를 체감하게 함 | 포로 아이콘에 추가 표식 |
| 유물 보상 | 중간보스와 보스 전투의 핵심 보상 선택 | 중앙 보상 아이콘 |
| 보유 유물 변화 | 새 유물 선택 후 현재 런 강화가 늘었음을 확인 | 선택한 유물 아이콘 강조 |
| 다음 진행 버튼 | 선택을 확정하고 다음 일차로 이동 | 우측 하단 버튼 |

## 1차 화면 스케치

```text
------------------------------------------------------------
전투 완료
3일차 일반 전투 / 처치한 보스: 굶주린 병사 / 넥서스 체력 82/100
------------------------------------------------------------
보상 아이콘

[골드 +10]  [어둠의 흔적 +10]  [보스 포로]  [포로]  [포로]

[유물 없음]
------------------------------------------------------------
선택한 보상
굶주린 병사 / 창병 / 사제
------------------------------------------------------------
                                      [보상 선택으로 이동]
------------------------------------------------------------
```

중간보스나 보스 전투라면 `[유물 없음]` 대신 유물 아이콘 3개를 보여주고, 유물 1개를 선택해야 다음 버튼을 누를 수 있다.

## 화면 구성

| 구역 | 요소 | 기능 |
|---|---|---|
| 상단 | 전투 완료 제목 | 현재 단계가 전투 종료 후 보상 확인임을 표시 |
| 상단 보조 줄 | 일차, 스테이지, 전투 종류, 처치한 보스, 넥서스 남은 체력 | 어떤 전투의 보상인지 확인 |
| 중앙 | 보상 아이콘 목록 | 골드, 어둠의 흔적, 포로, 유물 보상을 아이콘으로 확인 |
| 중앙 하단 | 선택한 보상 | 포로 이름과 선택한 유물 이름 확인 |
| 하단 우측 | 다음 버튼 | 보상 선택 단계 또는 다음 일차로 이동 |

## 상단 정보

| 항목 | 내용 |
|---|---|
| 제목 | `전투 완료`로 표시 |
| 일차 | 현재 스테이지와 일차 표시 |
| 전투 종류 | 일반 전투, 정예 전투, 중간보스 전투, 보스 전투 중 하나 |
| 처치한 보스 | 포로 보상에 포함되는 보스 이름 표시 |
| 넥서스 남은 체력 | 전투 종료 시 남은 체력 표시 |

상단은 전투 중 화면의 정보를 이어받되, 보스 체력 같은 전투 진행 정보는 제거한다.
플레이어가 지금 해야 할 일이 전투 조작이 아니라 보상 확인이라는 점을 분명하게 보여준다.

## 보상 아이콘 목록

| 항목 | 내용 |
|---|---|
| 표시 방식 | 중앙에 아이콘을 가로로 나열 |
| 골드 | 골드 아이콘과 획득량 표시 |
| 어둠의 흔적 | 어둠의 흔적 아이콘과 획득량 표시 |
| 포로 | 포로 얼굴 또는 적 아이콘으로 표시 |
| 보스 포로 | 포로 아이콘 위에 `보스` 표식 표시 |
| 정예 추가 포로 | 포로 아이콘 위에 `정예 추가` 표식 표시 |
| 유물 | 유물 아이콘으로 표시 |
| 유물 없음 | 유물 보상이 없는 전투에서는 작은 `유물 없음` 아이콘 표시 |

보상은 종류별 박스나 긴 설명보다 아이콘을 우선한다.
아이콘 아래에는 이름 또는 수량만 짧게 표시한다.

## 획득 보상 요약

| 항목 | 일반 전투 | 정예 전투 | 중간보스/보스 전투 |
|---|---|---|---|
| 골드 | 표시 | 표시 | 표시 |
| 어둠의 흔적 | 표시 | 표시 | 표시 |
| 포로 수 | 표시 | 기본 포로 + 추가 포로 표시 | 표시 |
| 유물 보상 | 없음 표시 | 없음 표시 | 유물 선택 필요 표시 |

골드, 어둠의 흔적, 포로, 유물은 모두 같은 보상 아이콘 목록 안에 보여준다.
선택 없이 받는 보상은 바로 밝게 표시한다.
선택이 필요한 유물은 선택 전까지 테두리만 강조한다.

## 포로 후보

| 항목 | 내용 |
|---|---|
| 표시 방식 | 보상 아이콘 목록 안에 함께 표시 |
| 아이콘 정보 | 포로 얼굴 또는 적 아이콘, 포로 이름 |
| 보스 포로 | `보스` 표식을 붙여 가장 먼저 표시 |
| 정예 추가 포로 | `정예 추가` 표식을 붙여 일반 포로와 구분 |
| 선택 여부 | 이 화면에서는 포로 후보 확인만 하고, 다음 보상 선택 화면에서 사용 방식을 고른다 |

포로 후보에는 해당 전투의 보스 포로가 반드시 포함된다.
포로가 1명만 등장한 경우에는 보스 포로 아이콘 1개만 보여준다.
정예 전투에서는 추가 포로 1명을 같은 목록 안에 넣되, 정예 보너스라는 표시를 붙인다.

## 유물 후보

| 항목 | 내용 |
|---|---|
| 표시 조건 | 5일차 중간보스, 10일차 중간보스, 보스 전투 완료 |
| 표시 방식 | 보상 아이콘 목록 안에 유물 아이콘 최대 3개 |
| 아이콘 정보 | 유물 이름, 짧은 핵심 효과 |
| 선택 규칙 | 후보 중 1개 선택 |
| 선택 후 | 선택한 유물을 보유 유물 목록에 추가 표시 |

유물 보상이 없는 전투에서는 보상 아이콘 목록 끝에 `유물 없음` 아이콘을 표시한다.
유물 보상이 있는 전투에서는 유물 1개를 선택해야 다음 버튼이 활성화된다.

## 버튼

| 버튼 | 위치 | 기능 | 눌렀을 때 |
|---|---|---|---|
| 보상 선택으로 이동 | 하단 우측 | 포로 사용 선택 단계로 이동 | 포로 선택 화면으로 이동 |
| 다음 일차로 이동 | 하단 우측 | 선택할 보상이 모두 확정된 뒤 다음 일차로 이동 | 다음 일차 선택 화면으로 이동 |

일반 전투와 정예 전투에서는 포로 후보를 확인한 뒤 `보상 선택으로 이동` 버튼을 누른다.
유물 보상이 있는 전투에서는 유물을 먼저 선택해야 다음 버튼을 누를 수 있다.

## 화면 이동

| 상황 | 결과 |
|---|---|
| 일반 전투 완료 | 전투 완료 후 보상 화면으로 이동 |
| 정예 전투 완료 | 전투 완료 후 보상 화면에서 정예 추가 포로를 함께 표시 |
| 중간보스 전투 완료 | 전투 완료 후 보상 화면에서 유물 후보를 표시 |
| 보스 전투 완료 | 전투 완료 후 보상 화면에서 유물 후보와 보스 포로를 표시 |
| 보상 선택으로 이동 | 포로 사용 선택 화면으로 이동 |
| 다음 일차로 이동 | 다음 일차 선택 화면 또는 다음 스테이지로 이동 |

## 예외 상황

| 상황 | 처리 |
|---|---|
| 유물 후보가 3개보다 적음 | 남은 유물 수만큼만 표시 |
| 포로 후보가 1명 | 보스 포로 아이콘 1개만 표시 |
| 보스 전투에서 보스가 여러 명 | 포로 후보에 포함된 보스 포로를 모두 보스 표식으로 표시 |
