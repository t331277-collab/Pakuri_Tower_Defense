# 데미지 표 오버레이 UI 기획

## 화면 참고 이미지

![[docs/png/reference/ui/combat/damage-meter/damage-meter-overlay-example.png]]

## 목적

데미지 표 오버레이는 전투 중 편성된 1번부터 5번까지의 캐릭터가 지금까지 얼마나 피해를 넣었는지 확인하는 화면이다.
기존 전투 화면은 그대로 뒤에 남기고, 사용자가 데미지 표 버튼을 눌렀을 때만 전투 화면 위에 임시로 열린다.

플레이어는 이 화면에서 각 캐릭터의 총 딜량, 최고 딜량 대비 비율, 기본 공격과 액티브 스킬 및 패시브 추가타별 딜량을 한 번에 비교한다.

## 열림 방식

| 상황 | 결과 |
|---|---|
| 데미지 표 버튼을 누름 | 데미지 표 오버레이를 연다 |
| 오버레이가 열린 상태에서 데미지 표 버튼을 다시 누름 | 오버레이를 닫는다 |
| 오버레이의 닫기 버튼을 누름 | 오버레이를 닫는다 |
| 전투가 끝남 | 최종 수치를 유지한 채 닫거나 결과 화면에서 다시 확인할 수 있다 |

오버레이가 열려도 전투는 멈추지 않는다.
표시되는 딜량은 전투가 진행되는 동안 계속 갱신된다.
오버레이가 열린 동안 뒤쪽 전투 화면의 스킬 버튼과 조작 버튼은 직접 누를 수 없는 상태로 보이게 한다.

## 화면 배치

| 영역 | 표시 |
|---|---|
| 화면 전체 | 약 50% 투명도의 회색 덮개 |
| 중앙 | 데미지 표 패널 |
| 패널 상단 | 제목, 간단한 기준 설명, 닫기 버튼 |
| 패널 중단 | 공격 및 스킬 색상 범례 |
| 패널 본문 | 편성 순서별 캐릭터 딜량 목록 |
| 패널 하단 | 닫기 안내 또는 표시 기준 |

회색 덮개는 전투 화면을 완전히 지우지 않는다.
뒤쪽 전투 상황은 흐릿하게 보이지만, 현재 조작 초점은 데미지 표에 있다는 느낌을 준다.

패널은 화면 중앙에 크게 배치한다.
상단 보스 체력과 하단 스킬 묶음을 완전히 가리는 목적이 아니라, 전투 화면 위에 올라온 정보창처럼 보이게 한다.

## 패널 크기와 위치

- 패널은 화면 중앙에 둔다.
- 패널 가로폭은 캐릭터별 긴 막대를 비교하기 충분해야 한다.
- 패널 높이는 편성 1번부터 5번까지 5명의 행이 보이는 것을 기준으로 한다.
- 높이가 부족하면 목록 영역만 세로로 넘겨 본다.
- 화면 바깥을 누르는 동작으로 닫히지 않는다.
- 닫기 버튼 또는 데미지 표 버튼으로 닫는다.

## 캐릭터 행 구성

각 캐릭터는 한 줄 단위로 표시한다.

| 표시 항목 | 내용 |
|---|---|
| 초상 또는 아이콘 | 캐릭터를 구분하는 작은 그림 |
| 이름 | 캐릭터 이름 |
| 편성 순서 | 전투 편성 위치 1, 2, 3, 4, 5 |
| 총 딜량 | 전투 시작 후 해당 캐릭터가 넣은 전체 피해량 |
| 비율 | 최고 총 딜량을 100%로 잡았을 때의 상대 비율 |
| 총 딜량 막대 | 전체 피해량을 길이로 비교하는 큰 막대 |
| 스킬별 딜량 | 막대 아래에 스킬 이름과 누적 피해량을 표시 |

캐릭터 행의 순서는 편성 1, 2, 3, 4, 5 순서로 고정한다.
전투 중 총 딜량 순위가 바뀌어도 행 위치는 바뀌지 않는다.
딜량 비교는 막대 길이와 숫자로만 보여준다.

## 총 딜량 막대 규칙

모든 캐릭터 중 총 딜량이 가장 높은 캐릭터의 막대를 가장 길게 표시한다.
다른 캐릭터의 막대는 최고 총 딜량에 비례해 짧아진다.

예시:

| 편성 | 캐릭터 | 총 딜량 | 막대 길이 |
|---:|---|---:|---:|
| 1 | 세인 | 1,820,400 | 100% |
| 2 | 이브 | 1,421,900 | 약 78% |
| 3 | 린 | 968,120 | 약 53% |
| 4 | 베가 | 611,880 | 약 34% |
| 5 | 아리엘 | 384,260 | 약 21% |

막대는 항상 왼쪽에서 시작한다.
막대가 짧은 캐릭터도 최소한 숫자를 읽을 수 있을 만큼의 표시 폭을 가진다.
총 딜량 숫자는 막대 안쪽 또는 막대 오른쪽에 표시한다.

## 스킬 구간 표시

총 딜량 막대 안은 피해 출처별 비중에 따라 여러 색 구간으로 나눈다.
각 구간은 해당 캐릭터의 총 딜량 안에서 그 공격 또는 스킬이 차지한 비율을 나타낸다.

| 구간 | 표시 예시 |
|---|---|
| 기본 공격 | 빨간색 |
| 액티브 A | 파란색 |
| 액티브 B | 연두색 |
| 패시브 추가타 A | 하늘색 |
| 패시브 추가타 B | 노란색 |

기본 공격과 액티브 스킬만 피해를 넣는 캐릭터는 3가지 색만 보일 수 있다.
패시브가 추가타 피해를 따로 발생시키는 캐릭터는 패시브 추가타 구간까지 포함해 최대 5가지 색이 보일 수 있다.

피해량이 0인 스킬이나 추가타는 막대 구간을 만들지 않거나 목록에서 0으로 표시한다.
소환 피해 또는 지속 피해 전용 구간은 따로 두지 않는다.

## 스킬별 상세 표시

큰 막대 아래에는 스킬 이름과 피해량만 순서대로 표시한다.
별도의 작은 보조 막대는 넣지 않는다.

표시 방식:

- 스킬 이름
- 해당 스킬 누적 피해량

스킬 이름과 딜량 텍스트만 한 줄에 나란히 보여준다.
스킬 순서는 캐릭터의 기본 표시 순서를 따른다.
권장 순서는 기본 공격, 액티브 스킬들, 패시브 추가타들이다.

패시브 추가타가 없는 캐릭터는 해당 항목을 표시하지 않는다.
패시브 추가타가 2종 있는 캐릭터는 액티브 스킬 뒤에 패시브 추가타 2종을 이어서 표시한다.
한 캐릭터가 최대 5개 항목을 가질 수 있으므로, 한 줄에 모두 들어가지 않으면 다음 줄로 자연스럽게 이어 보인다.

## 숫자 표기

| 피해량 범위 | 표기 |
|---|---|
| 0 이상 999 이하 | 그대로 표시 |
| 1,000 이상 | 쉼표 또는 K 표기 |
| 1,000,000 이상 | M 표기 |

긴 숫자를 그대로 표시할 수 있는 영역에서는 `1,820,400`처럼 쉼표를 사용한다.
좁은 영역에서는 `1.82M`, `968K`처럼 줄여 표시한다.

같은 화면 안에서는 표기 방식을 맞춘다.
단, 총 딜량 영역은 읽기 쉬운 방식을 우선한다.

## 보호막 피해 집계

보호막에 준 피해량은 데미지 표에 포함하는 것이 좋다.
플레이어 입장에서는 보호막을 깎는 행동도 전투 기여로 체감되기 때문이다.
보호막 피해를 제외하면 보호막이 많은 적을 상대할 때 실제 기여보다 딜량이 낮아 보일 수 있다.

집계 기준은 다음과 같다.

- 적의 체력에 들어간 피해와 보호막에 들어간 피해를 모두 총 딜량에 포함한다.
- 보호막에 막혀 체력 피해가 0이어도 보호막을 실제로 깎았다면 그만큼 집계한다.
- 보호막을 초과한 피해는 보호막을 깎은 양과 체력을 깎은 양을 합친 실제 적용 피해만 집계한다.
- 무적, 회피, 피해 무효 등으로 아무것도 깎지 못한 피해는 집계하지 않는다.

보호막 피해를 별도 색으로 분리하지 않는다.
피해를 발생시킨 공격 또는 스킬의 구간에 합산한다.

## 갱신 규칙

- 피해가 적의 체력이나 보호막에 실제로 적용된 시점에 누적 딜량을 더한다.
- 방어력, 속성, 치명타, 버프, 디버프가 반영된 최종 적용 피해량을 기준으로 한다.
- 적의 남은 체력과 보호막보다 큰 피해를 넣어도 실제로 깎인 수치만 집계한다.
- 전투 중에는 일정 간격으로 화면 표시를 갱신한다.
- 권장 갱신 간격은 약 0.2초다.
- 수치가 바뀔 때 막대 길이는 부드럽게 변하게 한다.

## 닫기 후 처리

오버레이를 닫아도 누적 딜량은 초기화하지 않는다.
다시 열면 전투 시작 이후 쌓인 최신 누적 딜량을 그대로 보여준다.
전투가 끝나고 다음 전투에 들어가기 전 누적 딜량을 0으로 초기화한다.

## 예외 상황

| 상황 | 처리 |
|---|---|
| 모든 캐릭터의 딜량이 0 | 모든 막대를 빈 상태로 표시하고 총 딜량은 0으로 표시 |
| 최고 딜량이 0 | 비율 계산을 하지 않고 모든 비율을 0%로 표시 |
| 특정 스킬 피해량이 0 | 스킬 목록에는 0으로 표시하고 막대 구간은 생략 가능 |
| 캐릭터가 전투 중 사라짐 | 해당 전투에서 누적한 딜량은 편성 행에 남긴다 |
| 패시브 추가타가 없음 | 패시브 추가타 항목과 색 구간을 표시하지 않는다 |

## 개발 참고용 데이터 기준

데미지 표에 필요한 값은 다음과 같다.

| 값 | 설명 |
|---|---|
| 편성 순서 | 행 순서를 고정하기 위한 1~5 위치 |
| 캐릭터 식별값 | 어떤 캐릭터의 피해인지 구분 |
| 캐릭터 이름 | 화면에 표시할 이름 |
| 캐릭터 아이콘 | 행 왼쪽에 표시할 초상 또는 아이콘 |
| 총 딜량 | 해당 캐릭터의 누적 최종 피해량 |
| 스킬별 딜량 | 기본 공격, 액티브, 패시브 추가타마다 누적한 최종 피해량 |
| 스킬 표시 이름 | 화면에 표시할 스킬 이름 |
| 스킬 표시 색 | 큰 막대 구간에 사용할 색 |

피해 이벤트가 발생할 때마다 캐릭터와 피해 출처를 구분할 수 있어야 한다.
피해 출처를 구분할 수 없는 피해는 기본 공격이나 기타 피해로 묶는다.
패시브 추가타는 원래 액티브 스킬에 합치지 않고 별도 항목으로 표시할 수 있다.

## 개발 참고용 계산 순서

1. 피해가 적에게 실제 적용된다.
2. 실제로 깎인 체력 피해와 보호막 피해를 구한다.
3. 피해를 발생시킨 캐릭터를 찾는다.
4. 피해를 발생시킨 기본 공격, 액티브 스킬, 패시브 추가타를 찾는다.
5. 캐릭터 총 딜량에 실제 적용 피해량을 더한다.
6. 해당 스킬별 딜량에 실제 적용 피해량을 더한다.
7. 화면 갱신 때 최고 총 딜량을 찾는다.
8. 최고 총 딜량 기준으로 각 캐릭터의 큰 막대 길이를 계산한다.
9. 각 캐릭터의 총 딜량 안에서 스킬별 구간 비율을 계산한다.
10. 편성 1~5 순서대로 숫자와 막대를 화면에 표시한다.
