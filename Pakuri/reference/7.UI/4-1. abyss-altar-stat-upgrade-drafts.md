# 심연의 제단 강화 UI

> 목적: 심연의 제단 강화 화면의 표시 기준을 정리한다.

## 공통 전제

| 항목 | 내용 |
|---|---|
| 화면 | 심연의 제단 |
| 강화 대상 | 액티브 스킬 각성, 캐릭터 스탯, 액티브 스킬 |
| 기본 탭 | 각성 탭 |
| 탭 순서 | 각성, 스탯, 액티브 |
| 강화 단계 | 모든 강화 5단계 |
| 강화 방식 | 성공 확률이 있는 강화 시도 |
| 실패 처리 | 실패해도 현재 단계 유지, 단 화면 본문에는 별도 안내하지 않음 |
| 필수 표시 | 현재 단계, 강화 후 단계, 현재 수치, 강화 후 수치, 성공 확률, 강화 시도 비용 |

액티브 스킬 각성이 가장 먼저 해금되므로, 심연의 제단의 탭 순서는 `각성`, `스탯`, `액티브`를 기본으로 한다.
이미지 안의 탭 순서가 다르게 보이더라도 실제 기준은 이 순서를 따른다.

## 참고 이미지

![[docs/png/reference/ui/abyss-altar/stat-upgrade-step-board-v1.png]]

스탯 강화 화면은 단계판형을 기준으로 사용한다.
실패 관련 상시 안내는 화면에서 빼고, 필요 재화는 강화 시도 버튼 안에 함께 표시한다.

![[docs/png/reference/ui/abyss-altar/active-skill-upgrade-step-board-v1.png]]

액티브 스킬 강화 탭도 스탯 강화 화면과 같은 구조를 사용한다.
스탯 비교 대신 현재 스킬 수치와 강화 후 스킬 수치를 비교한다.

![[docs/png/reference/ui/abyss-altar/active-skill-awakening-step-board-v1.png]]

액티브 스킬 각성 탭은 중앙 목록에서 각성 후보별 강화 항목을 보여주고, 누른 각성 효과를 오른쪽에서 현재 수치와 강화 후 수치로 비교한다.
성공 확률은 버튼과 분리하고, 강화 비용은 `강화 시도 3000`처럼 버튼 안에 포함한다.

## 화면 기준

| 항목 | 기준 |
|---|---|
| 화면 구조 | 좌측 캐릭터 목록, 중앙 강화 목록, 우측 선택 정보 |
| 중앙 상단 | 각성, 스탯, 액티브 탭 |
| 진행 표시 | 각 강화 항목마다 5칸 단계 표시 |
| 선택 정보 | 선택한 강화 항목의 전후 수치를 오른쪽에 표시 |
| 강화 비용 | `강화 시도 500`처럼 버튼 문구에 포함 |
| 성공 확률 | 버튼과 분리된 정보 구역에 표시 |
| 실패 유지 문구 | 상시 문구로 표시하지 않음 |
| 보조 버튼 | 강화 버튼 아래에 다른 보조 버튼을 두지 않음 |

오른쪽 선택 정보는 강화 전후 차이를 비교하는 곳이다.
선택한 항목 이름을 가장 위에 두고, 그 아래에 `Lv.0 >>> Lv.1`처럼 현재 단계에서 다음 단계로 넘어가는 표시를 둔다.
단계 표시 아래에는 현재 수치와 강화 후 수치를 나란히 보여준다.

## 전후 수치 표시

| 현재 스탯 | 강화 후 |
|---|---|
| 공격력 120 | 공격력 139 |
| 주문력 90 | 주문력 90 |
| 위력 0% | 위력 0% |
| 모든 속성 0% | 모든 속성 0% |

성공 확률은 전후 수치 비교 아래쪽에 별도 줄로 둔다.
버튼에는 필요한 어둠의 흔적을 합쳐서 `강화 시도 500`처럼 표시한다.
재화가 부족하면 강화 시도 버튼은 어둡게 표시한다.
이때 버튼 문구는 유지하고, 선택 정보 구역에 보유 재화가 부족하다는 상태만 표시한다.

## 스탯 탭 화면 구성

| 구역 | 표시 내용 |
|---|---|
| 상단 | 화면 이름, 보유 어둠의 흔적, 닫기 버튼 |
| 좌측 | 캐릭터 초상, 이름, 선택 상태 |
| 중앙 상단 | 각성, 스탯, 액티브 탭 |
| 중앙 목록 | 체력, 공격력, 주문력, 위력, 모든 속성 |
| 중앙 하단 | 전체 완료 수치 |
| 우측 상단 | 선택한 강화 항목 이름과 단계 변화 |
| 우측 중앙 | 현재 스탯과 강화 후 스탯 비교 |
| 우측 하단 | 성공 확률, 강화 시도 버튼 |

## 액티브 탭 화면 구성

| 구역 | 표시 내용 |
|---|---|
| 중앙 목록 | 액티브 스킬 이름과 5단계 진행 표시 |
| 선택 정보 상단 | 선택한 액티브 스킬 강화 이름 |
| 단계 변화 | 현재 단계에서 다음 단계로 넘어가는 표시 |
| 전후 비교 | 현재 스킬 수치와 강화 후 스킬 수치 |
| 성공 확률 | 비교 영역 아래의 별도 구역 |
| 강화 버튼 | `강화 시도 1300`처럼 비용 포함 |

액티브 탭은 스킬 형태를 바꾸지 않고 화력 수치만 올리는 탭이다.
오른쪽 비교 영역에는 피해, 계수, 투사체 수, 속성처럼 해당 스킬의 핵심 수치를 보여준다.

## 각성 탭 화면 구성

| 구역 | 표시 내용 |
|---|---|
| 중앙 목록 | 액티브 스킬 이름, 각성 후보별 5단계 진행 표시 |
| 선택 정보 상단 | 누른 각성 이름 |
| 단계 변화 | 현재 각성 단계에서 다음 단계로 넘어가는 표시 |
| 전후 비교 | 현재 각성 효과와 강화 후 각성 효과 |
| 성공 확률 | 비교 영역 아래의 별도 구역 |
| 강화 버튼 | `강화 시도 3000`처럼 비용 포함 |

각성 탭은 스킬을 다른 스킬로 교체하지 않고, 각성 효과를 강화하는 탭이다.
중앙 목록에서는 각성 후보 2개의 5단계 강화 진행도를 각각 표시한다.
잠긴 스킬은 잠금 상태만 보여주고 강화 버튼은 활성화하지 않는다.

## 버튼 규칙

| 버튼 | 표시 | 눌렀을 때 |
|---|---|---|
| 강화 시도 | `강화 시도 500`처럼 비용 포함 | 강화 성공 또는 실패 결과 표시 |
| 닫기 | `닫기` | 이전 화면으로 돌아가기 |
