# 타이틀 화면 UI 기획서

## 화면 참고 이미지

![[docs/png/reference/ui/title/title-screen.png]]

## 화면 구성
								
| 구역 | 요소 | 기능 |
|---|---|---|
| 중앙 | 메인 버튼 5개 | 주요 화면으로 이동 |
| 우측 상단 | 보조 버튼 4개 | 업적, 도감 팝업 화면, 클라우드 저장, 설정 열기 |
| 좌측 하단 | 버전 표기 | 현재 버전 표시 |

## 메인 버튼

| 순서 | 버튼 | 기능 | 눌렀을 때 |
|---:|---|---|---|
| 1 | 암시장 | 상품, 재화, 패키지 확인 | 암시장 화면으로 이동 |
| 2 | 심연 강화 | 어둠의 흔적 해금 트리 확인 | 심연 강화 화면으로 이동 |
| 3 | 심연의 제단 | 액티브 스킬 각성, 캐릭터 스탯 강화, 액티브 스킬 강화 | 심연의 제단 화면으로 이동 |
| 4 | 원정 시작 | 전투 시작 또는 스테이지 선택 | 원정 시작 화면으로 이동 |
| 5 | 훈련장 | 전투 연습, 조합 테스트 | 훈련장 화면으로 이동 |

## 메인 버튼 표시

| 항목 | 내용 |
|---|---|
| 배치 | 5개 버튼을 가로로 나열 |
| 이동 | 좌우로 넘겨 다른 버튼 확인 |
| 강조 | 중앙에 있는 버튼을 가장 크게 표시 |
| 화면 밖 버튼 | 좌우 버튼은 일부만 보일 수 있음 |
| 선택 | 버튼 전체를 누를 수 있음 |

## 메인 버튼 잠금

| 버튼 | 해금 조건 | 잠금 상태에서 눌렀을 때 |
|---|---|---|
| 심연의 제단 | 어둠의 흔적 해금 트리에서 캐릭터 강화 관련 노드 1개 이상 해금 | 해금 조건 안내 창 열기 |

## 보조 버튼

| 버튼 | 위치 | 기능 | 눌렀을 때 |
|---|---|---|---|
| 설정 | 우측 상단 가장 오른쪽 | 사운드, 그래픽, 계정, 언어 설정 | 설정 창 열기 |
| 클라우드 저장 | 설정 왼쪽 | 저장 데이터 업로드/다운로드 | 클라우드 저장 창 열기 |
| 도감 | 클라우드 저장 왼쪽 | 적, 아군, 타워, 아이템 정보 확인 | 도감 팝업 화면 열기 |
| 업적 | 도감 왼쪽 | 업적 목록과 보상 확인 | 업적 화면 열기 |
