# 훈련장 화면 UI 기획서

## 화면 구성

| 구역 | 요소 | 기능 |
|---|---|---|
| 좌측 | 테스트 설정 | 훈련 조건 선택 |
| 중앙 | 훈련 전장 미리보기 | 배치와 적 등장 위치 확인 |
| 우측 | 선택 정보 | 선택한 몬스터, 적, 웨이브 정보 표시 |
| 하단 | 실행 버튼 | 훈련 시작 |
| 우측 상단 | 닫기 버튼 | 타이틀 화면으로 돌아가기 |

## 테스트 설정

| 항목 | 내용 |
|---|---|
| 아군 선택 | 테스트할 스쿼드 또는 몬스터 선택 |
| 포메이션 선택 | 사용할 포메이션 선택 |
| 적 선택 | 등장시킬 적 종류 선택 |
| 웨이브 선택 | 단일 적, 일반 웨이브, 보스 테스트 선택 |
| 배속 선택 | 훈련 속도 선택 |

## 훈련 전장 미리보기

| 항목 | 내용 |
|---|---|
| 아군 위치 | 현재 포메이션 기준으로 표시 |
| 적 등장 위치 | 오른쪽 화면 밖 스폰 기준 표시 |
| 넥서스 위치 | 좌측 방어 목표 표시 |
| 시작 전 상태 | 전투 시작 전 배치 확인 |

## 선택 정보

| 항목 | 내용 |
|---|---|
| 선택 아군 | 현재 테스트 대상 아군 표시 |
| 선택 적 | 현재 테스트 대상 적 표시 |
| 선택 포메이션 | 현재 포메이션 이름 표시 |
| 예상 웨이브 | 등장 적 수와 종류 표시 |

## 훈련 중 표시

| 항목 | 내용 |
|---|---|
| 일시정지 | 훈련 일시정지 |
| 재시작 | 같은 조건으로 다시 시작 |
| 종료 | 훈련 종료 후 설정 화면으로 복귀 |
| 피해량 | 아군별 누적 피해량 표시 |

## 버튼

| 버튼 | 위치 | 기능 | 눌렀을 때 |
|---|---|---|---|
| 훈련 시작 | 하단 중앙 | 선택 조건으로 훈련 시작 | 훈련 전투 시작 |
| 재설정 | 테스트 설정 하단 | 선택 조건 초기화 | 기본값으로 변경 |
| 종료 | 훈련 중 | 훈련 종료 | 설정 화면으로 복귀 |
| 닫기 | 우측 상단 | 화면 닫기 | 타이틀 화면으로 돌아가기 |

## 화면 이동

| 선택 항목 | 결과 |
|---|---|
| 훈련 시작 | 훈련 전투 시작 |
| 종료 | 훈련 설정 화면 |
| 닫기 | 타이틀 화면 |
