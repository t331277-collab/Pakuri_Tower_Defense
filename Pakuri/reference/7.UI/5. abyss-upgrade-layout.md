# 심연 강화 화면 UI 기획

## 화면 구성

| 구역 | 요소 | 기능 |
|---|---|---|
| 상단 | 보유 재화 | 현재 보유한 어둠의 흔적 표시 |
| 중앙 | 해금 트리 | 어둠의 흔적 해금 노드 표시 |
| 우측 | 선택 정보 | 선택한 노드의 상세 정보 표시 |
| 하단 | 해금 버튼 | 선택한 노드 해금 |
| 우측 상단 | 닫기 버튼 | 타이틀 화면으로 돌아가기 |

## 보유 재화

| 항목 | 내용 |
|---|---|
| 어둠의 흔적 | 해금 트리에 사용하는 메타 재화 |

## 어둠의 흔적 해금 트리 화면

어둠의 흔적 해금 트리는 `dark-trace-unlock-tree.md`에 들어간 참고 이미지를 기준으로 배치한다.

```text
┌──────────────────────────────────────────────────────────────┐
│ 심연 강화                                      [닫기]         │
│ 어둠의 흔적 0000                                             │
├───────────────────────────────┬──────────────────────────────┤
│ 해금 트리                     │ 선택 정보                    │
│                               │ 노드 아이콘                  │
│             ○                 │ 노드 이름                    │
│           ○   ○               │ 한 줄 설명                   │
│         ○   ○   ○             │ 적용 효과                    │
│       ○   ○   ○   ○           │ 필요 어둠의 흔적             │
│         ○   ○   ○             │ 해금 조건                    │
│           ○   ○               │ 현재 상태                    │
│             ○                 │ [해금]                       │
│                               │                              │
│        아래에서 위로 진행      │                              │
└───────────────────────────────┴──────────────────────────────┘
```

| 구역 | 내용 |
|---|---|
| 중앙 트리 | 세로로 긴 가지형 노드 트리 |
| 진행 방향 | 아래에서 위로 진행 |
| 노드 연결 | 아래 노드와 위 노드를 선으로 연결 |
| 해금 조건 | 선택한 노드의 아래 연결 노드 중 1개 이상 해금 |
| 스크롤 | 트리가 화면보다 길면 중앙 영역만 세로로 넘겨 보기 |
| 오른쪽 빈 공간 | 선택한 노드의 아이콘, 이름, 설명, 효과, 가격, 조건, 상태 표시 |

플레이어는 노드를 눌러 어떤 기능이 열리는지 확인한다.
레퍼런스 이미지처럼 오른쪽 빈 공간은 선택한 노드의 정보 패널로 사용한다.

## 해금 트리 노드 상태

| 상태 | 표시 |
|---|---|
| 잠금 | 어두운 노드, 잠금 아이콘 |
| 해금 가능 | 밝은 테두리, 가격 표시, 해금 버튼 활성화 |
| 재화 부족 | 조건은 만족했지만 가격이 부족한 상태, 가격은 표시 |
| 선택 중 | 선택 테두리, 우측 선택 정보 갱신 |
| 해금 완료 | 밝은 노드, 완료 표시 |

## 선택 정보

노드를 누르면 우측 선택 정보 영역이 갱신된다.

| 항목 | 해금 가능 또는 재화 부족 | 아직 해금 불가 | 해금 완료 |
|---|---|---|---|
| 노드 아이콘 | 표시 | 어둡게 표시 | 표시 |
| 노드 이름 | 표시 | 표시 | 표시 |
| 한 줄 설명 | 표시 | 숨김 | 표시 |
| 적용 효과 | 표시 | 숨김 | 표시 |
| 필요 어둠의 흔적 | 표시 | 숨김 | 해금 완료 |
| 해금 조건 | 표시 | 간단한 잠금 안내만 표시 | 완료 |
| 현재 상태 | 표시 | 아직 도달하지 못함 | 이미 적용 중 |

아직 바로 아래 연결 노드가 열리지 않은 노드는 이름만 보여준다.
가격과 자세한 효과는 숨겨서, 플레이어가 다음 단계에 대한 기대감만 가지게 한다.
해금 가능한 상태이거나 재화만 부족한 상태라면 가격과 자세한 효과를 보여준다.

## 선택 정보 문구 예시

| 선택 상태 | 표시 예시 |
|---|---|
| 아직 해금 불가 | 아래 연결 노드를 먼저 해금해야 합니다. |
| 해금 가능 | 어둠의 흔적을 사용해 이 기능을 해금할 수 있습니다. |
| 재화 부족 | 어둠의 흔적이 부족합니다. |
| 해금 완료 | 이미 해금되어 현재 적용 중입니다. |

| 노드 이름 | 한 줄 설명 | 적용 효과 | 가격 |
|---|---|---|---:|
| 데미지 표 해금 | 전투 중 캐릭터별 누적 딜량을 확인할 수 있습니다. | 전투 화면에 데미지 표 버튼이 열린다. | 30 |
| 전투 배속 1단계 | 전투 속도 1.5배를 사용할 수 있습니다. | 전투 화면의 1.5배속 버튼이 활성화된다. | 30 |
| 전투 배속 2단계 | 전투 속도 2.0배를 사용할 수 있습니다. | 전투 화면의 2.0배속 버튼이 활성화된다. | 100 |
| 전투 배속 3단계 | 전투 속도 3.0배를 사용할 수 있습니다. | 전투 화면의 3.0배속 버튼이 활성화된다. | 240 |
| 골드량 증가 1단계 | 전투 보상 골드가 +5% 증가합니다. | 모든 전투 보상 골드 +5% | 75 |
| 골드량 증가 2단계 | 전투 보상 골드가 +10% 증가합니다. | 모든 전투 보상 골드 +10% | 600 |
| 골드량 증가 3단계 | 전투 보상 골드가 +15% 증가합니다. | 모든 전투 보상 골드 +15% | 5000 |
| 골드량 증가 4단계 | 전투 보상 골드가 +20% 증가합니다. | 모든 전투 보상 골드 +20% | 7700 |
| 골드량 증가 5단계 | 전투 보상 골드가 +25% 증가합니다. | 모든 전투 보상 골드 +25% | 93000 |
| 이벤트 행운 상승 | 이벤트에서 좋은 결과가 나올 확률이 +10%p 증가합니다. | 이벤트 보상 판정 성공 확률 +10%p | 1600 |
| 상점 할인 | 상점 구매 비용이 5% 감소합니다. | 상점 구매 비용 -5% | 1200 |
| 전투 시작 보호막 | 전투 시작 시 모든 아군에게 최대 체력 10% 보호막을 부여합니다. | 모든 아군 최대 체력 10% 보호막 | 900 |
| 유물 등급 보정 | 희귀 등급 이상 유물이 나올 확률이 +5%p 증가합니다. | 희귀 등급 이상 유물 등장 확률 +5%p | 42000 |
| 전투 중 회복 보정 | 전투 중 받는 회복량이 +15% 증가합니다. | 받는 회복량 +15% | 3700 |
| 심연의 제단 해금 | 캐릭터 강화 화면을 사용할 수 있습니다. | 타이틀 화면에서 심연의 제단 버튼이 활성화된다. | 20 |
