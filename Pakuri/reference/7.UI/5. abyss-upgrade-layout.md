# 심연 강화 화면 UI 기획서

## 화면 구성

| 구역 | 요소 | 기능 |
|---|---|---|
| 상단 | 보유 재화 | 어둠 계열 재화 표시 |
| 좌측 | 강화 분류 | 성장 대상 선택 |
| 중앙 | 성장 노드 목록 | 강화 가능한 항목 표시 |
| 우측 | 선택 노드 정보 | 선택한 강화 정보 표시 |
| 하단 | 강화 버튼 | 선택 노드 강화 |
| 우측 상단 | 닫기 버튼 | 타이틀 화면으로 돌아가기 |

## 강화 분류

| 순서 | 분류 | 기능 |
|---:|---|---|
| 1 | 공통 스탯 | 캐릭터별 공통 스탯 강화 |
| 2 | 액티브 스킬 | 캐릭터별 액티브 스킬 강화 |
| 3 | 해금 트리 | 어둠의 흔적 해금 트리 확인 |

## 보유 재화

| 항목 | 내용 |
|---|---|
| 어둠의 흔적 | 기본 메타 성장 재화 |
| 어둠의 결정 | 상위 재화 |
| 어둠의 정수 | 상위 재화 |
| 어둠의 심핵 | 상위 재화 |
| 심연의 성흔 | 최상위 재화 |

## 성장 노드 목록

| 항목 | 내용 |
|---|---|
| 표시 방식 | 중앙 영역에 노드 카드 또는 트리 형태로 표시 |
| 노드 정보 | 이름, 현재 단계, 최대 단계 |
| 강화 가능 | 필요한 재화가 있으면 활성 표시 |
| 강화 불가 | 재화 부족 또는 선행 조건 부족 표시 |
| 최대 강화 | 최대 단계 도달 표시 |

## 선택 노드 정보

| 항목 | 내용 |
|---|---|
| 노드 이름 | 선택한 성장 항목 이름 |
| 현재 단계 | 현재 강화 단계 |
| 다음 단계 | 강화 후 효과 |
| 필요 재화 | 강화에 필요한 재화와 수량 |
| 적용 대상 | 강화가 적용되는 캐릭터 또는 스킬 |

## 버튼

| 버튼 | 위치 | 기능 | 눌렀을 때 |
|---|---|---|---|
| 강화 | 하단 | 선택 노드 강화 | 단계 상승 |
| 초기화 | 우측 정보 영역 | 투자 재화 반환 | 초기화 확인 창 열기 |
| 분류 선택 | 좌측 | 강화 분류 변경 | 중앙 목록 갱신 |
| 닫기 | 우측 상단 | 화면 닫기 | 타이틀 화면으로 돌아가기 |

## 화면 이동

| 선택 항목 | 결과 |
|---|---|
| 강화 분류 | 해당 성장 목록 표시 |
| 성장 노드 | 선택 노드 정보 표시 |
| 강화 | 선택 노드 단계 상승 |
| 초기화 | 초기화 확인 창 |
| 닫기 | 타이틀 화면 |
