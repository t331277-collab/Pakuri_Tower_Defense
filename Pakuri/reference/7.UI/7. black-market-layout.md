# 암시장 화면 UI 기획서

## 화면 구성

| 구역 | 요소 | 기능 |
|---|---|---|
| 상단 | 보유 재화 | 현재 보유 재화 표시 |
| 좌측 | 상품 분류 | 상품 종류 선택 |
| 중앙 | 상품 목록 | 구매 가능한 상품 표시 |
| 우측 | 선택 상품 정보 | 선택한 상품 상세 표시 |
| 하단 | 구매 버튼 | 선택 상품 구매 |
| 우측 상단 | 닫기 버튼 | 타이틀 화면으로 돌아가기 |

## 상품 분류

| 순서 | 분류 | 기능 |
|---:|---|---|
| 1 | 추천 | 주요 상품 표시 |
| 2 | 재화 | 재화 상품 표시 |
| 3 | 패키지 | 묶음 상품 표시 |
| 4 | 한정 | 기간 한정 상품 표시 |

## 상품 목록

| 항목 | 내용 |
|---|---|
| 표시 방식 | 중앙 영역에 카드 목록 표시 |
| 상품 카드 | 아이콘, 상품명, 가격 표시 |
| 구매 완료 | 이미 구매한 상품 표시 |
| 한정 상품 | 남은 시간 표시 |
| 선택 | 상품 카드를 누르면 우측 정보 갱신 |

## 선택 상품 정보

| 항목 | 내용 |
|---|---|
| 상품명 | 선택한 상품 이름 |
| 상품 이미지 | 대표 이미지 또는 아이콘 |
| 구성품 | 포함된 재화와 아이템 목록 |
| 가격 | 구매 가격 |
| 구매 제한 | 구매 횟수 제한이 있으면 표시 |

## 구매 확인 창

| 항목 | 내용 |
|---|---|
| 상품명 | 구매할 상품 이름 |
| 가격 | 결제 또는 소비 재화 |
| 구성품 | 받을 상품 목록 |
| 확인 | 구매 진행 |
| 취소 | 구매 취소 |

## 버튼

| 버튼 | 위치 | 기능 | 눌렀을 때 |
|---|---|---|---|
| 구매 | 하단 | 선택 상품 구매 | 구매 확인 창 열기 |
| 분류 선택 | 좌측 | 상품 분류 변경 | 중앙 상품 목록 갱신 |
| 닫기 | 우측 상단 | 화면 닫기 | 타이틀 화면으로 돌아가기 |

## 화면 이동

| 선택 항목 | 결과 |
|---|---|
| 상품 분류 | 해당 상품 목록 표시 |
| 상품 카드 | 상품 정보 표시 |
| 구매 | 구매 확인 창 |
| 닫기 | 타이틀 화면 |
