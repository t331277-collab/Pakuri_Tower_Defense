## 데미지 표 오버레이 참고 이미지

![[docs/png/reference/ui/combat/damage-meter/damage-meter-overlay-example.png|697]]

상세 표시 규칙과 개발 참고 내용은 [[8-1. damage-meter-overlay-layout|데미지 표 오버레이 UI 기획]] 문서를 따른다.

데미지 표 버튼을 누르면 전투 화면 전체 위에 회색 반투명 덮개가 깔리고, 그 위에 데미지 표 패널이 열린다.
이 이미지는 전투 중 데미지 표를 펼쳤을 때의 기준 예시로 사용한다.
기존 전투 화면의 상단 보스 체력, 좌측 조작 버튼, 하단 스킬 묶음은 뒤쪽에 남아 있지만 회색 덮개 때문에 직접 조작 대상처럼 보이지 않는다.

데미지 표 패널은 화면 중앙에 크게 배치한다.
패널은 전투 화면을 완전히 대체하는 새 화면이 아니라, 전투 화면 위에 얹히는 임시 정보창이다.
닫기 버튼이나 데미지 표 버튼을 다시 누르면 전투 화면으로 돌아간다.

## 화면 구성

| 구역 | 요소 | 기능 |
|---|---|---|
| 상단 좌측 | 난이도, 보유 유물 아이콘, 넥서스 체력, 현재 골드 | 현재 전투 상태와 보유 유물 확인 |
| 상단 중앙 | 보스 체력 | 현재 보스 체력 확인 |
| 상단 우측 | 설정, 남은 적, 데미지 표 토글 | 설정 창 열기, 남은 적 확인, 데미지 표 열기 |
| 중앙 전체 | 전투 화면 | 아군, 적, 투사체, 장판, 피해 표시 |
| 좌측 | 유물 시너지 | 현재 유물 시너지 진행도 확인 |
| 좌측 하단 | 배속, 조준 모드 | 전투 속도 변경, 조준 모드 전환 |
| 좌측 하단 | 캐릭터 스킬 묶음 | 캐릭터별 선택 액티브 스킬 상태 확인 |

## 전투 화면

| 항목 | 내용 |
|---|---|
| 표시 범위 | 화면 전체를 전투 화면으로 사용 |
| 하단 처리 | 하단 전체를 별도 UI 칸으로 막지 않음 |
| UI 배치 | 필요한 정보만 전투 화면 위에 작게 겹쳐 표시 |
| 보스 알림 | 별도 등장 알림 문구는 사용하지 않음 |

## 공격 대상 규칙

| 항목 | 내용 |
|---|---|
| 기본 조준 | 자동 조준 |
| 자동 조준 대상 | 화면 안에 있는 가장 가까운 적 |
| 수동 조준 기준 | 플레이어가 화면 안에서 누른 지점 |
| 거리 제한 | 별도 거리 제한을 사용하지 않음 |
| 화면 밖 적 | 자동 조준 대상에서 제외 |
| 화면 밖 입력 | 수동 조준 기준점으로 사용하지 않음 |
| 세부 규칙 | [`aiming-system.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F3.combat%2Faiming-system) 문서 기준 |

## 조준 모드 토글

| 항목 | 내용 |
|---|---|
| 표시 조건 | 전술 지휘 해금 후 표시 |
| 위치 | 좌측 하단, 배속 버튼 근처 |
| 기본 상태 | 자동 조준 |
| 토글 상태 | 자동 조준, 수동 조준 |
| 눌렀을 때 | 두 조준 모드를 번갈아 전환 |

전술 지휘를 해금하기 전에는 조준 모드 토글을 표시하지 않는다.
해금 전 전투는 자동 조준 상태로만 진행된다.

## 상단 좌측 정보

| 항목 | 내용 |
|---|---|
| 난이도 | 가장 왼쪽 위에 현재 난이도 또는 진행 구간 표시 |
| 보유 유물 | 난이도 텍스트 바로 오른쪽에서 시작 |
| 유물 배치 | 아이콘만 가로로 나열 |
| 넥서스 체력 | 난이도와 유물 줄 아래쪽에 숫자 또는 게이지로 표시 |
| 현재 골드 | 넥서스 체력 옆 또는 아래에 표시 |

상단 좌측 정보는 전투 중 가장 자주 확인하는 상태를 모아둔다.
보유 유물은 별도 칸을 만들지 않고, 난이도 옆에 작은 아이콘만 이어 붙인다.
유물 아이콘에는 테두리, 슬롯 배경, 별도 카드 형태를 쓰지 않는다.

## 보유 유물 아이콘

| 항목 | 내용 |
|---|---|
| 위치 | 상단 좌측, 난이도 표시 바로 옆 |
| 표시 | 보유 유물 아이콘 약 7개 |
| 묶음 | 같은 종류의 유물은 가까이 나열 |
| 예시 | 왕관, 해골, 보석, 책, 검, 심장, 플라스크 |
| 테두리 | 사용하지 않음 |

## 상단 중앙 보스 체력

| 항목 | 내용 |
|---|---|
| 위치 | 화면 상단 중앙 |
| 표시 | 보스 이름과 체력 게이지 |
| 등장 조건 | 보스가 있을 때 표시 |
| 숨김 조건 | 보스가 없으면 표시하지 않음 |
| 유물 아이콘 | 보스 체력 위에는 배치하지 않음 |

보스 체력은 전투 시야를 가리지 않도록 상단 중앙에 길게 둔다.
보스 등장 알림 문구는 별도로 띄우지 않고, 보스 체력 게이지 표시만으로 보스 상태를 알린다.

## 상단 우측 정보

| 항목 | 내용 |
|---|---|
| 설정 | 우측 상단 가장 끝에 배치 |
| 남은 적 | 설정 근처에 현재 남은 적 수 표시 |
| 데미지 표 토글 | 남은 적 아래에 작은 버튼으로 표시 |
| 기본 상태 | OFF |
| OFF 상태 | 버튼만 보이고 표 내용은 보이지 않음 |

## 유물 시너지

| 항목 | 내용 |
|---|---|
| 위치 | 좌측 |
| 토글 상태 | ON |
| 표시 방식 | 작은 아이콘과 시너지 이름, 진행도 표시 |
| 접기 | 토글 버튼을 누르면 목록을 접음 |

| 시너지 | 표시 |
|---|---|
| 정령왕 | 정령왕 3/4 |
| 처형관 | 처형관 2/4 |
| 파수꾼 | 파수꾼 1/3 |

유물 시너지는 전투 화면 왼쪽에 작게 붙여둔다.
목록이 펼쳐진 상태에서는 현재 맞춰진 시너지와 다음 단계까지 필요한 수를 보여준다.
각 줄은 작은 아이콘, 시너지 이름, 진행도 숫자 순서로 표시한다.
토글을 OFF로 바꾸면 `유물 OFF` 버튼만 남기고 목록은 숨긴다.

## 데미지 표 토글

| 항목 | 내용 |
|---|---|
| 위치 | 상단 우측, 남은 적 아래 |
| 토글 상태 | OFF |
| 표시 문구 | 데미지 표 OFF |
| 눌렀을 때 | 실시간 데미지 표를 열거나 닫음 |

데미지 표는 기본적으로 닫힌 상태다.
OFF 상태에서는 전투 화면을 가리지 않도록 버튼만 보인다.
ON 상태가 되면 버튼 아래로 캐릭터별 누적 피해량과 비중을 표시한다.

## 캐릭터 스킬 묶음

| 항목 | 내용 |
|---|---|
| 위치 | 좌측 하단 |
| 배치 | 위 줄 2명, 아래 줄 3명 |
| 캐릭터 표시 | 작은 캐릭터 얼굴 아이콘 |
| 스킬 표시 | 캐릭터 얼굴 옆에 선택된 액티브 스킬 3개 표시 |
| 스킬 모양 | 작은 육각형 아이콘 |
| 장전 완료 | 밝게 표시 |
| 장전 중 | 어둡게 표시하거나 덮개 표시 |
| 탄환 수 | 스킬 아이콘 안쪽 또는 근처에 작은 숫자로 표시 |

캐릭터 스킬 묶음은 하단 전체를 차지하지 않는다.
전투 화면 위에 작게 얹는 형태로만 표시한다.
각 캐릭터는 얼굴 아이콘 1개와 선택된 액티브 스킬 3개를 한 묶음으로 가진다.
스킬 아이콘은 원작처럼 작은 육각형 슬롯으로 표시하고, 현재 장전 상태와 탄환 수를 함께 보여준다.

```text
좌측 하단 배치

[캐릭터] ⬡ ⬡ ⬡    [캐릭터] ⬡ ⬡ ⬡
[캐릭터] ⬡ ⬡ ⬡    [캐릭터] ⬡ ⬡ ⬡    [캐릭터] ⬡ ⬡ ⬡
```

| 스킬 상태 | 표시 |
|---|---|
| 사용 가능 | 아이콘을 밝게 표시 |
| 재장전 중 | 아이콘 위에 어두운 덮개 표시 |
| 탄환 있음 | 작은 숫자로 현재 탄환 수 표시 |
| 탄환 없음 | 숫자를 0으로 표시하거나 아이콘을 어둡게 표시 |
| 조준 모드 | 조준 모드 토글에서만 표시 |
