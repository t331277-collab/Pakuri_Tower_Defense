# 원소 포메이션

> 원작 명칭: Element Formation

## 원작 참고 이미지
![Element Formation](element-formation.png)

## 타워 위치
| 원작 번호 | 프로젝트 슬롯 | 좌표 |
|---|---|---:|
| 1번 | mid-center | `(6,8)` |
| 2번 | front-top | `(8,12)` |
| 3번 | front-bottom | `(8,4)` |
| 4번 | rear-top | `(4,12)` |
| 5번 | rear-bottom | `(4,4)` |

## 원작 효과
1번: 화염/냉기/번개/산성 피해 스킬 1개마다 모든 몬스터의 위력 증가 2/2.5/3/4/5%  
2번: 화염 피해 스킬을 가진 몬스터 배치 시 모든 몬스터의 화염 피해 증가 15/20/25/32.5/40%  
3번: 산성 피해 스킬을 가진 몬스터 배치 시 모든 몬스터의 산성 피해 증가 15/20/25/32.5/40%  
4번: 번개 피해 스킬을 가진 몬스터 배치 시 모든 몬스터의 번개 피해 증가 15/20/25/32.5/40%  
5번: 냉기 피해 스킬을 가진 몬스터 배치 시 모든 몬스터의 냉기 피해 증가 15/20/25/32.5/40%

## 프로젝트 반영 메모
- 화염, 냉기, 번개, 산성 계열을 묶는 속성 포메이션으로 본다.
- 현재 프로젝트 확정 속성에는 산성이 없으므로 산성은 독/부패 계열 또는 후속 속성 후보로 둔다.
