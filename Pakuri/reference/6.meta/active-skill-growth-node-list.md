# 액티브 스킬 강화 목록

> 목적: `어둠의 흔적`을 사용해 액티브 스킬의 기본 화력을 올리는 구조를 정의한다.

액티브 스킬 강화는 스킬 형태를 바꾸지 않는다.
도탄, 타격 범위 증가, 추가 타겟 같은 변주는 각 캐릭터의 액티브 스킬 문서 안에서 다룬다.

## 1. 기본 규칙

| 항목 | 규칙 |
|---|---|
| 사용 재화 | 어둠의 흔적 |
| 강화 대상 | 캐릭터별 액티브 스킬 |
| 적용 범위 | 런 시작 전 영구 성장 |
| 관리 단위 | 캐릭터 1명 + 액티브 스킬 1개 |
| 사용 조건 1 | 해금 트리에서 액티브 스킬 강화 해금 |
| 사용 조건 2 | 해당 캐릭터의 모든 스탯 강화 완료 |
| 각성 관계 | 액티브 스킬 각성 여부와 별개로 스킬의 기본 화력만 강화 |
| 초기화 | 캐릭터 단위 초기화에 포함 |
| 강화 방식 | 단계별 성공 확률을 가진 확률 강화 |
| 실패 처리 | 실패해도 현재 단계 유지 |

해금 트리에서 액티브 스킬 강화 노드를 열 수는 있지만, 실제 강화는 캐릭터 스탯 강화 완료 후 사용할 수 있다.
액티브 스킬 각성은 이보다 먼저 열리는 분류이므로, 액티브 스킬 강화 완료가 각성의 조건이 되지 않는다.
성공률과 시도 비용은 [`enhancement-probability-rule.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F6.meta%2Fenhancement-probability-rule) 문서를 따른다.

## 2. 강화 항목

| 강화 항목 | 최대 단계 | 단계당 효과 | 5단계 총 효과 | 역할 |
|---|---:|---|---|---|
| 스킬 위력 강화 | 5 | 스킬 위력 +20% | 스킬 위력 +100% | 해당 스킬의 기본 피해 증가 |
| 공격력 계열 강화 | 5 | 공격력 계수 +20% | 공격력 계수 +100% | 공격력 기반 스킬의 피해 증가 |
| 주문력 계열 강화 | 5 | 주문력 계수 +20% | 주문력 계수 +100% | 주문력 기반 스킬의 피해 증가 |
| 속성 피해 강화 | 5 | 해당 속성 피해 +14% | 해당 속성 피해 +70% | 해당 스킬의 주 속성 피해 증가 |
| 효과량 강화 | 5 | 효과량 +16% | 효과량 +80% | 버프형 스킬의 효과 증가 |
| 지속시간 강화 | 5 | 지속시간 +12% | 지속시간 +60% | 버프형 스킬의 유지 시간 증가 |

각 액티브 스킬은 위 항목 중 스킬 성격에 맞는 2개 강화 항목을 가진다.
공격력 기반 스킬은 공격력 계열 강화와 스킬 위력 강화를 우선 사용한다.
주문력 기반 스킬은 주문력 계열 강화와 스킬 위력 강화를 우선 사용한다.
버프형 스킬은 스킬 위력 대신 효과량 강화를 사용할 수 있다.

## 3. 강화 확률과 비용

모든 액티브 스킬 강화는 같은 성공률과 비용 곡선을 사용한다.
실패해도 단계는 하락하지 않는다.

| 목표 단계 | 성공 확률 | 실패 시 | 필요 어둠의 흔적 |
|---:|---:|---|---:|
| 1 | 100% | 단계 유지 | 800 |
| 2 | 65% | 단계 유지 | 1300 |
| 3 | 35% | 단계 유지 | 2100 |
| 4 | 15% | 단계 유지 | 3400 |
| 5 | 7% | 단계 유지 | 5400 |

## 4. 강화 예시

| 스킬 유형 | 강화 1 | 강화 2 |
|---|---|---|
| 공격력 기반 투사체 | 공격력 계열 강화 | 스킬 위력 강화 |
| 주문력 기반 광선 | 주문력 계열 강화 | 속성 피해 강화 |
| 장판 피해 | 스킬 위력 강화 | 속성 피해 강화 |
| 단일 처형 | 공격력 계열 강화 | 스킬 위력 강화 |
| 파티 버프 | 효과량 강화 | 지속시간 강화 |

## 5. 완료 조건

| 항목 | 내용 |
|---|---|
| 액티브 스킬 강화 완료 | 해당 스킬의 강화 항목이 모두 최대 단계 |
| 완료 후 영향 | 해당 스킬의 화력 강화 완료 표시 |
| 미완료 상태 | 각성 상태와 무관하게 액티브 스킬 강화 진행도만 표시 |
