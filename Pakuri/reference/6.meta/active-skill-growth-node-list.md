# 액티브 스킬 메타 강화 목록

> 목적: `어둠의 흔적`을 사용해 캐릭터별 액티브 스킬을 강화하는 구조를 정의한다.

액티브 강화는 모든 스킬에 같은 노드를 붙이지 않는다.
각 캐릭터의 각 액티브 스킬마다 역할이 다르므로, 강화 노드도 스킬별로 다르게 설계한다.

관련 문서:
- 공통 스탯 강화는 [`meta-growth-node-list.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F6.meta%2Fmeta-growth-node-list) 참고.

## 1. 기본 규칙

| 항목 | 규칙 |
|---|---|
| 사용 재화 | 어둠의 흔적 |
| 강화 대상 | 캐릭터별 액티브 스킬 |
| 적용 범위 | 런 시작 전 영구 성장 |
| 관리 단위 | 캐릭터 1명 + 액티브 스킬 1개 |
| 패시브 | 메타 성장에서 다루지 않음 |
| 초기화 | 캐릭터 단위 초기화에 포함 |

액티브 강화는 스킬별 정체성을 살리는 방향으로 둔다.
투사체 스킬은 탄창, 관통, 추가 타격을 강화하고, 장판 스킬은 범위, 지속시간, 상태 부여를 강화하며, 버프 스킬은 지속시간, 효과량, 적용 대상을 강화한다.

## 2. 공통 비용

모든 액티브 스킬 강화는 같은 비용 곡선을 사용한다.
스킬마다 강화 효과는 다르지만, 비용 차이는 두지 않는다.

| 최대 레벨 | 레벨별 비용 |
|---:|---:|
| 5 | 80 / 160 / 280 / 480 / 800 |

## 3. 액티브 강화 작성 규칙

| 항목 | 규칙 |
|---|---|
| 노드 수 | 스킬당 2~3개 |
| 최대 레벨 | 기본 5단계 |
| 노드 중복 | 같은 이름의 공통 노드를 억지로 반복하지 않는다. |
| 수치 표기 | 레벨당 효과를 적는다. 비용은 모든 액티브 강화가 동일하다. |
| 결전기 제한 | 전장 전체/보스 대응 스킬도 다른 액티브와 같은 비용을 사용한다. |

## 9. 후속 결정 필요 항목

- 각 액티브 스킬의 실제 런 내부 특성과 메타 강화 노드가 겹치지 않는지 검토
- 스킬별 노드 수를 2개로 고정할지, 핵심 스킬만 3개까지 허용할지 결정
- 공통 액티브 강화 비용과 전투 보상량의 체감 속도 검증
