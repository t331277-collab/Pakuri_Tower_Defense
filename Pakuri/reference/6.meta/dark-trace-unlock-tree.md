# 어둠의 흔적 해금 트리

![[dark-unlock-tree-example.png]]

## 1. 기본 규칙

| 항목 | 내용 |
|---|---|
| 사용 재화 | 어둠의 흔적 |
| 화면 형태 | 아래에서 위로 뻗어 올라가는 노드 트리 |
| 진행 방향 | 하단 시작 노드에서 상단 노드로 진행 |
| 노드 표시 | 아이콘, 짧은 이름, 해금 상태 |
| 상세 표시 | 노드를 눌렀을 때 오른쪽 선택 정보 영역에 표시 |
| 초기화 | 해금 트리는 초기화하지 않음 |

해금 트리는 플레이어가 어둠의 흔적을 사용해 전투 보조, 보상, 진행 확장, 캐릭터 강화 관련 기능을 여는 화면이다.
플레이어는 노드의 아이콘과 이름을 보고 선택하며, 자세한 내용은 노드를 눌렀을 때 확인한다.

## 2. 기획 의도

초반 해금 구간에는 게임 진행에 직접적인 영향을 주거나, 편의성과 플레이 경험에 유의미한 차이를 주는 기능을 많이 배치한다.
초반에 해금하는 기능은 플레이어가 “다음 판이 바로 달라졌다”고 느껴야 한다.

초반 주요 해금 예시는 다음과 같다.

| 초반 해금 | 의도 |
|---|---|
| 심연의 제단 해금 | 캐릭터 강화 화면을 열어 장기 성장의 목표를 빨리 보여준다. |
| 액티브 스킬 각성 | 보유한 액티브 스킬에 도탄, 범위 증가, 추가 타겟 같은 변주 효과를 먼저 선택하고 확률 강화할 수 있게 한다. |
| 캐릭터 스탯 강화 | 캐릭터의 기본 체급을 확률 강화할 수 있게 한다. |
| 액티브 스킬 강화 | 스탯 강화를 완료한 캐릭터의 액티브 스킬 화력을 확률 강화할 수 있게 한다. |
| 데미지 표 해금 | 전투 결과를 비교하고 성장 체감을 확인할 수 있게 한다. |
| 전술 지휘 | 전투 중 자동 조준과 수동 조준을 전환할 수 있게 한다. |
| 전투 배속 1단계 | 전투 속도 1.5배를 열어 반복 전투의 피로도를 줄인다. |
| 전투 배속 2단계 | 전투 속도 2.0배를 초반 구간 안에서 1단계와 약간 떨어진 위치에 배치한다. |
| 전투 배속 3단계 | 전투 속도 3.0배를 초반 후반부에 배치해, 배속 해금이 너무 연속으로 끝나지 않게 한다. |
| 골드량 증가 1단계 | 전투 보상 골드 +5%로 다음 전투의 초반 선택 폭을 늘린다. |

전투 배속 1단계, 2단계, 3단계는 모두 초반 구간에 두되, 서로 바로 붙이지 않는다.
초반 반복 전투 피로를 빠르게 줄이면서도, 배속 해금이 한 번에 끝나는 느낌은 피한다.
골드량 증가 1~5단계는 초반, 중반, 후반에 넓게 퍼뜨려 장기적으로 계속 목표가 되게 한다.
상단으로 갈수록 장기 목표, 높은 가격, 누적 보너스, 진행 확장 기능을 배치한다.
초반에는 기능 해금과 체감 변화가 중심이고, 후반에는 효율 상승과 장기 보상이 중심이다.

해금 효과 수치는 1차 기획 기준으로 아래 값을 사용한다.

| 계열 | 수치 기준 |
|---|---|
| 전투 배속 | 1단계 1.5배, 2단계 2.0배, 3단계 3.0배 |
| 골드량 증가 | 1단계 +5%, 2단계 +10%, 3단계 +15%, 4단계 +20%, 5단계 +25% |
| 어둠의 흔적 획득 증가 | 전투 보상 어둠의 흔적 +10% |
| 상점 할인 | 상점 구매 비용 -5% |
| 이벤트 행운 상승 | 좋은 결과 판정 확률 +10%p |
| 유물 등급 보정 | 희귀 등급 이상 유물 등장 확률 +5%p |
| 전투 시작 보호막 | 전투 시작 시 모든 아군에게 최대 체력 10% 보호막 |
| 전투 중 회복 보정 | 전투 중 받는 회복량 +15% |

가격은 초반 기능 해금은 낮게 유지하고, 후반 장기 목표는 기존 초안 대비 10배에서 100배 정도 높인다.
후반 노드는 한 번에 여러 개를 빠르게 여는 구간이 아니라, 장기 반복 플레이의 목표로 둔다.

## 3. 해금 조건

| 항목 | 내용 |
|---|---|
| 시작 위치 | 트리 하단의 시작 노드 |
| 기본 진행 | 아래 노드를 해금한 뒤 그 위쪽 노드로 진행 |
| 연결 조건 | 선택한 노드와 연결된 아래쪽 노드 중 1개 이상이 해금되어 있으면 해금 가능 |
| 잠금 상태 | 연결된 아래쪽 노드가 하나도 해금되지 않았으면 잠금 |
| 해금 가능 상태 | 조건을 만족하고 어둠의 흔적이 충분하면 해금 가능 표시 |
| 해금 완료 상태 | 이미 해금한 노드는 밝게 표시 |
| 심연의 제단 해금 | 캐릭터 강화 관련 노드 1개 이상 해금 시 타이틀 화면의 심연의 제단 버튼 활성화 |

## 4. 화면 노드 흐름

```text
     ○   ○   ○   ○   ○   ○   ○       ┌ 선택 정보 ┐
     │╲  │╲  │╲  │╲  │╲  │╲  │       │ 아이콘    │
     ○   ○   ○   ○   ○   ○   ○       │ 노드 이름 │
      ╲  │╲  │╲  │╲  │╲  │  ╱        │ 설명      │
       ○   ○   ○   ○   ○   ○         │ 가격      │
        ╲  │╲  │╲  │╲  │  ╱          │ 조건      │
         ○   ○   ○   ○   ○           │ 상태      │
            ╲  │  ╱                  │ [해금]    │
               ○                     └───────────┘
             ╱   ╲
            ○     ○
              ╲ ╱
               ○

          아래에서 위로 해금 진행
```

| 구역 | 내용 |
|---|---|
| 하단 | 처음 접근 가능한 시작 노드 배치 |
| 중단 | 여러 갈래로 나뉘는 주요 해금 노드 배치 |
| 상단 | 높은 비용의 장기 해금 노드 배치 |
| 연결선 | 해금 가능 여부를 판단하는 선행 관계 표시 |
| 오른쪽 빈 공간 | 레퍼런스 이미지처럼 선택한 노드의 설명 패널 표시 |
| 빈 배경 | 아직 이어지지 않은 구간은 배경만 표시 |

오른쪽 빈 공간은 노드를 눌렀을 때 선택 정보가 나오는 자리다.
해금 트리의 노드를 선택하면 오른쪽에 노드 이름, 아이콘, 한 줄 설명, 적용 효과, 가격, 해금 조건, 현재 상태가 표시된다.

단, 아직 해금 가능한 상태가 아닌 노드는 세부 내용을 숨긴다.
바로 아래 연결 노드가 활성화되지 않은 노드를 누르면 노드 이름만 보여주고, 가격과 구체 효과는 보여주지 않는다.
이때 이름과 어두운 아이콘만으로 “나중에 이런 계열의 기능이 열릴 수 있다”는 기대감만 준다.

## 5. 노드 상태

| 상태 | 표시 |
|---|---|
| 잠금 | 어두운 노드, 잠금 아이콘 |
| 해금 가능 | 밝은 테두리, 가격 표시, 해금 버튼 활성화 |
| 재화 부족 | 조건은 만족했지만 가격이 부족한 상태, 가격은 표시 |
| 선택 중 | 선택 테두리, 선택 정보 영역 갱신 |
| 해금 완료 | 밝은 노드, 완료 표시 |

## 6. 노드를 눌렀을 때 나오는 설명

플레이어가 해금 트리의 노드를 누르면 화면 오른쪽 선택 정보 영역에 아래 내용을 표시한다.

| 표시 항목 | 해금 가능 또는 재화 부족 | 아직 해금 불가 | 해금 완료 |
|---|---|---|---|
| 노드 아이콘 | 표시 | 어둡게 표시 | 표시 |
| 노드 이름 | 표시 | 표시 | 표시 |
| 한 줄 설명 | 표시 | 숨김 | 표시 |
| 적용 효과 | 표시 | 숨김 | 표시 |
| 필요 재화 | 표시 | 숨김 | 해금 완료 |
| 해금 조건 | 표시 | 간단한 잠금 안내만 표시 | 완료 |
| 현재 상태 | 표시 | 아직 도달하지 못함 | 이미 적용 중 |
| 해금 버튼 | 조건 충족 시 표시 | 표시하지 않음 | 해금 완료 표시 |

### 아직 해금 불가 노드 선택

바로 아래 연결 노드가 열리지 않은 노드는 자세한 정보를 숨긴다.
플레이어에게는 이름만 보여주고, 가격과 정확한 효과는 공개하지 않는다.

표시 예시:

| 표시 항목 | 예시 문구 |
|---|---|
| 노드 이름 | 전투 배속 1단계 |
| 현재 상태 | 아래 연결 노드를 먼저 해금해야 합니다. |
| 버튼 | 표시하지 않음 |

### 해금 가능 노드 선택

해금 가능한 노드를 눌렀을 때는 가격과 적용 효과를 명확히 보여준다.

표시 예시:

| 표시 항목 | 예시 문구 |
|---|---|
| 노드 이름 | 데미지 표 해금 |
| 한 줄 설명 | 전투 중 캐릭터별 누적 딜량을 확인할 수 있습니다. |
| 적용 효과 | 전투 화면에 데미지 표 버튼이 열린다. |
| 필요 재화 | 어둠의 흔적 30 |
| 해금 조건 | 아래 연결 노드 해금 완료 |
| 현재 상태 | 해금할 수 있습니다. |
| 버튼 | 해금 |

### 재화 부족 노드 선택

연결 조건은 만족했지만 어둠의 흔적이 부족한 노드는 내용을 보여준다.
이 경우 가격을 보여줘서 다음 목표를 명확하게 만든다.

표시 예시:

| 표시 항목 | 예시 문구 |
|---|---|
| 노드 이름 | 골드량 증가 2단계 |
| 한 줄 설명 | 전투 보상 골드가 +10% 증가합니다. |
| 적용 효과 | 모든 전투 보상 골드 +10% |
| 필요 재화 | 어둠의 흔적 600 |
| 현재 상태 | 어둠의 흔적이 부족합니다. |
| 버튼 | 해금 불가 |

### 해금 완료 노드 선택

이미 해금한 노드를 눌렀을 때는 완료 상태와 적용 중인 효과를 보여준다.

표시 예시:

| 표시 항목 | 예시 문구 |
|---|---|
| 노드 이름 | 시작 골드 증가 |
| 한 줄 설명 | 모든 전투 시작 골드가 +100 증가합니다. |
| 적용 효과 | 모든 전투 시작 골드 +100 |
| 필요 재화 | 해금 완료 |
| 해금 조건 | 완료 |
| 현재 상태 | 이미 적용 중입니다. |
| 버튼 | 해금 완료 |

## 8. UI 표시 규칙

| 항목 | 내용 |
|---|---|
| 노드 이름 | 짧은 이름만 표시 |
| 해금 불가 노드 | 이름만 표시하고 세부 효과와 가격은 숨김 |
| 해금 가능 노드 | 이름, 아이콘, 설명, 효과, 가격, 조건 표시 |
| 재화 부족 노드 | 이름, 아이콘, 설명, 효과, 가격, 부족 상태 표시 |
| 해금 완료 노드 | 이름, 아이콘, 설명, 적용 중인 효과 표시 |
| 선행 조건 | 바로 아래 연결 노드만 표시 |
| 비용 | 선택한 노드의 필요 어둠의 흔적 표시 |
| 해금 버튼 | 조건과 재화가 모두 충분하면 활성화 |
