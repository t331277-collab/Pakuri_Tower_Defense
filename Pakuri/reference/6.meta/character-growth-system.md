# 캐릭터 강화 시스템 초안

> 목적: 해금 트리로 열리는 캐릭터 강화 콘텐츠의 순서와 각 강화 분류의 역할을 정리한다.

## 1. 강화 분류

| 순서 | 분류 | 역할 |
|---:|---|---|
| 1 | 액티브 스킬 각성 | 액티브 스킬의 형태를 먼저 조금 변주한다. |
| 2 | 캐릭터 스탯 강화 | 캐릭터의 기본 체급을 올린다. |
| 3 | 액티브 스킬 강화 | 액티브 스킬의 기본 화력을 올린다. |

캐릭터 강화는 위 순서대로 열리는 것을 기본으로 한다.
해금 트리에서 각 기능을 여는 순서는 `액티브 스킬 각성`, `캐릭터 스탯 강화`, `액티브 스킬 강화` 순서다.
액티브 스킬 각성은 강화 콘텐츠의 첫 인상 역할을 하며, 플레이어가 숫자 성장보다 먼저 스킬의 변주 방향을 고르게 만든다.

## 2. 해금과 사용 조건

| 항목 | 내용 |
|---|---|
| 액티브 스킬 각성 사용 조건 | 해금 트리에서 액티브 스킬 각성을 해금하고, 해당 캐릭터가 대상 액티브 스킬을 보유 |
| 캐릭터 스탯 강화 사용 조건 | 해금 트리에서 캐릭터 스탯 강화를 해금 |
| 액티브 스킬 강화 사용 조건 | 해금 트리에서 액티브 스킬 강화를 해금하고, 해당 캐릭터의 모든 스탯 강화를 완료 |
| 해금 트리 제한 | 이전 단계 사용 조건을 만족하지 않아도 해금 트리에서 다음 기능을 해금할 수 있음 |

해금 트리는 기능을 여는 장기 목표다.
다만 실제 강화 화면에서 사용할 수 있는지는 캐릭터별 진행도에 따라 따로 판단한다.

예를 들어 액티브 스킬 강화 노드를 해금했더라도, 해당 캐릭터의 모든 스탯 강화를 완료하지 않았다면 액티브 스킬 강화 목록은 잠금 상태로 보인다.
이 경우 해금 트리 노드는 이미 열린 상태로 유지된다.
반대로 액티브 스킬 각성은 첫 강화 분류이므로, 액티브 스킬 강화 완료를 요구하지 않는다.
각성은 스킬의 화력을 키우기 전부터 그 스킬이 어떤 방식으로 변주될지 먼저 정하는 선택지다.

## 3. 공통 강화 방식

| 항목 | 내용 |
|---|---|
| 강화 방식 | 단계별 성공 확률을 가진 확률 강화 |
| 실패 처리 | 실패해도 현재 단계 유지 |
| 실패 비용 | 시도에 사용한 어둠의 흔적은 소모 |
| 단계 하락 | 없음 |
| 파괴 | 없음 |

캐릭터 강화는 메이플스토리의 스타포스처럼 단계가 올라갈수록 성공 확률이 낮아지는 구조로 둔다.
한 번 강화할 때 오르는 수치 폭은 크지만, 후반 단계는 성공 확률이 크게 낮아 장기 목표로 남긴다.

세부 성공률과 단계별 비용은 [`enhancement-probability-rule.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F6.meta%2Fenhancement-probability-rule) 문서를 따른다.

## 4. 액티브 스킬 각성

| 각성 방향 | 역할 |
|---|---|
| 도탄 | 투사체가 추가 대상에게 튄다. |
| 타격 범위 증가 | 폭발, 장판, 직선, 부채꼴 등의 타격 범위가 넓어진다. |
| 추가 타겟 | 단일 또는 소수 대상 스킬이 더 많은 적을 노린다. |
| 추가 투사체 | 한 번에 발사되는 투사체 수가 늘어난다. |
| 추가 타격 | 같은 기준점 또는 대상에게 추가 피해가 발생한다. |

액티브 스킬 각성은 스킬을 완전히 다른 스킬로 바꾸지 않는다.
기존 스킬의 정체성을 유지하면서 도탄, 타격 범위 증가, 추가 타겟처럼 작게 변주한다.
해금 순서상 가장 먼저 열리므로, 스킬 강화 완료 조건 없이 캐릭터가 보유한 액티브 스킬을 대상으로 사용한다.
초반부터 각성 방향을 정하게 해서 캐릭터의 플레이 감각을 먼저 바꾸고, 이후 스탯 강화와 액티브 스킬 강화가 그 선택을 수치적으로 뒷받침하게 한다.
각 액티브 스킬은 각성 후보 2개를 가진다.
두 각성 후보는 양자택일이 아니며, 각각 별도의 5단계 강화 항목으로 다룬다.
각성 후보별 단계 효과는 각 액티브 스킬 문서에 함께 작성한다.

## 5. 캐릭터 스탯 강화

| 강화 항목 | 역할 |
|---|---|
| 체력 | 캐릭터 생존력 증가 |
| 공격력 | 공격력 기반 스킬 피해 증가 |
| 주문력 | 주문력 기반 스킬 피해 증가 |
| 위력 | 모든 직접 피해의 기본 화력 증가 |
| 모든 속성 피해 | 물리, 화염, 번개, 얼음, 어둠, 신성 피해 전체 증가 |

캐릭터 스탯 강화는 캐릭터의 기본 체급을 올리는 단계다.
스킬 형태를 바꾸지 않고, 전투 전체에서 체감되는 기본 수치만 강화한다.

## 6. 액티브 스킬 강화

| 강화 항목 | 역할 |
|---|---|
| 스킬 위력 | 해당 액티브 스킬의 기본 피해 증가 |
| 공격력 계열 강화 | 공격력 기반 액티브 스킬의 피해 증가 |
| 주문력 계열 강화 | 주문력 기반 액티브 스킬의 피해 증가 |
| 속성 피해 강화 | 해당 스킬의 주 속성 피해 증가 |

액티브 스킬 강화는 스킬의 형태를 바꾸지 않는다.
해당 액티브 스킬의 공격력, 주문력, 위력처럼 기본 화력에 해당하는 수치만 올린다.
