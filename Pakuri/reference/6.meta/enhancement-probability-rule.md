# 캐릭터 강화 확률 규칙

> 목적: 심연의 제단에서 진행하는 캐릭터 강화의 공통 확률 규칙을 정의한다.

## 1. 기본 규칙

| 항목 | 규칙 |
|---|---|
| 적용 대상 | 액티브 스킬 각성, 캐릭터 스탯 강화, 액티브 스킬 강화 |
| 강화 방식 | 단계별 성공 확률을 가진 확률 강화 |
| 실패 처리 | 실패해도 강화 단계는 하락하지 않음 |
| 실패 비용 | 강화 시도에 사용한 어둠의 흔적은 반환하지 않음 |
| 파괴 여부 | 파괴 없음 |
| 최대 단계 | 모든 캐릭터 강화는 5단계 |
| 비용 기준 | 시작 단계부터 이전 초안 대비 약 10배 높은 어둠의 흔적을 요구 |

강화는 한 번 시도할 때마다 어둠의 흔적을 소비한다.
성공하면 단계가 1 상승하고, 실패하면 현재 단계가 유지된다.

## 2. 스탯 강화 성공률

| 목표 단계 | 성공 확률 | 실패 시 | 필요 어둠의 흔적 |
|---:|---:|---|---:|
| 1 | 100% | 단계 유지 | 500 |
| 2 | 70% | 단계 유지 | 800 |
| 3 | 40% | 단계 유지 | 1200 |
| 4 | 20% | 단계 유지 | 1800 |
| 5 | 10% | 단계 유지 | 2600 |

## 3. 액티브 스킬 강화 성공률

| 목표 단계 | 성공 확률 | 실패 시 | 필요 어둠의 흔적 |
|---:|---:|---|---:|
| 1 | 100% | 단계 유지 | 800 |
| 2 | 65% | 단계 유지 | 1300 |
| 3 | 35% | 단계 유지 | 2100 |
| 4 | 15% | 단계 유지 | 3400 |
| 5 | 7% | 단계 유지 | 5400 |

## 4. 액티브 스킬 각성 성공률

| 목표 단계 | 성공 확률 | 실패 시 | 필요 어둠의 흔적 |
|---:|---:|---|---:|
| 1 | 80% | 단계 유지 | 3000 |
| 2 | 50% | 단계 유지 | 6000 |
| 3 | 25% | 단계 유지 | 11000 |
| 4 | 12% | 단계 유지 | 19000 |
| 5 | 5% | 단계 유지 | 32000 |

액티브 스킬 각성은 스킬의 형태 변주를 강화하는 단계다.
각 액티브 스킬의 각성 후보 2개는 각각 위 확률표에 따라 5단계까지 강화할 수 있다.

## 5. UI 표시 기준

| 상태 | 표시 |
|---|---|
| 강화 가능 | 목표 단계, 성공 확률, 필요 어둠의 흔적, 성공 시 효과 표시 |
| 재화 부족 | 성공 확률과 필요 재화는 보이지만 강화 버튼 비활성 |
| 강화 성공 | 성공 안내와 상승한 단계 표시 |
| 강화 실패 | 실패 안내와 단계 유지 표시 |
| 최대 단계 | 완료 표시, 강화 버튼 비활성 |
