# 메타 성장 노드 목록

> 목적: `어둠의 흔적`을 사용해 런 밖에서 캐릭터 스탯을 강화하는 공통 구조를 정의한다.

원작 참고 방향:
- 원작의 아콜라이트 룸은 런 밖에서 몬스터의 전투력을 강화하는 장기 성장 축이다.
- 원작의 가이던스 스톤은 부활, 시작 골드, 전투 시작 효과처럼 간접 전투 보너스를 제공한다.
- 이 프로젝트에서는 위 구조를 단순화해, 기본 메타 재화인 `어둠의 흔적`으로 캐릭터별 공통 스탯을 직접 강화한다.

액티브 스킬별 메타 강화는 [`active-skill-growth-node-list.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F6.meta%2Factive-skill-growth-node-list) 참고.

## 1. 기본 규칙

| 항목 | 규칙 |
|---|---|
| 사용 재화 | 어둠의 흔적 |
| 강화 대상 | 캐릭터별 공통 스탯 |
| 적용 범위 | 런 시작 전 영구 성장 |
| 캐릭터별 관리 | 각 캐릭터가 독립된 스탯 강화 상태를 가진다. |
| 액티브 강화 | 별도 문서에서 캐릭터별 스킬마다 다르게 관리한다. |
| 패시브 | 메타 성장에서 다루지 않는다. |
| 초기화 가능 여부 | 가능 |
| 초기화 반환 | 해당 캐릭터에 투자한 어둠의 흔적 전액 반환 |
| 초기화 수수료 | 초기화 1회마다 어둠의 흔적 50개 고정 소모 |

초기화 수수료는 반환 대상에 포함하지 않는다.
예를 들어 한 캐릭터에 어둠의 흔적 300개를 투자했다면, 초기화 시 300개를 돌려받고 별도로 수수료 50개를 지불한다.

## 2. 강화 분류

| 분류 | 강화 대상 | 문서 |
|---|---|---|
| 스탯 강화 | 체력, 공격력, 주문력, 방어력, 치명타, 행동속도 | 이 문서 |
| 액티브 강화 | 캐릭터별 액티브 스킬마다 다른 강화 노드 | [`active-skill-growth-node-list.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F6.meta%2Factive-skill-growth-node-list) |

패시브는 런 내부 스킬 성장, 유물, 시너지로 강화 방향을 다룬다.

## 3. 스탯 강화 노드

스탯 강화는 모든 캐릭터가 같은 공통 구조를 사용한다.
캐릭터별로 다른 전용 스탯 노드를 만들지 않고, 같은 노드 목록에서 필요한 스탯을 선택해 강화한다.

모든 스탯 강화 노드는 5단계까지 강화할 수 있다.
단계가 올라갈수록 필요한 `어둠의 흔적`이 크게 증가해, 초반에는 핵심 스탯 1~2개를 고르고 후반에는 장기 투자 목표가 되도록 한다.

| 노드 | 최대 레벨 | 레벨당 효과 | 레벨별 비용 |
|---|---:|---|---:|
| 체력 강화 | 5 | 체력 +3% | 50 / 100 / 180 / 300 / 500 |
| 공격력 강화 | 5 | 공격력 +3% | 50 / 100 / 180 / 300 / 500 |
| 주문력 강화 | 5 | 주문력 +3% | 50 / 100 / 180 / 300 / 500 |
| 방어력 강화 | 5 | 방어력 +3% | 50 / 100 / 180 / 300 / 500 |
| 치명타 확률 강화 | 5 | 치명타 확률 +1.5% | 70 / 140 / 250 / 420 / 700 |
| 치명타 피해 강화 | 5 | 치명타 피해 +4% | 70 / 140 / 250 / 420 / 700 |
| 행동속도 강화 | 5 | 행동속도 +2% | 80 / 160 / 280 / 480 / 800 |

## 4. 캐릭터별 추천 스탯

추천 스탯은 UI에서 먼저 보여주는 가이드일 뿐, 실제 강화 가능 스탯은 모든 캐릭터가 동일하다.

| 캐릭터 | 추천 스탯 노드 | 이유 |
|---|---|---|
| 이브 | 주문력 강화, 행동속도 강화 | 번개/얼음 스킬의 발동 빈도와 주문 피해를 올린다. |
| 세인 | 공격력 강화, 치명타 피해 강화 | 화염 화살의 직접 피해와 폭발 화력을 올린다. |
| 린 | 공격력 강화, 체력 강화 | 물리 충격파 피해와 전방형 캐릭터 생존력을 올린다. |
| 베가 | 공격력 강화, 치명타 확률 강화 | 검기와 처형 계열의 물리 화력을 올린다. |
| 아리엘 | 주문력 강화, 방어력 강화 | 신성 피해와 보호 계열 안정성을 올린다. |

## 5. 초기화 규칙

초기화는 캐릭터 단위로 진행한다.

| 항목 | 규칙 |
|---|---|
| 초기화 단위 | 캐릭터 1명 |
| 반환 대상 | 해당 캐릭터의 스탯 강화와 액티브 강화에 투자한 어둠의 흔적 |
| 반환 비율 | 100% |
| 수수료 | 어둠의 흔적 50개 고정 소모 |
| 수수료 반환 | 반환되지 않음 |
| 초기화 제한 | 전투 중에는 불가, 런 시작 전 메타 화면에서만 가능 |

수수료는 투자량에 비례하지 않는다.
작게 투자한 캐릭터를 자주 초기화하는 것을 막고, 크게 투자한 캐릭터는 부담 없이 방향을 바꿀 수 있게 한다.

## 6. UI 흐름

1. 메타 성장 화면 진입
2. 캐릭터 선택
3. `스탯 강화` 탭 선택
4. 노드 선택 후 어둠의 흔적 지불
5. 필요 시 `초기화` 버튼 선택
6. 수수료 확인
7. 투자 재화 반환 및 노드 초기화

액티브 강화 UI는 캐릭터별 스킬 목록이 필요하므로 별도 탭 또는 별도 화면으로 분리한다.

## 7. 후속 결정 필요 항목

- 초기화 수수료 50개가 적절한지 테스트
- 메타 강화가 런 초반 난이도를 얼마나 낮추는지 검증
