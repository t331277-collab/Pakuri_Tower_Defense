# 조준 시스템

> 목적: 전투 중 자동 조준과 수동 조준의 기본 동작, 해금 조건, UI 표시 기준을 정리한다.

## 1. 기본 규칙

| 항목 | 내용 |
|---|---|
| 기본 조준 상태 | 자동 조준 |
| 기본 해금 상태 | 별도 해금 없이 처음부터 사용 |
| 조준 기준 조건 | 자동 조준은 화면 안의 적, 수동 조준은 화면 안의 입력 지점 |
| 거리 제한 | 별도 거리 제한 없음 |
| 스킬 사용 기준 | 사용 가능한 모든 스킬을 자동으로 사용 |

자동 조준은 해금과 관계없이 모든 전투에서 기본으로 적용되는 조준 상태다.
플레이어가 별도 조작을 하지 않아도 자동 조준 상태로 전투가 진행된다.

## 2. 자동 조준

| 항목 | 내용 |
|---|---|
| 대상 선택 | 화면 안에 있는 가장 가까운 적 |
| 스킬 사용 | 사용 가능한 모든 스킬을 자동으로 사용 |
| 클릭 입력 | 필요 없음 |
| 화면 안 적이 없을 때 | 공격하지 않고 대기 |

자동 조준 상태에서는 화면 안에 있는 가장 가까운 적을 기준으로 모든 스킬을 사용한다.
스킬이 사용 가능한 상태가 되면 플레이어 입력을 기다리지 않고 즉시 사용한다.
화면 안에 적이 없으면 공격하지 않는다.

## 3. 전술 지휘 해금

| 항목 | 내용 |
|---|---|
| 해금 이름 | 전술 지휘 |
| 해금 위치 | 어둠의 흔적 해금 트리 |
| 해금 효과 | 전투 중 조준 모드 토글 UI 활성화 |
| 토글 모드 | 자동 조준, 수동 조준 |

전술 지휘를 해금하면 전투 화면에서 조준 모드를 바꾸는 UI가 열린다.
해금 전에는 조준 모드 UI가 보이지 않으며, 전투는 항상 자동 조준으로 진행된다.

## 4. 수동 조준

| 항목 | 내용 |
|---|---|
| 공격 기준점 | 플레이어가 화면 안에서 누른 지점 |
| 스킬 사용 | 사용 가능한 모든 스킬을 자동으로 사용 |
| 입력 유지 | 누르고 있는 동안 해당 지점을 공격 기준점으로 사용 |
| 입력 없음 | 공격하지 않고 대기 |
| 화면 밖 입력 | 공격 기준점으로 사용하지 않음 |
| 재장전 처리 | 클릭이 없다는 이유로 재장전하거나 별도 행동을 하지 않음 |

수동 조준 상태에서는 플레이어가 화면 안에서 누른 지점을 공격 기준점으로 삼는다.
플레이어가 화면을 누르고 있는 동안 사용 가능한 모든 스킬은 그 지점을 향해 자동으로 사용된다.

플레이어가 손을 떼고 있거나 아무 지점도 누르지 않으면 공격하지 않고 대기한다.
화면 밖 입력은 공격 기준점으로 사용하지 않는다.
이 대기 상태는 별도 재장전, 강제 시전, 자동 대상 전환으로 이어지지 않는다.

## 5. 모드 비교

| 구분 | 자동 조준 | 수동 조준 |
|---|---|---|
| 기본 사용 | 기본 상태 | 전술 지휘 해금 후 선택 가능 |
| 대상 기준 | 화면 안의 가장 가까운 적 | 플레이어가 누른 화면 안 지점 |
| 스킬 사용 | 사용 가능한 모든 스킬 자동 사용 | 사용 가능한 모든 스킬 자동 사용 |
| 플레이어 입력 | 필요 없음 | 화면을 누르고 있어야 공격 |
| 입력 없음 | 가장 가까운 적을 계속 공격 | 공격하지 않음 |
