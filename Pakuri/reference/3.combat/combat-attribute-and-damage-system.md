# 속성 및 데미지 적용 시스템

> 현재 프로젝트 전투에서 사용하는 속성 종류, 속성 방어력 처리, 버프/디버프 적용 순서, 치명타 규칙을 정의한다.

## 1. 목적
- 속성 종류를 고정한다.
- 각 속성이 어떤 방어력과 상호작용하는지 명확히 한다.
- 속성 방어력에 대한 고정 수치 / 퍼센트 버프·디버프 적용 순서를 정의한다.
- 방어력은 최종 데미지에 퍼센트 경감으로 적용한다.
- 데미지 계산과 치명타 규칙의 기준을 만든다.

## 2. 속성 종류
현재 속성은 아래 6종으로 고정한다.
- 물리
- 화염
- 번개
- 얼음
- 어둠
- 신성

## 3. 속성 상성 규칙
- 속성 간 상성은 없다.
- 특정 속성이 다른 속성에 추가 보정 또는 약점 보너스를 갖지 않는다.
- 각 공격은 자기 속성에 대응하는 방어력 수치하고만 상호작용한다.

예시:
- 화염 공격은 화염 방어력과만 계산한다.
- 번개 공격은 번개 방어력과만 계산한다.
- 물리 공격은 물리 방어력과만 계산한다.

## 4. 방어력 구조
각 유닛은 속성별 방어력을 따로 가진다.
- 물리 방어력
- 화염 방어력
- 번개 방어력
- 얼음 방어력
- 어둠 방어력
- 신성 방어력

즉 방어력은 단일 방어 수치가 아니라, 속성별 개별 수치 묶음이다.

## 5. 속성 방어력 버프/디버프 규칙
특정 속성 방어력에는 아래 두 종류의 변화가 들어갈 수 있다.
- 고정 수치 증가 / 감소
- 퍼센트 증가 / 감소

### 5.1 적용 순서
속성 방어력 계산 순서는 아래와 같이 고정한다.

1. 고정 수치 증가를 먼저 더한다.
2. 고정 수치 감소를 뺀다.
3. 그 다음 퍼센트 증가를 곱연산으로 적용한다.
4. 마지막으로 퍼센트 감소를 곱연산으로 적용한다.

즉 정리하면:
- 고정 증감으로 기준 방어력을 먼저 만든다.
- 퍼센트 증가는 고정 증감이 끝난 값에 곱연산으로 적용한다.
- 퍼센트 감소는 퍼센트 증가까지 적용된 값에 곱연산으로 적용한다.

### 5.2 방어력 계산식 표기
기준 속성 방어력을 `BaseDef`라고 할 때,
- 고정 증가 합: `FlatBonus`
- 퍼센트 증가 합: `PercentBonus`
- 퍼센트 감소 효과: `PercentReduction`
- 고정 감소 합: `FlatReduction`

최종 속성 방어력은 아래 순서로 계산한다.

`Step1 = BaseDef + FlatBonus`

`Step2 = Step1 - FlatReduction`

`Step3 = Step2 * (1 + PercentBonus)`

`FinalDef = Step3 * (1 - PercentReduction)`

퍼센트 감소 효과가 여러 개일 경우 서로 합산하지 않고 각각 곱연산한다.

`FinalDef = Step3 * (1 - PercentReduction_1) * (1 - PercentReduction_2) * ...`

예를 들어 30% 방어력 감소와 20% 방어력 감소가 동시에 적용되면 최종 감소 배율은 `0.7 * 0.8 = 0.56`이다.
즉 두 효과의 실질 총 감소량은 50%가 아니라 44%다.

방어력 수치는 이렇게 최종 계산한 뒤, 데미지에 직접 차감이 아니라 퍼센트 경감으로 적용한다.
필요하면 최종 방어력의 최소값은 후속 문서에서 별도 제한한다.

## 6. 공격과 속성 방어력 상호작용
- 공격은 반드시 1개의 주 속성을 가진다고 가정한다.
- 해당 공격은 동일 속성의 방어력만 참조한다.
- 예를 들어 화염 공격이면 최종 화염 방어력만 확인한다.
- 다른 속성 방어력은 그 공격 계산에 직접 개입하지 않는다.

## 7. 데미지 공식 기본 구조
현재 단계에서 데미지 계산은 아래 구조를 기준으로 한다.

1. 공격의 기본 데미지를 구한다.
2. 공격 속성에 대응하는 최종 속성 방어력을 구한다.
3. 방어력 반영 후 최종 피해를 계산한다.
4. 치명타가 발생하면 치명타 배율을 적용한다.

### 7.1 기본 데미지
현재 문서에서는 공격의 기본 데미지를 `BaseDamage`로 둔다.
이 값은 스킬 계수, 공격력 계수, 기타 계수 계산이 모두 끝난 뒤의 값으로 본다.

### 7.2 방어력 반영 기본식
방어력은 롤 계열 방어력처럼 최종 피해에 퍼센트 경감으로 적용한다.
즉 방어력 수치를 그대로 빼는 방식이 아니다.

현재 문서에서는 아래와 같이 정의한다.

`DamageAfterDefense = BaseDamage * (100 / (100 + FinalDef))`

즉 현재 단계에서는
- 해당 속성 방어력은 최종 피해를 퍼센트로 줄이는 역할을 한다.
- 방어력은 대응 속성 공격에만 적용된다.
- 방어력이 높을수록 피해 감소율이 커지지만, 선형 차감이 아니라 완만하게 증가한다.

## 8. 치명타 규칙
### 8.1 기본 치명타 확률
- 기본 치명타 확률은 `5%`다.

### 8.2 기본 치명타 데미지
- 기본 치명타 데미지는 `1.5배`다.

### 8.3 치명타 적용 순서
- 먼저 기본 피해와 방어력 반영 결과를 계산한다.
- 그 다음 치명타가 발생하면 치명타 배율을 곱한다.

즉:

`FinalDamage = DamageAfterDefense * CritMultiplier`

치명타가 발생하지 않으면:

`FinalDamage = DamageAfterDefense`

치명타가 발생하면:

`CritMultiplier = 1.5`

## 9. 계산 예시
### 9.1 화염 공격 예시
- 화염 기본 데미지: 120
- 화염 기본 방어력: 30
- 화염 방어력 고정 증가: +10
- 화염 방어력 퍼센트 증가: +20%
- 화염 방어력 퍼센트 감소: 10%
- 화염 방어력 고정 감소: 5

계산:
- Step1 = 30 + 10 = 40
- Step2 = 40 - 5 = 35
- Step3 = 35 * 1.2 = 42
- FinalDef = 42 * 0.9 = 37.8

최종 피해:
- DamageAfterDefense = 120 * (100 / (100 + 37.8))
- DamageAfterDefense ≈ 87.08
- 치명타가 아니면 최종 피해 ≈ 87.08
- 치명타면 최종 피해 ≈ 130.62

## 10. 현재 확정 사항 요약
- 속성은 6종: 물리 / 화염 / 번개 / 얼음 / 어둠 / 신성
- 속성 상성은 없음
- 각 공격은 동일 속성 방어력과만 상호작용
- 속성 방어력 계산 순서:
  - 고정 증가
  - 고정 감소
  - 퍼센트 증가
  - 퍼센트 감소
- 방어력은 최종 피해에 퍼센트 경감으로 적용
- 기본 치명타 확률: 5%
- 기본 치명타 데미지: 1.5배
- 치명타는 방어력 반영 후 적용

## 11. 후속 결정 필요 항목
- 방어력 최소값 허용 여부
- 방어력 상한선 여부
- 최소 피해 1 보장 여부
- 치명타 확률/치명타 피해 증가 스탯 추가 여부
- 다속성 공격 허용 여부
- 방어 무시 / 고정 피해 / 관통 피해 규칙 추가 여부
