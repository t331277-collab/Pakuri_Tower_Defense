# 전투 스탯 시스템

> 목적: 전투 계산에서 참조하는 주요 스탯의 의미, 적용 대상, 표기 기준을 정리한다.

## 1. 기본 원칙
- 스탯은 몬스터, 스킬, 장비, 버프/디버프가 전투 결과를 조정하는 공통 기준값이다.
- 각 스킬 문서는 어떤 스탯을 참조하는지 명시해야 한다.
- 수치 단위는 별도 표기가 없으면 퍼센트 스탯은 `%`, 시간 원본값은 `초`, 횟수/개수 원본값은 `개`를 사용한다.
- 최종 계산식과 상한/하한은 별도 전투 계산 문서에서 확정한다.

## 2. 스탯 증감 계산 원칙
스탯에 고정 증가, 고정 감소, 퍼센트 증가, 퍼센트 감소가 함께 적용될 때는 아래 순서를 기본으로 한다.

1. 기본값을 가져온다.
2. 고정 증가를 더한다.
3. 고정 감소를 뺀다.
4. 퍼센트 증가를 곱연산으로 적용한다.
5. 퍼센트 감소를 곱연산으로 적용한다.
6. 스탯별 하한/상한이 있으면 마지막에 적용한다.

계산식으로 표기하면 아래와 같다.

`FinalStat = (BaseStat + FlatBonus - FlatReduction) * (1 + PercentBonus) * (1 - PercentReduction)`

퍼센트 스탯 감소 효과가 여러 개일 경우 서로 합산하지 않고 각각 곱연산한다.

`FinalStat = (BaseStat + FlatBonus - FlatReduction) * (1 + PercentBonus) * (1 - PercentReduction_1) * (1 - PercentReduction_2) * ...`

예를 들어 어떤 스탯에 30% 감소와 20% 감소가 동시에 적용되면 최종 감소 배율은 `0.7 * 0.8 = 0.56`이다.
즉 두 효과의 실질 총 감소량은 50%가 아니라 44%다.

이 원칙은 공격력, 주문력, 방어력, 속성 저항 등 수치형 전투 스탯에 공통 적용한다.
단, 최종 피해 증가/감소, 치명타 판정, 방어막 흡수처럼 별도 계산 단계가 필요한 효과는 해당 전투 계산 문서의 규칙을 우선한다.

## 3. 공격 계수 스탯

| 스탯 | 기본값 | 기획 메모 |
|---|---:|---|
| 공격력 | 30 | 스킬 설명의 `공격력 계수`가 붙는 경우 참조한다. |
| 주문력 | 30 | 스킬 설명의 `주문력 계수`가 붙는 경우 참조한다. |

## 4. 생존 및 방어 스탯

| 스탯 | 기본값 | 기획 메모 |
|---|---:|---|
| 생명력 | 스킬/대상별 지정 | 현재 체력은 생명력 최대값을 넘을 수 없다. |
| 방어력 | 0 | 속성 저항과 분리하며, 물리 피해 계산에 우선 사용한다. |
| 속성 저항 | 0 | 속성별 개별 값으로 관리한다. |

## 5. 치명타 스탯

| 스탯 | 기본값 | 기획 메모 |
|---|---:|---|
| 치명타 확률 | 5% | 기본값과 증가/감소값을 합연산한다. |
| 치명타 피해 | 150% | 기본 치명타 배율에 더해지는 증가량으로 취급한다. |
| 치명타 저항 | 0% | 공격자의 치명타 확률에서 합연산으로 차감한다. |

### 5.1 치명타 확률과 치명타 저항
- 치명타 확률과 치명타 저항은 곱연산이 아니라 합연산으로 계산한다.
- 공격자의 최종 치명타 확률은 `기본 치명타 확률 + 치명타 확률 증가 - 대상의 치명타 저항`을 기준으로 한다.
- 예시: 기본 치명타 확률 5%, 치명타 확률 증가 20%, 대상의 치명타 저항 10%라면 최종 치명타 확률은 15%다.
- 최종 치명타 확률의 최소값/최대값은 별도 전투 계산 문서에서 확정한다.

## 6. 기타 스탯

| 스탯 | 기본값 | 기획 메모 |
|---|---:|---|
| 행동속도 | 0% | 탄환 발사 간격과 쿨타임 충전 속도를 가속한다. |
| 쿨다운 | 0% | 스킬 원본 쿨다운에 적용되는 퍼센트 보정값이다. |
| 지속시간 | 0% | 스킬 원본 지속시간에 적용되는 퍼센트 보정값이다. |
| 발사 간격 | 0% | 스킬 원본 발사 간격에 적용되는 퍼센트 보정값이다. |
| 피해 범위 | 0% | 스킬 원본 피해 범위에 적용되는 퍼센트 보정값이다. |

### 6.1 행동속도
- 행동속도는 캐릭터의 전투 행동이 얼마나 빠르게 진행되는지 나타내는 스탯이다.
- 행동속도는 탄창형/연발형 스킬의 탄환 발사 간격을 가속한다.
- 행동속도는 액티브 스킬의 쿨타임이 차오르는 속도를 가속한다.
- 행동속도는 스킬 피해량, 투사체 속도, 버프 지속시간, 디버프 지속시간에는 직접 적용하지 않는다.
- 예시: 행동속도 +25% 상태에서는 탄환 발사 간격이 더 짧아지고, 쿨타임 충전이 더 빠르게 진행된다.



## 7. 설계 메모
- 공격력과 주문력은 피해 계수의 기준 스탯이며, 스킬마다 둘 중 하나만 참조하는 것을 기본으로 한다.
- 방어력은 물리 피해, 속성 저항은 해당 속성 피해에 대응한다.
- 치명타 관련 스탯은 치명타 가능 여부가 명시된 공격/스킬에만 적용한다.
- 행동속도는 탄환 발사 간격과 쿨타임 충전 속도에만 적용한다.
- 쿨다운, 지속시간, 발사 간격 같은 개별 시간 보정 스탯은 행동속도와 별도 스탯으로 관리한다.
- 탄창, 재장전, 발사 간격은 탄창형 또는 연발형 스킬의 운용감을 만드는 전용 스탯으로 본다.
