# 버프 / 디버프 문서

> 목적: 전투 중 적용되는 버프와 디버프 상태를 정리한다.

## 감전

| 항목 | 값 |
|---|---:|
| 분류 | 디버프 |
| 속성 | 번개 |
| 기본 지속시간 | 4.0초 |
| 최대 스택 | 5 |
| 기본 부여량 | 1스택 |

## 감전 적용 기준
- 감전은 번개 계열 스킬이 부여한다.
- 감전 자체는 현재 직접 피해를 주지 않는다.
- 감전 대상은 번개 계열 후속 스킬의 연계 대상으로 사용할 수 있다.
- 감전 추가 피해, 폭발, 연쇄 효과는 개별 스킬 문서에서 정의한다.

## 추위

| 항목 | 값 |
|---|---:|
| 분류 | 디버프 |
| 속성 | 얼음 |
| 기본 지속시간 | 3.0초 |
| 최대 스택 | 5 |
| 스택당 둔화 | 6% |

## 추위 적용 기준
- 추위는 얼음 계열 스킬이 부여한다.
- 추위 1스택당 이동 속도가 6% 감소한다.
- 추위가 5스택이 되면 추위 스택을 제거하고 빙결로 전환한다.

## 빙결

| 항목 | 값 |
|---|---:|
| 분류 | 디버프 |
| 속성 | 얼음 |
| 기본 지속시간 | 2.0초 |
| 이동 가능 여부 | 불가 |
| 행동 가능 여부 | 불가 |

## 빙결 적용 기준
- 빙결 상태의 적은 지속시간 동안 멈춘다.
- 빙결 상태에서는 이동과 공격을 할 수 없다.
- 빙결 종료 후 추위 스택은 0으로 시작한다.

## 취약

| 항목 | 값 |
|---|---:|
| 분류 | 디버프 |
| 속성 | 없음 |
| 기본 지속시간 | 영구 지속 |
| 최대 스택 | 10 |
| 스택당 받는 치명타 피해 증가 | 3% |
| 스택당 치명타 저항 감소 | 3% |

## 취약 적용 기준
- 취약은 스택형 디버프다.
- 취약은 기본적으로 해제되지 않고 영구 지속된다.
- 취약 1스택마다 대상이 받는 치명타 피해가 3% 증가한다.
- 취약 1스택마다 대상의 치명타 저항이 3% 감소한다.
- 취약은 최대 10스택까지 중첩된다.

## 화염 저항 감소

| 항목 | 값 |
|---|---:|
| 분류 | 디버프 / 저항 약화 |
| 속성 | 화염 |
| 기본 지속시간 | 스킬별 지정 |
| 최대 중첩 | 스킬별 지정 |
| 기본 효과 | 대상의 화염 저항 감소 |

## 화염 저항 감소 적용 기준
- 화염 저항 감소는 화염 피해 계산 전에 대상의 화염 저항을 낮춘다.
- 여러 출처의 화염 저항 감소가 중첩되는지는 개별 스킬 문서에서 정의한다.
- 지속시간이 다른 화염 저항 감소가 동시에 적용되면 각 출처의 지속시간을 따로 관리한다.

## 화염 노출

| 항목 | 값 |
|---|---:|
| 분류 | 디버프 / 받는 피해 증가 |
| 속성 | 화염 |
| 기본 지속시간 | 스킬별 지정 |
| 최대 중첩 | 스킬별 지정 |
| 기본 효과 | 대상이 모든 아군에게 받는 화염 피해 증가 |

## 화염 노출 적용 기준
- 화염 노출은 대상이 모든 아군의 화염 피해를 더 크게 받게 만드는 디버프다.
- 화염 저항 감소와 동시에 적용될 수 있으며, 저항 계산 이후 최종 화염 피해 보정으로 처리한다.
- 중첩 여부와 수치는 개별 스킬 문서에서 정의한다.

## 신성 방어막

| 항목 | 값 |
|---|---:|
| 분류 | 버프 / 방어막 |
| 속성 | 신성 |
| 기본 지속시간 | 스킬별 지정 |
| 기본 효과 | 피해를 먼저 흡수 |
| 중첩 방식 | 높은 값 우선 갱신 |

## 신성 방어막 적용 기준
- 신성 방어막은 대상이 받는 피해를 체력보다 먼저 흡수한다.
- 남은 방어막보다 큰 피해를 받으면 방어막을 제거하고 초과 피해를 체력에 적용한다.
- 같은 대상에게 여러 신성 방어막이 적용되면 기본적으로 더 높은 방어막 값을 사용한다.
- 개별 스킬이나 특성이 별도 중첩 방식을 지정할 수 있다.

- 행동속도 증가는 탄환 발사 간격과 쿨타임 충전 속도에 적용한다.

## 이름표식

| 항목 | 값 |
|---|---:|
| 분류 | 디버프 / 표식 |
| 속성 | 없음 |
| 기본 지속시간 | 영구 지속 |
| 최대 스택 | 제한 없음 |
| 자체 효과 | 없음 |

## 이름표식 적용 기준
- 이름표식은 베가의 표식 연계 스킬이 부여한다.
- 이름표식 자체에는 피해 증가, 이동 속도 감소, 받는 피해 증가 같은 독립 효과가 없다.
- 이름표식 스택 수는 이름표식을 참조하는 개별 스킬의 대상 선정, 피해 계산, 추가 효과에만 사용한다.
- 이름표식 소모 여부는 개별 스킬 문서에서 정의한다.

## 침묵 적용 기준
- 침묵 상태의 적은 지속시간 동안 특수능력을 사용할 수 없다.
- 일반 이동과 기본 공격까지 제한할지는 개별 적 패턴에 따라 별도 정의한다.
- 보스나 침묵 면역 대상에게는 침묵 대신 특수능력 위력 감소, 시전 지연, 또는 면역 처리를 적용할 수 있다.

## 몰살 허가

| 항목 | 값 |
|---|---:|
| 분류 | 버프 / 자기 강화 |
| 속성 | 없음 |
| 기본 지속시간 | 6.0초 |
| 행동속도 증가 | +25% |
| 공격력 증가 | +20% |
| 기본 적용 대상 | 베가 |

## 몰살 허가 적용 기준
- 몰살 허가는 베가에게 적용되는 자기 강화 버프다.
- 행동속도 증가는 탄환 발사 간격과 쿨타임 충전 속도에 적용한다.
- 공격력 증가는 베가의 공격력 계수를 참조하는 피해 계산에 적용한다.
- 패시브나 특성 효과로 몰살 허가의 일부 효과가 아군 전체에 공유될 수 있다.
