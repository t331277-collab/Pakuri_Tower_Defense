# 실시간 딜 미터기 기획 문서

> 전투 중 각 타워가 입힌 피해량을 실시간으로 비교할 수 있는 보조 UI를 정의한다. 플레이어는 우측 상단 토글 버튼으로 딜 미터기를 열고 닫을 수 있으며, 패널은 슬라이더형 목록으로 표시된다.

## 1. 목적
- 전투 중 어떤 타워가 실제로 피해 기여를 하고 있는지 즉시 확인하게 한다.
- 타워별 누적 피해량을 얼굴 아이콘과 수치로 보여 주어 비교를 쉽게 만든다.
- 스킬 선택, 배치, 성장 선택의 결과를 플레이어가 전투 흐름 안에서 체감하게 한다.
- 기본 전투 화면을 가리지 않도록 필요할 때만 열 수 있는 선택형 UI로 제공한다.

## 2. 기본 진입 방식
- 전투 화면의 맨 위 오른쪽 상단에 딜 미터기 토글 버튼을 배치한다.
- 토글 버튼 기본 상태는 닫힘이다.
- 버튼을 누르면 딜 미터기 패널이 표시된다.
- 패널이 열린 상태에서 버튼을 다시 누르면 딜 미터기 패널이 숨겨진다.
- 전투 시작 시 기본값은 숨김으로 한다.

## 3. 화면 배치
- 토글 버튼 위치: 전투 UI 최상단 우측.
- 딜 미터기 패널 위치: 토글 버튼 아래쪽에서 펼쳐지는 우측 고정 패널.
- 패널은 전투 필드 중앙 시야를 침범하지 않는 폭으로 제한한다.
- 패널은 세로 슬라이더 목록 형식으로 구성한다.
- 표시할 타워 수가 패널 높이를 넘으면 세로 스크롤로 확인한다.
- 패널은 반투명 어두운 배경을 사용해 전투 화면 위에서도 수치가 읽히게 한다.

## 4. 표시 정보
각 타워 항목은 전투 중 빠르게 읽을 수 있도록 최소 정보만 표시한다.

| 항목 | 설명 |
|---|---|
| 얼굴 | 해당 타워의 얼굴 또는 상반신 아이콘 |
| 누적 피해량 | 전투 시작 후 해당 타워가 입힌 총 피해량 |
| 피해 비중 | 전체 타워 피해량 중 해당 타워가 차지한 비율 |

- 화면에 직접 표시되는 요소는 얼굴 아이콘, 누적 피해량 숫자, 피해 비중 세 가지만 사용한다.
- 타워 이름과 순위 숫자는 기본 표시에서 제외한다.
- 목록은 포메이션 배치 순서 1, 2, 3, 4, 5로 고정한다.
- 피해량이 변해도 항목 위치는 바뀌지 않는다.



## 6. 피해량 집계 규칙
- 집계 단위는 전투 1회이다.
- 전투 시작 시 모든 타워의 누적 피해량은 0으로 초기화한다.
- 적에게 최종 피해가 적용된 시점에 해당 피해량을 공격한 타워의 누적 피해량에 더한다.
- 피해량은 방어력, 속성, 치명타, 버프, 디버프가 모두 반영된 최종 피해량 기준으로 집계한다.
- 초과 피해는 실제 적용 피해량 기준으로 집계한다.
  - 예: 남은 체력 10인 적에게 100 피해를 입힌 경우 집계 피해량은 10이다.
- 지속 피해, 소환물, 투사체, 장판 피해는 원인을 제공한 타워에게 귀속한다.
- 원인 타워를 특정할 수 없는 시스템 피해는 딜 미터기에 포함하지 않는다.

## 7. 실시간 갱신 규칙
- 피해 이벤트가 발생할 때마다 내부 누적값을 즉시 갱신한다.
- UI 표시는 너무 자주 흔들리지 않도록 일정 간격으로 갱신한다.
- 권장 UI 갱신 주기: 0.2초.
- 누적 피해 수치는 증가 애니메이션을 짧게 적용할 수 있다.
- 항목 위치는 포메이션 순서로 고정되며, 전투 중 순위 변동으로 재배치하지 않는다.
- 전투 일시정지 상태에서는 수치 갱신도 멈춘다.
- 전투 재개 시 누락된 피해 이벤트 없이 최신 누적값을 표시한다.

## 8. 피해 비중 표시 규칙
- 피해 비중은 전체 타워 피해량 중 해당 타워가 차지한 비율로 계산한다.
- 피해 비중은 소수점 없이 정수 퍼센트로 표시한다.
- 누적 피해량은 1,000 이상부터 축약 표기를 사용할 수 있다.
  - 예: `1,250`, `12.4K`, `1.3M`

## 9. 토글 상태
### 9.1 닫힘
- 우측 상단에 토글 버튼만 보인다.
- 전투 화면에는 딜 미터기 패널이 표시되지 않는다.
- 피해량 집계는 닫힘 상태에서도 계속 진행한다.

### 9.2 열림
- 토글 버튼 아래에 딜 미터기 패널이 표시된다.
- 타워별 항목은 포메이션 배치 순서대로 표시된다.
- 실시간 피해량과 피해 비중이 갱신된다.

### 9.3 다시 닫기
- 열린 상태에서 토글 버튼을 다시 누르면 패널을 숨긴다.
- 숨긴 뒤 다시 열면 전투 시작부터 누적된 최신 피해량을 그대로 표시한다.

## 10. UI 형태 예시
이미지 참고안처럼 우측 상단에서 열리는 검은색 계열 보조 패널을 기준으로 한다.

```text
[DPS 토글]
┌─────────────────┐
│ 딜 미터기        │
│ [1번 얼굴] 12.4K 42% │
│ [2번 얼굴]  9.8K 33% │
│ [3번 얼굴]  4.1K 14% │
│ [4번 얼굴]  2.2K  7% │
│ [5번 얼굴]  1.1K  4% │
└─────────────────┘
```

## 11. 인터랙션
- 토글 버튼 클릭 또는 터치로 열고 닫는다.
- 패널 내부 목록은 마우스 휠 또는 드래그로 스크롤한다.
- 타워 항목을 눌렀을 때 추가 상세창을 열지는 않는다.
- 이번 범위에서는 표시 순서 변경, DPS/누적 피해 전환, 상세 로그 기능은 제외한다.

## 12. 전투 종료 처리
- 전투가 끝나면 딜 미터기 최종 수치를 유지한다.
- 보상 화면 또는 결과 화면에서 동일 데이터를 재사용할 수 있다.
- 다음 전투에 진입하면 누적 피해량은 다시 0으로 초기화한다.

## 13. 이번 범위에서 제외
- 초당 피해량 DPS 계산.
- 스킬별 피해 상세 분해.
- 적 유형별 피해 분해.
- 플레이어가 직접 표시 순서를 바꾸는 기능.
- 딜 미터기 결과를 저장하는 전투 로그 시스템.
- 전투 리플레이와 연동되는 상세 타임라인.

## 14. 확정 사항 요약
- 딜 미터기는 전투 화면 우측 상단 토글 버튼으로 열고 닫는다.
- 닫혀 있어도 피해량 집계는 계속된다.
- 열린 상태에서는 타워 얼굴, 누적 피해량 숫자, 피해 비중 %가 표시된다.
- 목록은 포메이션 배치 순서대로 고정 표시된다.
- 패널은 슬라이더형 세로 목록으로 구성한다.
- 피해량은 최종 적용 피해량 기준으로 집계한다.

## 데미지 표 오버레이 갱신

데미지 표 버튼을 누르면 기존 우측 상단 보조 패널 대신 전투 화면 전체를 덮는 데미지 표 오버레이를 연다.
전투 화면은 뒤에 그대로 남고, 화면 전체에는 투명도 약 50%의 회색 덮개가 깔린다.
데미지 표는 그 덮개 위에 표시한다.

### 진입과 닫기

- 데미지 표 버튼을 누르면 오버레이를 연다.
- 오버레이가 열린 상태에서 데미지 표 버튼을 다시 누르거나 닫기 버튼을 누르면 오버레이를 닫는다.
- 오버레이가 열린 동안 전투 화면 뒤쪽의 스킬, 배속, 조준 모드 버튼은 직접 조작 대상으로 보이지 않는다.
- 전투는 일시정지하지 않는다. 단, 표시 수치는 오버레이가 열린 상태에서도 계속 갱신된다.

### 화면 위치

- 회색 덮개는 화면 전체를 덮는다.
- 데미지 표 패널은 화면 중앙에 크게 배치한다.
- 패널은 상단 보스 체력과 하단 스킬 묶음을 완전히 대신하지 않고, 전투 화면 위에 얹히는 임시 정보창으로 보이게 한다.
- 패널 높이가 목록보다 부족하면 내부 목록만 세로로 넘겨 본다.

### 표시 정보

각 캐릭터 행에는 다음 정보를 표시한다.

| 항목 | 내용 |
|---|---|
| 캐릭터 | 캐릭터 초상 또는 아이콘과 이름 |
| 총 딜량 | 전투 시작 후 해당 캐릭터가 누적한 전체 피해량 |
| 순위와 비율 | 모든 캐릭터 중 최고 총 딜량을 100%로 두었을 때의 현재 비율 |
| 스킬별 딜량 | 기본 공격과 각 액티브 스킬이 누적한 피해량 |

### 막대 표시 규칙

- 모든 캐릭터 중 총 딜량이 가장 높은 캐릭터의 막대를 가장 길게 표시한다.
- 다른 캐릭터의 총 딜량 막대는 최고 총 딜량에 비례해서 짧게 표시한다.
- 각 캐릭터의 총 딜량 막대는 왼쪽에서 시작한다.
- 총 딜량 막대 안은 스킬별 피해량 구간으로 나눈다.
- 같은 캐릭터 안에서 기본 공격과 각 액티브 스킬은 서로 다른 색으로 구분한다.
- 막대 끝이나 막대 안쪽에는 현재 총 딜량 숫자를 표시한다.
- 막대 아래에는 각 스킬 이름과 해당 스킬의 누적 피해량을 함께 표시한다.

## 데미지 표 오버레이 최신 기준

데미지 표 오버레이의 상세 UI 규칙은 `8-1. damage-meter-overlay-layout.md` 문서를 따른다.
최신 기준에서는 캐릭터 행을 총 딜량 순위로 재정렬하지 않고 포메이션 1, 2, 3, 4, 5 순서로 고정한다.
막대 안의 색 구간은 기본 공격, 액티브 스킬, 패시브 추가타를 표시한다.
소환 또는 지속 피해 전용 구간은 사용하지 않는다.
패시브 추가타가 없는 캐릭터는 3가지 색만 보일 수 있고, 패시브 추가타가 2종 있는 캐릭터는 최대 5가지 색이 보일 수 있다.
스킬별 상세 표시에는 작은 보조 막대를 쓰지 않고, 스킬 이름과 누적 딜량만 순서대로 표시한다.
보호막에 실제로 준 피해량은 총 딜량과 해당 스킬별 딜량에 포함한다.
