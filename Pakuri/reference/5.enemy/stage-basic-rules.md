# 스테이지 기본 규칙

> 목적: 각 스테이지에서 등장하는 일반 적, 5라운드 중간보스, 10라운드 중간보스, 보스의 기본 규칙을 정리한다.

## 1. 보스 출현 규칙
- 일반 전투에서는 해당 스테이지의 일반몹 중 1종이 랜덤으로 보스 개체가 되어 등장한다.
- 5라운드에는 해당 스테이지의 `5라운드 중간보스`가 등장한다.
- 10라운드에는 해당 스테이지의 `10라운드 중간보스`가 등장한다.
- 11라운드 보스전에는 `5라운드 중간보스`, `10라운드 중간보스`, `스테이지 보스`가 모두 등장한다.
- 전투마다 등장한 보스 개체는 포로 보상에 확정 포함된다.

적은 처치 대상인 동시에 포로 보상의 후보가 되는 성장 자원이다.
즉 전투 구성은 난이도뿐 아니라 포로 확보 가능성과도 연결된다.

## 2. 적 진입 및 스폰 규칙
- 화면 전체 좌표 기준은 좌측 하단 `(0,0)`부터 우측 상단 `(31,17)`까지이다.
- 적은 기본적으로 전장 오른쪽 화면 경계에서 등장한다.
- 적의 주 목표는 넥서스다.
- 적은 넥서스를 향해 기본적으로 직선에 가까운 압박 형태로 전진한다.
- 현재 단계에서는 우측 단일 진입 축을 기준으로 문서를 고정한다.
- 다중 진입, 곡선 진입, 특수 패턴 진입은 후속 단계에서 별도로 확장한다.

### 2.1 기본 스폰 기준
- 몬스터는 무조건 화면 오른쪽 경계에서 스폰된다.
- 기본 스폰 X 좌표는 우측 화면 경계인 `31`로 고정한다.
- 일반 몬스터의 Y 좌표는 `0~17` 범위 안에서 랜덤으로 결정한다.
- 보스 몬스터는 화면 중간 높이 부근에서 스폰되며, 기본 기준점은 `(31, 8)`로 잡는다.
- 즉 적은 화면 우측 경계에서 등장한 뒤 넥서스 방향으로 좌측을 향해 압박해 들어오는 구조를 기본값으로 한다.

## 3. 전투별 보스 개체
모든 전투에는 보스 개체가 존재한다.

| 전투 종류 | 보스 개체 |
|---|---|
| 일반 전투 | 해당 스테이지 일반몹 중 1종이 랜덤 선택되어 보스 개체로 등장 |
| 5라운드 중간보스 전투 | 해당 스테이지의 5라운드 중간보스가 등장 |
| 10라운드 중간보스 전투 | 해당 스테이지의 10라운드 중간보스가 등장 |
| 11라운드 보스 전투 | 5라운드 중간보스 + 10라운드 중간보스 + 스테이지 보스가 함께 등장 |

## 4. 일반 전투 보스 생명력
일반 전투 보스는 선택된 일반몹의 최대 생명력이 스테이지에 따라 증가한다.

| 스테이지 | 일반 전투 보스 생명력 배율 |
|---:|---:|
| 1스테이지 | 10~20배 |
| 2스테이지 | 20~30배 |
| 3스테이지 | 30~40배 |
| 4스테이지 | 40~50배 |

## 5. 스테이지별 보스 구성

| 스테이지 | 일반 적 수 | 일반 적 방향 | 5라운드 중간보스 | 10라운드 중간보스 | 스테이지 보스 |
|---:|---:|---|---|---|---|
| 1스테이지 | 5종 | 용사길드, 기본 직업군 학습 | 수호대장 | 공격대장 | 용사 카린 |
| 2스테이지 | 5종 | 용살자, 속성 용사 | 성창추적자 에단 | 용살자 드레이크 | 용살기사단장 아르센 |
| 3스테이지 | 5종 | 환영, 분신과 타겟 교란 | 환술사 로키 | 예언자 모르간 | 사도 라키아 |
| 4스테이지 | 6종 | 천상, 신성 심판과 보호막 | 집행관 미카엘 | 대행자 토르 | 심판자 세라프 |
