# 2스테이지 적 컨셉 - 용살자

> 컨셉: 괴물과 용을 사냥해온 영웅 집단. 관통, 강타, 방어구 파괴, 보스 사냥에 특화된 스테이지.

## 1. 스테이지 방향
2스테이지는 `용을 죽이는 영웅들`을 중심으로 잡는다.
원작의 강한 영웅 조우처럼, 일반 용사보다 한 단계 위의 전설 후보들이 나온다는 느낌이 필요하다.

- 속성은 물리, 화염, 번개를 중심으로 둔다.
- 용비늘, 성창, 대검, 쇠뇌, 사냥 표식 같은 이미지가 핵심이다.
- 단단한 적을 뚫는 관통과 강타 패턴을 많이 사용한다.
- 플레이어 입장에서는 전열이 순식간에 무너지는 압박을 받는다.

## 2. 몹 목록

| 구분 | 이름 | 속성 | 공격 타입 | 전투 컨셉 |
|---|---|---|---|---|
| 일반 | 용비늘 창병 | 물리 | 근거리 | 창 돌진으로 전열에 빠르게 접근한다. |
| 일반 | 쇠뇌 사냥꾼 | 물리 | 원거리 | 느리지만 강한 관통 화살을 발사한다. |
| 일반 | 화염병 투척수 | 화염 | 원거리 | 작은 범위 화염 장판을 남긴다. |
| 일반 | 용가죽 방패병 | 물리 / 화염 | 근거리 | 화염 저항과 방어력이 높아 오래 버틴다. |
| 일반 | 사냥 표식술사 | 번개 | 원거리 | 아군이 집중 공격할 표식을 부여한다. |
| 5일차 중간보스 | 성창추적자 에단 | 물리 / 번개 | 원거리 | 가장 멀리 있는 대상을 향해 성창을 던진다. |

| 보스 | 용살자 아르센 | 물리 / 화염 | 근거리 | 체력 구간마다 화염 저항 증가, 대검 참격, 사냥 표식을 사용한다. |

## 3. 패턴 방향
- `용비늘 창병`은 1스테이지 근거리 일반몹보다 빠르고 위협적이어야 한다.
- `쇠뇌 사냥꾼`은 관통으로 후열까지 위협한다.
- `사냥 표식술사`는 새 디버프를 복잡하게 쌓기보다, 표식 대상에게 적 공격이 몰리는 정도로 단순하게 둔다.
- 보스는 용을 잡았던 영웅답게 단일 강타와 화염 내성을 핵심으로 한다.
- 일반 전투에서는 일반몹 5종 중 1종이 랜덤으로 보스 개체가 되어 생명력 20~30배로 등장한다.

## 4. 후속 작업
- 관통 공격의 기본 규칙 정리
- 표식 패턴을 디버프 시스템에 넣을지, 적 AI 우선순위로만 처리할지 결정
- 용살자 계열 포로 보너스 작성
