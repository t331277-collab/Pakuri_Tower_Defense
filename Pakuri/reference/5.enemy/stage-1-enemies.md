# 1스테이지 적 목록 - 용사길드

> 컨셉: 던전에 처음 진입한 인간 용사 길드. 일반몹은 직업명 중심, 중간보스와 보스는 이름으로 개성을 준다.

## 1. 스테이지 규칙
- 일반 전투에서는 일반몹 5종 중 1종이 랜덤으로 강화 보스가 되어 등장한다.
- 일반 전투 보스의 생명력은 원본 일반몹 생명력의 10~20배로 증가한다.
- 5일차에는 `검호 레온`이 중간보스로 등장한다.
- 10일차에는 `기사단장 브란`이 중간보스로 등장한다.
- 11일차 보스전에는 `검호 레온`, `기사단장 브란`, `용사 카린`이 모두 등장한다.
- 전투마다 등장한 보스 개체는 포로 보상에 확정 포함된다.

| 견습 검사 | 근거리 | 물리 | 1.00 | 100 | 검으로 단일 대상 공격 | 없음 |

| 궁수 | 원거리 | 물리 | 0.90 | 80 | 화살로 단일 대상 공격 | `조준 사격`: 가장 가까운 아군에게 강한 화살 1발 발사 |
| 도적 | 근거리 | 물리 | 1.35 | 70 | 단검으로 빠르게 공격 | `기습`: 짧게 전진해 후열에 가까운 대상을 공격 |
| 사제 | 원거리 | 신성 | 0.80 | 90 | 약한 신성탄 발사 | `치유`: 주변 적 1명의 체력 80 회복 |

| 전투 컨셉 | 1스테이지의 첫 중간보스. 단순하지만 공격 빈도가 높아 전열 유지력을 시험한다. |

## 5. 스테이지 보스

| 항목 | 내용 |
|---|---|
| 이름 | 용사 카린 |

| 속성 | 물리 / 신성 |
| 이동속도 | 1.00 |
| 체력 | 5,000 |
| 기본 공격 | 성검으로 단일 대상 공격 |

| 스킬 2 | `용사의 외침`: 모든 아군 영웅에게 6초 동안 공격력 20% 증가 |
| 스킬 3 | `동료 호출`: 방패병, 궁수, 사제 중 2명을 소환 |
| 전투 컨셉 | 1스테이지 직업군을 모두 묶는 대표 보스. 11일차에는 두 중간보스와 함께 등장한다. |

## 6. 후속 작업
- 실제 전투 시간 기준으로 체력 보정
- 일반 전투 보스가 되었을 때 추가 스킬을 받을지 결정
- 포로가 된 `검호 레온`, `기사단장 브란`, `용사 카린`의 보너스 작성
