# Dungeon Squad 배치 / 포메이션 / 전술 구조 분석

## 1. 기본 배치 개념
Dungeon Squad는 전통적인 타워 설치형 게임은 아니지만, 스쿼드 배치와 포메이션 선택이 사실상 타워 배치 역할을 한다.

## 2. 플레이어가 통제하는 배치 축
- 어떤 몬스터를 스쿼드에 넣는가
- 어떤 몬스터를 리더로 쓰는가
- 어떤 포메이션을 채택하는가
- 어떤 태그/원소 스킬을 가진 몬스터를 전장에 세우는가

## 3. 포메이션의 의미
포메이션은 단순 버프가 아니라 **고정된 몬스터 배치 위치와 그 위치에 붙는 특수 보정**으로 이해하는 편이 맞다.

즉 포메이션은:
- 몬스터가 놓일 수 있는 위치가 정해져 있고
- 각 위치 또는 포지션 조합에 따라
- 특정 스탯/속성/전술 효과가 강화되는 구조다.

확인된 방향 예시:
- Defense : 체력, 방어력, 피해감소, 회복, 배리어 안정화 강화
- Element : 화염/냉기/번개/산성 중심 속성 피해 강화
- Salvo : 탄약형 스킬 중심 화력 강화
- Siege : 디버프 지속/행동 제한/유혹 계열 시너지 강화
- Black and White : 성/암 속성 조합 강화
- Megalith : 물리 중심 강화

※ Charge처럼 전진/이동으로 해석하는 축은 현재 재검토 대상이며, 포메이션을 이동형이 아니라 **배치 위치 + 위치별 버프형**으로 보는 기준이 우선이다.

## 4. 포메이션 설계 특징
- 각 포메이션은 **허용되는 몬스터 위치 구조**를 가진다.
- 같은 포메이션이라도 어떤 칸에 어떤 몬스터를 두는지에 따라 효율이 달라질 수 있다.
- 특정 스킬 태그를 가진 몬스터를 배치해야 포메이션 효율이 오른다.
- 포메이션은 아군 강화뿐 아니라 적 영웅의 저항 상승 같은 상쇄 페널티도 가진다.
- 따라서 단순히 제일 강한 포메이션 하나가 아니라, 빌드에 맞는 포메이션 선택이 필요하다.
- 포메이션 단계에 따라 강화 폭과 부작용이 달라질 수 있다.

## 5. 타워디펜스 기획으로 번역할 때의 핵심 참고점
Dungeon Squad를 타워디펜스로 재해석할 때 배치 구조는 아래 식으로 치환 가능하다.
- 리더 몬스터 = 주력 코어 유닛/지휘 타워
- 보조 몬스터 = 서브 타워 슬롯
- 포메이션 = 전술 프리셋 / 전장 모드
- 스킬 태그 시너지 = 타워 클래스 조합 보너스

## 6. 디자인적으로 중요한 부분
이 게임의 배치 재미는 좌표 설치보다 ‘구성 선택’에 있다.
즉 전장의 재미가 위치 하나하나보다,
- 어떤 역할군을 넣었는지
- 어떤 속성축을 선택했는지
- 어떤 포메이션으로 전체 보정을 가져가는지
에 더 크게 실린다.

## 7. 4번 씬(편성 씬) UI 배치 기준
4번 씬은 전장 맵처럼 보이는 화면이 아니라, 스쿼드 구성과 포메이션 선택을 빠르게 판단하는 편성 UI여야 한다.

### 7.1 화면 목적
- 전투 시작 전 최종 스쿼드를 편성한다.
- 리더와 서브 슬롯 구성을 확정한다.
- 현재 빌드에 맞는 포메이션을 선택한다.
- 선택한 몬스터와 포메이션의 시너지를 한 화면에서 읽게 한다.

### 7.2 화면 구조
- 상단 바: 씬 제목, 현재 전투력, 보유 자원, 메인 타워/리더 요약
- 좌측 패널: 편성 후보 몬스터 목록
- 중앙 패널: 고정 배치 위치를 가진 스쿼드 슬롯 보드
- 우측 패널: 선택 몬스터 상세 + 포메이션 시너지 요약
- 하단 패널: 포메이션 선택 카드 + 편성 확정 버튼

### 7.3 좌측 패널 역할
좌측 패널은 단순 후보 리스트가 아니라 ‘현재 편성 가능한 풀’을 보여주는 영역이다.
표시 우선순위:
- 몬스터 이름
- 역할군(전열 / 후열 / 지원 / 디버프)
- 속성 또는 핵심 태그
- 현재 편성 여부
- 리더 지정 가능 여부

필터 추천 축:
- 전체
- 전열
- 후열
- 지원
- 속성
- 태그

### 7.4 중앙 패널 역할
중앙 패널은 물리 좌표 배치 보드다.
- 리더 슬롯 1개는 크게 강조
- 서브 슬롯 4개는 리더 주변에 배치
- 각 슬롯은 위치 전략보다 역할 구성을 읽게 해야 함
- 빈 슬롯 / 배치 완료 / 시너지 활성 상태를 시각적으로 구분
- 포메이션마다 허용되는 배치 위치와 강화 대상이 다르게 보이도록 해야 함

권장 배치 형태:
- 상단 중앙: 리더 슬롯
- 중단 좌우: 서브 슬롯 2개
- 하단 좌우 또는 하단 중앙: 서브 슬롯 2개

### 7.5 우측 패널 역할
우측 패널은 일반적인 RPG 상세창보다 ‘현재 편성 판단’에 필요한 정보 중심이어야 한다.
우선 정보:
- 이름
- 역할
- 속성
- 핵심 태그
- 대표 스킬 요약
- 현재 포메이션과의 적합도
- 추천 조합 방향

### 7.6 하단 패널 역할
하단 패널은 포메이션 선택을 위한 전술 바다.
포메이션은 단순 버튼이 아니라 카드 형태로 보여야 하며, 최소 아래 정보가 필요하다.
- 포메이션 이름
- 핵심 효과 1줄 요약
- 추천 빌드 태그
- 현재 편성과의 적합도 표시

확정 버튼 규칙:
- 리더 포함 최소 편성 조건 충족 전에는 비활성화
- 선택 포메이션이 없으면 비활성화 또는 경고 상태 유지
- 버튼 텍스트는 ‘편성 완료’ 또는 ‘전투 시작’ 중 하나로 통일

### 7.7 원작 참고 기준의 핵심 해석
- 이 씬의 재미는 ‘좌표 배치’보다 ‘구성 선택’에 있다.
- 중앙 보드는 위치놀이보다 팀 구조를 읽게 해야 한다.
- 포메이션 정보는 장식이 아니라 화면의 핵심 의사결정 요소다.
- 상세 패널은 설정집이 아니라 현재 조합 판단 도구여야 한다.
