# 이벤트 목록

> 목적: 일반 전투와 정예 전투에 진입한 직후 20% 확률로 발생하는 이벤트의 문구, 선택지, 확률 결과 예시를 정리한다.

공통 등장 규칙은 [`event-system.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F4.run%2Fevent-system) 참고.
이 문서의 이벤트는 상점형 선택지를 포함하지 않는다.

## 1. 수상한 포로

낡은 쇠사슬에 묶인 포로 한 명을 마주했다.  
살려둘까, 더 뒤져볼까?

| 선택지 | 비용 | 확률 결과 |
|---|---|---|
| 포로를 풀어준다 | 없음 | 80%: 무작위 포로 1명 획득 / 20%: 포로 1명과 골드 10 획득 |
| 주변을 더 뒤진다 | 없음 | 60%: 무작위 포로 1명 획득 / 25%: 아무 일 없음 / 15%: 이번 전투 적 공격력 +10%, 포로 2명 획득 |
| 지나친다 | 없음 | 100%: 아무 일 없음 |

## 2. 금 간 제단

금이 간 제단에서 검은 빛이 새어 나온다.  
피를 바치면 무언가 답할지도 모른다.

| 선택지 | 비용 | 확률 결과 |
|---|---|---|
| 손끝의 피를 바친다 | 현재 체력 10% | 70%: 모든 아군 공격력 +5% / 20%: 모든 아군 공격력 +8% / 10%: 아무 보상 없음 |
| 깊게 피를 바친다 | 현재 체력 20% | 50%: 조건 없는 일반 유물 1개 획득 / 30%: 모든 아군 피해 +8% / 20%: 이번 전투 받는 피해 +15% |
| 제단을 부순다 | 없음 | 60%: 골드 20 획득 / 25%: 어둠의 흔적 10개 획득 / 15%: 이번 전투 적 체력 +10% |

## 3. 어둠 광맥

조심히 캐낼까, 깊게 파낼까?

| 선택지 | 비용 | 확률 결과 |
|---|---|---|

| 깊게 채굴한다 | 이번 전투 적 공격력 +15% | 55%: 어둠의 흔적 45개 획득 / 25%: 어둠의 흔적 60개 획득 / 20%: 어둠의 흔적 25개 획득 |
| 무시한다 | 없음 | 100%: 아무 일 없음 |

| 선택지 | 비용 | 확률 결과 |

| 선택지 | 비용 | 확률 결과 |
|---|---|---|
| 조심히 사용한다 | 없음 | 75%: 이번 전투 모든 아군 피해 +15% / 15%: 이번 전투 모든 아군 피해 +25% / 10%: 아무 일 없음 |
| 강제로 폭주시킨다 | 이번 전투 받는 피해 +15% | 50%: 이번 전투 모든 아군 피해 +30% / 30%: 모든 아군 공격력 +5% / 20%: 이번 전투 적 공격력 +15% |
