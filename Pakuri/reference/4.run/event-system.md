# 이벤트 시스템

> 목적: 이벤트의 선택지 구조와 예시 이벤트를 정의한다.

## 1. 이벤트 구조
이벤트는 전투 후 짧은 선택지를 제공하는 런 내부 변주 콘텐츠다.

이벤트 기본 규칙:
- 이벤트는 2~3개의 선택지를 제공한다.
- 선택지는 보상, 위험 부담, 골드 소비, 체력 소비, 포로 소비 중 하나 이상을 포함한다.
- 이벤트는 현재 런에만 영향을 주는 것을 기본으로 한다.
- 어둠의 흔적을 직접 지급하는 이벤트는 낮은 빈도로 둔다.
- 이벤트 등장 일차와 등장 확률은 [`dungeon-squad-run-structure.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F4.run%2Fdungeon-squad-run-structure)에서 관리한다.

## 2. 이벤트 예시

| 이벤트 | 선택지 예시 | 기획 의도 |
|---|---|---|
| 수상한 포로 | 포로 1명 획득 / 골드 20 지불 후 포로 2명 획득 / 무시 | 포로 수급 변주 |
| 떠돌이 상인 | 골드 30 지불 후 스킬 강화 / 골드 50 지불 후 유물 후보 갱신권 획득 / 무시 | 상점 축소판 |
| 금 간 제단 | 모든 아군 체력 15% 소모 후 유물 후보 1개 예약 / 무시 | 체력과 성장 교환 |
| 어둠의 잔향 | 어둠의 흔적 15개 획득 / 다음 전투 적 체력 +10%와 어둠의 흔적 30개 획득 | 외부 재화 리스크 보상 |
| 버려진 병참품 | 회복 물약 획득 / 보호 부적 획득 / 골드 15 획득 | 소규모 보급 |
| 불안정한 마석 | 다음 전투 모든 아군 피해 +20%, 받는 피해 +15% / 무시 | 고위험 전투 버프 |
| 훈련 교관 | 골드 35 지불 후 무작위 아군 스킬 강화 / 포로 1명 소모 후 원하는 아군 스킬 강화 | 스킬 성장 선택 |
| 봉인된 궤짝 | 골드 25 지불 후 무작위 보상 / 체력 10% 소모 후 더 좋은 무작위 보상 / 무시 | 도박성 보상 |
| 길 잃은 정령 | 정령계약 유물 후보 확률 증가 / 다음 전투 속성 피해 +15% / 무시 | 시너지 유도 |
| 낡은 지도 | 다음 일반 진행일에 이벤트 등장 확률 +25% / 다음 일반 진행일에 상점 등장 확률 +25% | 진행 루트 조정 |

## 3. 후속 결정 필요 항목
- 이벤트 선택지의 체력 소모가 현재 체력 기준인지 최대 체력 기준인지
- 이벤트 보상에 유물 직접 획득을 허용할지 여부
- 이벤트 선택지를 고정형으로 둘지, 일부 무작위 보정할지 여부
