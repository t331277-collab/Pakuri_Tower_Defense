# Dungeon Squad 런 내부 반복 구조 분석

> 목적: Dungeon Squad의 한 런이 어떤 단위로 반복되는지 정리한다.
> 주의: 이 문서는 일차 진행, 스테이지 구성, 보상 선택, 런 내부 성장 흐름을 중심으로 정리한다.

## 1. 런의 기본 형식
Dungeon Squad의 런 내부 진행은 일차별 반복 구조로 이루어진다.

- 총 4개의 스테이지가 있다.
- 각 스테이지는 11일 단위로 진행된다.
- 5일과 10일에는 중간보스 전투가 발생한다.
- 11일에는 최종 보스 전투가 발생한다.

즉, 한 스테이지는 11일 동안 진행되며, 중간보스와 최종 보스를 포함한 압축된 반복 구간으로 구성된다.

## 2. 일차별 콘텐츠 구성
각 스테이지의 일차는 고정 전투일과 일반 진행일로 나뉜다.

| 일차 | 기본 구성 | 추가 등장 가능 |
|---:|---|---|
| 1일 | 스테이지 시작 / 고정 전투 | 없음 |
| 2~4일 | 일반 전투 | 상점, 이벤트 |
| 5일 | 중간보스 전투 | 없음 |
| 6~9일 | 일반 전투 | 상점, 이벤트 |
| 10일 | 중간보스 전투 | 없음 |
| 11일 | 보스 전투 | 없음 |

일반 진행일에는 일반 전투가 항상 등장한다.
상점과 이벤트는 확률적으로 추가 등장할 수 있으며, 둘은 동시에 등장할 수 있다.

예시:
- 일반 전투만 등장
- 일반 전투 + 상점
- 일반 전투 + 이벤트
- 일반 전투 + 상점 + 이벤트

상점 등장 규칙:
- 상점은 한 스테이지에서 최대 1번만 등장한다.
- 상점은 확률 등장 콘텐츠이므로, 해당 스테이지에서 아예 등장하지 않을 수 있다.
- 상점이 이미 등장한 스테이지에서는 남은 일반 진행일에 상점이 다시 등장하지 않는다.
- 이벤트는 상점과 별도로 등장 여부를 판정한다.

등장 확률:

| 콘텐츠 | 기본 등장 확률 | 제한 |
|---|---:|---|
| 상점 | 일반 진행일마다 15% | 스테이지당 최대 1회 |
| 이벤트 | 일반 진행일마다 25% | 제한 없음 |

상점 상품 예시는 [`shop-system.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F4.run%2Fshop-system) 참고.
이벤트 예시는 [`event-system.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F4.run%2Fevent-system) 참고.

## 3. 일차 진행 흐름
각 일차는 전투와 보상 선택을 중심으로 반복된다.

기본 흐름:
1. 일차 전투 진행
2. 전투 후 보상 확인
3. 포로, 유물, 골드, 어둠의 흔적 보상 확인
4. 스킬 습득, 강화, 동화 등 포로 기반 선택 진행
5. 다음 일차로 이동

이 흐름이 스테이지 종료 시점까지 반복된다.

## 4. 전투 보상 구조
전투 종료 후 보상 규칙은 별도 문서에서 관리한다.

- 포로 등장 수와 확률
- 모든 전투의 보스 포로 확정 규칙
- 일반 전투 보스의 생명력 배율
- 5일차 중간보스, 10일차 중간보스, 보스 유물 보상
- 유물 3택 1 후보 생성 및 중복 방지
- 런 외부 재화 `어둠의 흔적` 지급량

자세한 내용은 [`combat-reward-system.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F4.run%2Fcombat-reward-system) 참고.

## 5. 런 내부 성장의 의미
런 내부 성장에서는 다음과 같은 강화가 누적된다.

- 스킬 습득 및 강화
- 유물 획득
- 전투력 보강
- 빌드 방향 확정

이 과정은 아웃 게임 성장과 구분된다.

- 아웃 게임 성장은 런 밖에서 누적되는 장기 성장이다.
- 런 내부 성장은 현재 런 안에서만 유효한 성장이다.

## 6. 스테이지 구조의 역할
4개의 스테이지는 단순한 반복 구간이 아니라, 런의 진행 속도와 빌드 완성도를 조절하는 단위다.

- 초반 스테이지: 기본 전력 확보
- 중반 스테이지: 핵심 스킬과 유물 확립
- 후반 스테이지: 보스 대응 빌드 완성
- 최종 스테이지: 전체 조합 검증

## 7. 기획적 해석
Dungeon Squad의 런은 단발성 전투 묶음이 아니라, 일차 단위 선택과 보상 누적으로 빌드를 완성하는 구조다.

핵심은 다음과 같다.
- 매 일차마다 진행과 보상이 연결된다.
- 보상은 스킬이나 유물 같은 런 내부 강화를 제공한다.
- 11일 단위 스테이지가 리듬을 만든다.
- 중간보스와 최종 보스가 빌드 완성 여부를 점검한다.

## 8. 유물 보상 구조
유물은 중간보스전과 보스전에서 드랍되는 런 내부 강화 보상이다.

- 5일과 10일 중간보스 처치 시 유물 보상을 제공한다.
- 11일 보스 처치 시 유물 보상을 제공한다.
- 유물 보상은 무작위 후보 3개 중 1개를 선택한다.
- 이미 보유한 유물은 후보에 등장하지 않는다.
- 유물은 장착 장비가 아니라, 획득 즉시 파티 전체에 적용되는 런 강화다.
- 유물은 롤체 시너지처럼 특정 조건을 만족한 아군 또는 파티 전체를 강화한다.
- 유물의 시각 표현은 Slay the Spire 유물처럼 작은 아이콘형 오브젝트로 둔다.

## 9. 유물 효과 방향
유물 효과는 특정 캐릭터 하나를 직접 강화하기보다, 파티 조합의 방향을 밀어주는 효과를 우선한다.

| 유형 | 효과 예시 | 기획 의도 |
|---|---|---|
| 속성 시너지 | 화염 스킬을 가진 아군 2명 이상이면 모든 아군 화염 피해 증가 | 속성 파티 구성 보상 |
| 역할 시너지 | 방어막을 부여하는 아군이 있으면 모든 아군 받는 피해 감소 | 역할 조합 보상 |
| 상태 시너지 | 낙인, 표식, 노출 대상에게 모든 아군 피해 증가 | 상태 중심 빌드 보상 |
| 전투 리듬 | 전투 시작 시 모든 아군 방어막 부여 | 초반 안정성 보상 |
| 처치 보상 | 중간보스 또는 보스 처치 후 모든 아군 쿨타임 충전 | 후반 공세 보상 |

## 10. 유물 설계 기준
- 유물은 한 런에서 얻는 장기 선택지이므로, 단순 피해 증가보다 파티 구성 조건을 붙이는 쪽을 우선한다.
- 조건은 플레이어가 이해하기 쉬워야 한다.
- 조건은 캐릭터 속성, 역할, 상태, 방어막, 탄창, 장판처럼 이미 문서화된 전투 축을 사용한다.
- 유물 하나가 특정 캐릭터 전용처럼 보이지 않게 하고, 최소 2명 이상의 파티 구성과 연결되게 한다.
- 유물은 장비 슬롯을 차지하지 않는다.
- 유물 시너지와 유물 목록은 [`artifact-synergy-list.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F4.run%2Fartifact-synergy-list) 참고
