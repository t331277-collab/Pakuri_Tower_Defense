# Dungeon Squad 런 내부 반복 구조 분석

> 목적: Dungeon Squad의 한 런이 어떤 단위로 반복되는지 정리한다.
> 주의: 이 문서는 라운드 진행, 스테이지 구성, 보상 선택, 런 내부 성장 흐름을 중심으로 정리한다.

## 1. 런의 기본 형식
Dungeon Squad의 런 내부 진행은 라운드별 반복 구조로 이루어진다.

- 총 4개의 스테이지가 있다.
- 각 스테이지는 11라운드 단위로 진행된다.
- 5라운드와 10라운드에는 중간보스 전투가 발생한다.
- 11라운드에는 최종 보스 전투가 발생한다.
- `4-8`처럼 표기할 때 앞 숫자는 스테이지, 뒤 숫자는 라운드를 뜻한다.
- 예: `4-8`은 `4스테이지 8라운드`다.

즉, 한 스테이지는 11라운드 동안 진행되며, 중간보스와 최종 보스를 포함한 압축된 반복 구간으로 구성된다.

## 2. 라운드별 콘텐츠 구성
각 스테이지의 라운드는 고정 전투 라운드와 일반 진행 라운드로 나뉜다.

| 라운드 | 기본 구성 | 선택지 |
|---:|---|---|
| 1라운드 | 스테이지 시작 / 고정 전투 | 없음 |
| 2~4라운드 | 일반 진행 라운드 | 일반 전투, 정예 전투 |
| 5라운드 | 중간보스 전투 | 없음 |
| 6~9라운드 | 일반 진행 라운드 | 일반 전투, 정예 전투, 상점 |
| 10라운드 | 중간보스 전투 | 없음 |
| 11라운드 | 보스 전투 | 없음 |

2~4라운드, 6~9라운드에는 일반 전투가 기본 선택지로 등장한다.
정예 전투는 매 일반 진행 라운드마다 30% 확률로 선택지에 추가된다.
정예 전투를 선택하면 해당 라운드 전투에 등장하는 모든 적이 같은 정예 접두 효과를 받으며, 전투 보상에 포로 1명이 추가된다.

상점은 6~9라운드 중 한 라운드에만 선택지로 등장한다.
상점을 선택하면 해당 라운드는 전투 없이 상점 이용만 하고 다음 라운드로 넘어간다.
6~9라운드에는 일반 전투, 정예 전투, 상점 선택지가 한 번에 모두 보일 수 있다.

상점 상품 예시는 [`shop-system.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F4.run%2Fshop-system) 참고.
정예 전투 규칙은 [`elite-combat-system.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F4.run%2Felite-combat-system) 참고.
전투 진입 직후 발생하는 이벤트 규칙은 [`event-system.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F4.run%2Fevent-system) 참고.

## 3. 라운드 진행 흐름
각 라운드는 전투와 보상 선택을 중심으로 반복된다.

기본 흐름:
1. 일반 진행 라운드이면 이번 라운드의 선택지를 표시한다.
2. 상점을 선택했다면 상점 이용 후 다음 라운드로 이동한다.
3. 일반 전투 또는 정예 전투를 선택했다면 라운드 전투를 진행한다.
4. 전투 진입 직후 20% 확률로 이벤트 발생 여부를 판정한다.
5. 이벤트가 발생했다면 이벤트 선택과 결과 적용 후 원래 전투로 복귀한다.
6. 전투 후 보상을 확인한다.
7. 정예 전투라면 포로 1명 추가 보상을 적용한다.
8. 스킬 습득, 강화, 동화 등 포로 기반 선택을 진행한다.
9. 다음 라운드로 이동한다.

이 흐름이 스테이지 종료 시점까지 반복된다.

## 4. 전투 보상 구조
전투 종료 후 보상 규칙은 별도 문서에서 관리한다.

- 포로 등장 수와 확률
- 모든 전투의 보스 포로 확정 규칙
- 일반 전투 보스의 생명력 배율
- 5라운드 중간보스, 10라운드 중간보스, 보스 유물 보상
- 유물 3택 1 후보 생성 및 중복 방지
- 런 외부 재화 `어둠의 흔적` 지급량

자세한 내용은 [`combat-reward-system.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F4.run%2Fcombat-reward-system) 참고.
포로 사용 선택지는 [`prisoner-choice-system.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F4.run%2Fprisoner-choice-system) 참고.

## 5. 런 내부 성장의 의미
런 내부 성장에서는 다음과 같은 강화가 누적된다.

- 스킬 습득 및 강화
- 유물 획득
- 전투력 보강
- 빌드 방향 확정

이 과정은 아웃 게임 성장과 구분된다.

- 아웃 게임 성장은 런 밖에서 누적되는 장기 성장이다.
- 런 내부 성장은 현재 런 안에서만 유효한 성장이다.

## 6. 스테이지 구조의 역할
4개의 스테이지는 단순한 반복 구간이 아니라, 런의 진행 속도와 빌드 완성도를 조절하는 단위다.

- 초반 스테이지: 기본 전력 확보
- 중반 스테이지: 핵심 스킬과 유물 확립
- 후반 스테이지: 보스 대응 빌드 완성
- 최종 스테이지: 전체 조합 검증


## 7. 유물 보상 구조
유물은 중간보스전과 보스전에서 드랍되는 런 내부 강화 보상이다.

- 5라운드와 10라운드 중간보스 처치 시 유물 보상을 제공한다.
- 11라운드 보스 처치 시 유물 보상을 제공한다.
- 유물 보상은 무작위 후보 3개 중 1개를 선택한다.
- 이미 보유한 유물은 후보에 등장하지 않는다.
- 유물은 장착 장비가 아니라, 획득 즉시 파티 전체에 적용되는 런 강화다.
- 유물은 롤체 시너지처럼 특정 조건을 만족한 아군 또는 파티 전체를 강화한다.
- 유물의 시각 표현은 Slay the Spire 유물처럼 작은 아이콘형 오브젝트로 둔다.


## 8. 유물 설계 기준
- 유물은 한 런에서 얻는 장기 선택지이므로, 단순 피해 증가보다 파티 구성 조건을 붙이는 쪽을 우선한다.
- 조건은 플레이어가 이해하기 쉬워야 한다.
- 조건은 캐릭터 속성, 역할, 상태, 방어막, 탄창, 장판처럼 이미 문서화된 전투 축을 사용한다.
- 유물 하나가 특정 캐릭터 전용처럼 보이지 않게 하고, 최소 2명 이상의 파티 구성과 연결되게 한다.
- 유물은 장비 슬롯을 차지하지 않는다.
- 유물 시너지와 유물 목록은 [`artifact-synergy-list.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F4.run%2Fartifact-synergy-list) 참고

## 9. 문서 정리 기준
