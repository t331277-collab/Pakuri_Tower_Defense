# 정예 전투 시스템

> 목적: 일반 진행 라운드에 등장하는 정예 전투의 구조, 접두 이벤트, 추가 보상을 정의한다.

정예 전투는 새 몬스터 종류를 추가하지 않는다.
기존 스테이지 적 구성에 라운드 단위 접두 이벤트를 붙여, 해당 라운드 전투에 등장하는 모든 용사가 같은 강화 규칙을 받는 방식이다.

## 1. 기본 규칙

| 항목 | 규칙 |
|---|---|
| 등장 라운드 | 2~4라운드, 6~9라운드 |
| 등장 방식 | 매 일반 진행 라운드마다 30% 확률로 선택지에 추가 |
| 전투 구성 | 해당 스테이지의 기존 일반 전투 구성을 사용 |
| 정예 적용 방식 | 해당 라운드 전투 전체에 접두 이벤트 적용 |
| 대상 | 그 전투에 등장하는 모든 용사 |
| 몬스터 추가 여부 | 새 몬스터 종류를 추가하지 않음 |
| 추가 보상 | 포로 1명 추가 |

정예 전투는 “광폭한 검사”처럼 개별 몬스터 이름을 새로 만드는 방식이 아니다.
대신 `광폭한 라운드`처럼 라운드 자체에 접두 이벤트가 붙은 전투 선택지이며, 그 전투에 등장하는 모든 용사가 광폭 효과를 받는다.

## 2. 정예 접두 이벤트

| 접두 이벤트 | 적용 효과                          | 기획 의도           |
| ------ | ------------------------------ | --------------- |
| 광폭한    | 모든 적 공격력 40%, 행동속도 10% 증가      | 단순하고 직관적인 화력 압박 |
| 수호받는   | 모든 적 방어력 40% 증가                | 장기전과 방어력 대응 학습  |
| 재생하는   | 모든 적이 5초마다 최대 체력 10% 회복        | 화력 부족 파티를 압박    |
| 저주받은   | 전투 시작 시 모든 타워 위력 15% 감소        | 디버프 대응과 안정성 검증  |
| 분열하는   | 일반 적이 사망 시 20% 확률로 약한 분신 1체 생성 | 광역 처리 능력 검증     |


## 3. 보상 규칙

정예 전투는 일반 전투 보상을 기준으로 하되, 포로 1명을 추가로 제공한다.

| 전투 | 보상 |
|---|---|
| 일반 전투 | 기본 포로 보상 |
| 정예 전투 | 기본 포로 보상 + 포로 1명 |

정예 전투 추가 포로는 해당 스테이지의 일반 포로 후보에서 뽑는다.
전투 보스 포로 확정 규칙은 기존 전투 보상 규칙을 그대로 따른다.

관련 보상 규칙은 [`combat-reward-system.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F4.run%2Fcombat-reward-system) 참고.

## 4. 후속 결정 필요 항목

- 정예 접두 이벤트별 수치가 과하게 강한지
- 상점과 정예 전투가 함께 등장했을 때 UI 우선순위
