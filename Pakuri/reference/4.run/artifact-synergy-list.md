# 유물 시너지 목록

> 목적: 중간보스 및 보스전에서 드랍되는 유물의 시너지 이름, 누적 효과, 고유 효과 예시를 정리한다.
> 참고 방향: TFT 특성처럼 짧고 기억하기 쉬운 진영/직업/판타지형 이름을 사용한다.

## 1. 유물 기본 구조
- 유물에는 등급이 없다.
- 유물마다 `보유 시너지`와 `고유 효과`가 있다.
- 같은 시너지 유물을 많이 모을수록 해당 시너지 효과가 증폭된다.
- 유물은 획득 즉시 현재 런 동안 파티 전체에 적용된다.

## 2. 시너지 단계

| 보유 수 | 단계 | 설명 |
|---:|---|---|
| 2개 | 1단계 | 방향성 확인 |
| 4개 | 2단계 | 빌드 핵심 |
| 6개 | 3단계 | 주력 시너지 |
| 8개 | 4단계 | 완성 시너지 |

## 3. 시너지 6종 요약

| 시너지명 | 설계 방향 | 핵심 효과 |
|---|---|---|
| 정령계약 | 정령왕 소환 | 전장 가운데 정령왕을 소환하고 단계별 스킬을 해금 |
| 처형관 | 치명타 처형 | 치명타 확률과 치명타 피해를 크게 높이고 낮은 체력 대상을 마무리한다 |
| 선택받은자 | 캐리 지정 | 선택된 타워 1명을 중심으로 앙코르, 최종 데미지 증가, 하이라이트, 피날레를 제공한다 |
| 파수꾼 | 방어 특화 | 방어력을 높이고 방어막이 피해를 반사하도록 만든다 |
| 포격대 | 포대 운용 | 후방 포대를 설치하고 아군 사격에 맞춰 포격을 누적 발사한다 |
| 추적자 | 사냥 지휘 | 우선 목표를 지정하고 추적 표식을 따라 집중 공격을 유도한다 |

## 4. 정령계약

> 유물로 정령왕과의 계약을 완성하는 시너지. 정령왕은 전장 가운데에 소환되며 아주 천천히 이동하지만 기본 공격은 하지 않는다. 시너지 단계가 오를수록 정령왕의 전장 스킬이 해금된다.

|  단계 | 시너지 효과                                                                                                       |     |
| --: | ------------------------------------------------------------------------------------------------------------ | --- |
|   2 | `정령왕`을 소환하고 `원소폭발`을 해금한다. 정령왕이 5초마다 적이 가장 많이 몰린 지점에 폭발을 일으켜 80 속성 피해를 준다. 피해 속성은 현재 파티에서 가장 많이 사용한 속성으로 정한다. |     |
|   4 | `원소폭풍`을 해금한다. 적 밀집 지점에 6초 동안 회전하는 폭풍을 만들고, 범위 안의 적에게 0.5초마다 18 속성 피해                                         |     |
|   6 | `정령 폭격`을 해금한다. 8초마다 무작위 적 밀집 지점 3곳에 폭격을 떨어뜨려 각각 70 속성 피해를 준다.                                                |     |
|   8 | `차원붕괴`를 해금한다. 전투 중 1회, 정령왕이 전장 중앙에 균열을 열어 적들을 약하게 끌어당긴 뒤 240 속성 피해를 준다.                                      |     |

| 유물     | 고유 효과                                |
| ------ | ------------------------------------ |
| 원소 프리즘 | 모든 아군이 보유한 스킬 속성에 따라 가장 많은 속성의 피해 +12% |
| 불씨 왕관  | 화염 피해 +18%, 화염 노출 대상에게 추가 +10%       |
| 서리 렌즈  | 얼음 피해 +18%, 추위/빙결 대상에게 추가 +10%       |
| 폭풍 축전기 | 번개 피해 +18%, 감전 대상에게 추가 +10%          |
| 성광 잔   | 신성 피해 +18%, 방어막을 가진 아군은 추가 +8%       |
| 검은 촛대  | 어둠 피해 +18%, 표식/낙인 대상에게 추가 +8%        |
| 정령의 비약 | 모든 속성 피해 +10%, 정령계약 유물 1개당 +2%       |
| 균열 보석  | 적의 모든 속성 저항 -5                       |
| 원소 도감  | 아군의 서로 다른 대표 속성 1개당 모든 속성 피해 +4%      |
| 공명 나침반 | 아군이 속성 피해를 줄 때 8% 확률로 같은 속성의 30% 추가 피해 발생 |

## 5. 처형관

> 치명타 확률과 치명타 피해를 집중적으로 강화하는 시너지. 낮은 체력 대상과 중간보스/보스에게 더 높은 치명타 기대값을 만든다.

|  단계 | 시너지 효과                                                   |
| --: | -------------------------------------------------------- |
|   2 | 모든 아군 치명타 확률 +8%. 체력 35% 이하 적에게는 추가로 치명타 확률 +8%.         |
|   4 | 모든 아군 치명타 피해 +35%. 치명타가 발생하면 해당 공격의 최종 피해가 추가로 +8% 증가한다. |
|   6 | 체력 35% 이하 적에게 주는 치명타 피해 +60%.                            |
|   8 | 중간보스/보스에게 치명타 확률 +15%, 치명타 피해 +80%.                    |

| 유물     | 고유 효과                                  |
| ------ | -------------------------------------- |
| 유리 심장  | 모든 아군 치명타 피해 +5%, 보유 유물 중 별빛 숫돌이 있다면 치명타 피해 +20% |

| 붉은 조준경 | 투사체 스킬 치명타 확률 +12%                     |

## 6. 선택받은자

> 특정 타워를 이번 런의 중심 캐리로 세우는 시너지. 전투 시작 시 조건에 맞는 타워 1명을 선택받은자로 지정하고, 단계가 오를수록 스킬 반복, 최종 데미지 증가, 주기적 쿨타임 초기화, 보스 추가 피해를 제공한다.

|  단계 | 시너지 효과                                                                                                                        |
| --: | ----------------------------------------------------------------------------------------------------------------------------- |
|   2 | `앙코르`를 해금한다. 전투 시작 시 선택받은자 유물을 가장 많이 보유한 타워 1명을 선택받은자로 지정한다. 선택받은자가 액티브 스킬을 3회 사용할 때마다 마지막으로 사용한 액티브 스킬을 50% 위력으로 한 번 더 발동한다. (탄창 스킬의 경우 탄창을 모두 소비한다.) |
|   4 | 선택받은자의 최종 데미지가 +18% 증가한다.                                                                                                     |
|   6 | `하이라이트`를 해금한다. 15초마다 선택받은자의 현재 남은 쿨타임이 가장 긴 액티브 스킬 1개의 쿨타임을 초기화한다.                                                            |
|   8 | `피날레`를 해금한다. 선택받은자가 보스 몬스터에게 주는 최종 데미지가 +50% 증가한다.                                                                            |

## 9. 작성 기준
- 시너지명은 설명형 이름보다 짧은 고유명사형 이름을 우선한다.
- 유물 고유 효과는 시너지 효과와 같은 방향을 가지되, 완전히 같은 수치 보너스만 반복하지 않는다.
- 시너지 단계 효과는 단순 스탯 증가보다 소환물, 전장 오브젝트, 조건부 발동, 스킬 해금처럼 플레이 중 체감되는 기믹을 우선한다.
- 선택받은자 유물은 특정 캐릭터 전용 효과를 허용한다.
- 선택받은자 외 유물은 특정 캐릭터 1명만 강화하지 않고, 파티 조합 또는 전투 조건과 연결한다.
- 유물 효과는 캐릭터 스킬 문서에 이미 존재하는 속성, 상태, 방어막, 탄창, 행동속도, 쿨타임 충전 속도를 우선 사용한다.
