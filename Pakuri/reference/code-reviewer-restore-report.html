최종 상태: Builder -> Reviewer 외부 강제 흐름 smoke test PASS

요약

Code Reviewer 기능은 역할 자체가 사라진 것이 아니라, 외부 래퍼가 Reviewer 단계까지 도달하지 못해서 중단됐다. 실제 원인은 Codex CLI 실행 권한 문제, PowerShell 함수 반환값 오염, native stderr 처리 방식이었다.

복구 후 codex_builder_reviewer.ps1 래퍼 smoke test는 Reviewer PASS at loop 1.을 반환했고, 최종 Reviewer 로그 codex_loop_logs\reviewer_restore_fix_final_review.md도 REVIEW_RESULT: PASS를 반환했다.

확인된 핵심 파일

  • AGENTS.md: 역할 규칙과 Reviewer 검토 범위 정의
  • BLACKBOARD.md: 복구 이력, smoke test 로그, 최종 판정 기록
  • codex_builder_reviewer.ps1: Builder -> Reviewer 강제 실행 래퍼
  • run_codex.bat: Codex 시작 배치 파일
  • codex_loop_logs\20260425_213901\loop_01_reviewer.md: 최종 wrapper smoke test Reviewer PASS 로그
  • codex_loop_logs\reviewer_restore_fix_final_review.md: 복구 코드 자체에 대한 최종 Reviewer PASS 로그

최종 판정 근거

  • codex_builder_reviewer.ps1 parser check: PARSE_OK
  • 최종 래퍼 실행 출력: Reviewer PASS at loop 1.
  • 최종 Reviewer 판정: REVIEW_RESULT: PASS
  • Reviewer 확인 함수: Read-Utf8File, Write-Utf8File, Add-BlackboardHistory, Invoke-CodexExec, Get-FileSnapshot, Compare-FileSnapshots, Get-GitStatusText

원래 동작 원리

1. 작업 입력 codex_builder_reviewer.ps1 -Task "..."가 사용자 작업을 받아 codex_loop_logs\날짜_시간 디렉터리를 만든다.
2. Builder 실행 래퍼가 Code Builder 프롬프트를 만들고 codex exec로 실행한다. Builder는 실제 파일과 명령 출력 기반으로 작업한다.
3. 변경 수집 Builder 실행 전후 파일 스냅샷을 비교해 loop_01_changed_files.txt와 loop_01_git_status.txt를 만든다.
4. Reviewer 실행 래퍼가 Code Reviewer 프롬프트를 다시 codex exec로 실행한다. Reviewer는 변경 라인, 함수 존재, null 위험, 부작용을 검토한다.
5. 판정 처리 REVIEW_RESULT: PASS면 종료하고, NEEDS_CHANGES면 Reviewer 피드백을 Builder에게 넘겨 최대 3회 반복한다.

실패 원인

원인 1 sandbox 내부에서 직접 codex exec를 실행하면 액세스가 거부되었습니다. (os error 5)로 실패했다. 같은 Reviewer smoke test는 승인된 외부 실행에서 REVIEW_RESULT: PASS를 반환했다.
원인 2 Invoke-CodexExec가 Codex 콘솔 출력을 PowerShell 함수 반환값으로 흘려보냈다. 그 결과 $builderExit가 정수 0이 아니라 Builder 응답 텍스트와 0이 합쳐진 값이 되어, Builder 성공을 실패로 오판했다.
원인 3 Codex CLI가 stderr로 배너를 출력했고, 스크립트 전체의 $ErrorActionPreference = 'Stop' 설정 때문에 PowerShell이 이를 NativeCommandError로 처리했다.
부가 문제 Reviewer가 추가로 run_codex.bat의 프롬프트 따옴표 변형과 BLACKBOARD.md 기록 위치 문제를 지적했다. 두 항목은 후속 수정에서 반영됐다.

복구 내용

1단계

codex_builder_reviewer.ps1의 Invoke-CodexExec를 수정했다.

$consoleOutputPath = "$OutputPath.console.txt"
$exitCode = $null
$previousErrorActionPreference = $ErrorActionPreference
try {
    $ErrorActionPreference = 'Continue'
    $Prompt | & $ResolvedCodexCmd exec --full-auto --skip-git-repo-check -C $Root -o $OutputPath - *> $consoleOutputPath
    $exitCode = $global:LASTEXITCODE
} finally {
    $ErrorActionPreference = $previousErrorActionPreference
}
2단계

Codex 콘솔 출력은 *.console.txt로 저장하고, 함수 반환값은 종료 코드만 반환하도록 정리했다.

if ($null -eq $exitCode) {
    return 0
}
return [int]$exitCode
3단계

Add-BlackboardHistory가 루프 기록을 파일 끝이 아니라 ### Builder Reviewer Loop 앞에 넣도록 수정했다.

$content = Read-Utf8File -Path $BlackboardPath
$markers = @("`r`n### Builder Reviewer Loop", "`n### Builder Reviewer Loop")
4단계

run_codex.bat가 codex_prompt.txt의 ASCII 큰따옴표를 스마트 따옴표로 바꾸지 않도록 정리했다.

Reviewer 확인 기준: line 34 no longer applies quote replacement.

남은 주의점

승인 없는 sandbox 내부 직접 codex exec는 현재 환경에서 access denied가 재발할 수 있다.

따라서 Builder -> Reviewer 강제 흐름은 승인된 외부 실행으로 돌릴 때 검증됐다. 또한 현재 확인 시점의 BLACKBOARD.md에는 병합 충돌 표식이 실제로 남아 있었다. 이 보고서는 별도 HTML 산출물이므로 해당 충돌 표식 자체는 수정하지 않았다.
