# 아리엘 스킬 - 심판의 빛

> 아리엘의 기본 신성 투사체. 적에게 빛의 탄환을 날려 신성 피해를 준다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 심판의 빛 |
| 사용 주체 | 아리엘 타워 |
| 분류 | 액티브 A |
| 스킬 타입 | 탄창 / 투사체 / 기본 공격 |
| 피해 속성 | 신성 |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 기본 신성 피해 | 18 |
| 공격력 계수 | 0 |
| 주문력 계수 | 1.0 |
| 투사체 속도 | 17 |
| 관통 횟수 | 1 |
| 탄창 | 7 |
| 재장전 시간 | 4.6초 |
| 발사 간격 | 0.36초 |
| 치명타 적용 | 가능 |

## 3. 피해 계산

| 항목 | 값 |
|---|---|
| 계산식 | `18 + 주문력 * 1.0` |
| 참조 저항 | 신성 저항 |
| 치명타 적용 | 저항 계산 이후 |

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 위력 +25% |
| 특성 2 | 탄창 +3 |
| 특성 3 | 재장전 시간 -20% |
| 특성 4 | 관통 횟수 +1 |
| 특성 5 | 방어막을 가진 아군 1명당 위력 +6% |

## 5. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 백색 심판 | 마지막 탄환이 2회 폭발하며 범위 신성 피해를 준다 |
| 인도하는 빛 | 심판의 빛에 맞은 적에게 신성 노출 1스택 부여 |

## 6. 액티브 스킬 각성

각성 후보 2개는 각각 별도로 강화할 수 있다.

| 각성 후보 | 강화되는 항목 | 1단계 | 2단계 | 3단계 | 4단계 | 5단계 |
|---|---|---|---|---|---|---|
| 백색 심판 | 마지막 탄환 폭발 / 피해 | 마지막 탄환 1회 폭발, 45% 피해 | 1회, 60% 피해 | 2회, 각 45% 피해 | 2회, 각 60% 피해 | 2회, 각 80% 피해 |
| 인도하는 빛 | 신성 노출 부여 / 지속시간 | 신성 노출 1스택, 3초 | 1스택, 4초 | 2스택, 4초 | 2스택, 5초 | 3스택, 6초 |
