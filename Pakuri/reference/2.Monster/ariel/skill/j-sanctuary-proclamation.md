# 아리엘 패시브 - 성역 선포

> 대천사의 강림 대응 패시브. 강림 이후 파티가 다시 공세를 이어갈 수 있게 만든다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 패시브명 | 성역 선포 |
| 슬롯 | J |
| 대응 액티브 | 대천사의 강림 |
| 해금 조건 | 대천사의 강림 습득 |

## 2. 기본 효과

| 항목 | 값 |
|---|---:|
| 대천사의 강림 이후 모든 아군 행동속도 | +15%, 5초 |
| 대천사의 강림 방어막이 남아있는 아군의 신성 피해 | +20% |

## 3. 특성 3종

| 특성 | 효과 |
|---|---|
| 특성 1 | 행동속도 증가량 +7% |
| 특성 2 | 신성 피해 증가량 +10% |
| 특성 3 | 대천사의 강림 쿨타임 -15% |
