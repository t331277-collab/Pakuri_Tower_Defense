# 아리엘 패시브 - 수호 교리

> 성광 방패 대응 패시브. 모든 아군의 방어막 운용을 강화한다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 패시브명 | 수호 교리 |
| 슬롯 | G |
| 대응 액티브 | 성광 방패 |
| 해금 조건 | 성광 방패 습득 |

## 2. 기본 효과

| 항목 | 값 |
|---|---:|
| 모든 아군이 받는 방어막량 | +18% |
| 전투 시작 시 모든 아군 신성 방어막 | 25 + 주문력 * 0.8 |

## 3. 특성 3종

| 특성 | 효과 |
|---|---|
| 특성 1 | 방어막량 증가 +8% |
| 특성 2 | 전투 시작 방어막 +40% |
| 특성 3 | 방어막을 가진 아군의 신성 피해 +10% |
