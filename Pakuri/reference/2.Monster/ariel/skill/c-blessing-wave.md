# 아리엘 스킬 - 축복의 파동

> 아군 전체를 강화하고, 가장 가까운 적 무리에는 신성 파동 피해를 준다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 축복의 파동 |
| 사용 주체 | 아리엘 타워 |
| 분류 | 액티브 C |
| 스킬 타입 | 비탄창 / 파티 강화 / 범위 피해 |
| 피해 속성 | 신성 |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 기본 신성 피해 | 28 |
| 주문력 계수 | 1.2 |
| 파동 반경 | 3.0 |
| 모든 아군 행동속도 | +12% |
| 버프 지속시간 | 4.0초 |
| 쿨타임 | 8.0초 |
| 치명타 적용 | 가능 |

## 3. 피해 계산

| 항목 | 값 |
|---|---|
| 계산식 | `28 + 주문력 * 1.2` |
| 참조 저항 | 신성 저항 |
| 치명타 적용 | 저항 계산 이후 |

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 위력 +25% |
| 특성 2 | 행동속도 증가량 +6% |
| 특성 3 | 버프 지속시간 +2초 |
| 특성 4 | 파동 반경 +25% |
| 특성 5 | 방어막을 가진 아군은 추가로 신성 피해 +10% |

## 5. 마스터 스킬

| 선택지    | 효과                           |
| ------ | ---------------------------- |
| 찬란한 성가 | 행동속도 대신 모든 아군 주문력 +18% 추가    |
| 전장의 축도 | 파동이 2회 발생하며 두 번째 파동의 위력은 60% |


## 6. 액티브 스킬 각성

각성 후보 2개는 각각 별도로 강화할 수 있다.

| 각성 후보 | 강화되는 항목 | 1단계 | 2단계 | 3단계 | 4단계 | 5단계 |
|---|---|---|---|---|---|---|
| 찬란한 성가 | 주문력 보너스 / 행동속도 | 모든 아군 주문력 +8% | +12% | +16%, 행동속도 +4% | +20%, 행동속도 +6% | +24%, 행동속도 +8% |
| 전장의 축도 | 파동 횟수 / 두 번째 파동 피해 | 두 번째 파동 35% 피해 | 45% 피해 | 55% 피해 | 65% 피해 | 두 번째 파동 75% 피해, 반경 +20% |
