# 아리엘 스킬 - 성광 방패

> 모든 아군에게 짧은 시간 유지되는 신성 방어막을 부여한다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 성광 방패 |
| 사용 주체 | 아리엘 타워 |
| 분류 | 액티브 B |
| 스킬 타입 | 비탄창 / 파티 보호 / 방어막 |
| 피해 속성 | 없음 |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 기본 방어막 | 35 |
| 주문력 계수 | 1.4 |
| 지속시간 | 5.0초 |
| 쿨타임 | 9.0초 |
| 적용 대상 | 모든 아군 |

## 3. 방어막 계산

| 항목 | 값 |
|---|---|
| 계산식 | `35 + 주문력 * 1.4` |
| 중첩 방식 | 높은 값 우선 갱신 |
| 초과 피해 처리 | 방어막 제거 후 남은 피해 적용 |

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 방어막량 +30% |
| 특성 2 | 지속시간 +2초 |
| 특성 3 | 쿨타임 -20% |
| 특성 4 | 방어막이 사라질 때 주변 적에게 방어막량의 60% 신성 피해 |
| 특성 5 | 방어막을 받은 아군의 신성 피해 +12%, 5초 |

## 5. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 순백의 장벽 | 방어막량 +50%, 방어막이 유지되는 동안 상태이상 저항 +30% |
| 반사의 성광 | 방어막이 피해를 흡수할 때 공격자에게 흡수량의 35% 신성 피해 |
