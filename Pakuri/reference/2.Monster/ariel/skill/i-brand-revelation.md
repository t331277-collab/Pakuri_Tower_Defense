# 아리엘 패시브 - 낙인 계시

> 천상의 낙인 대응 패시브. 신성 노출 대상에게 파티의 공격을 집중시킨다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 패시브명 | 낙인 계시 |
| 슬롯 | I |
| 대응 액티브 | 천상의 낙인 |
| 해금 조건 | 천상의 낙인 습득 |

## 2. 기본 효과

| 항목 | 값 |
|---|---:|
| 신성 노출 대상이 모든 아군에게 받는 피해 | +10% |

## 3. 특성 3종

| 특성 | 효과 |
|---|---|
| 특성 1 | 받는 피해 증가량 +5% |
| 특성 2 | 천상의 낙인 쿨타임 -20% |
| 특성 3 | 신성 노출 대상의 신성 저항 -8 |
