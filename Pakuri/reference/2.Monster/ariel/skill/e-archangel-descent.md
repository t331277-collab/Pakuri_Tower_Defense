# 아리엘 스킬 - 대천사의 강림

> 전장에 신성한 빛을 내려 적에게 광역 피해를 주고 모든 아군에게 강한 방어막을 부여한다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 대천사의 강림 |
| 사용 주체 | 아리엘 타워 |
| 분류 | 액티브 E |
| 스킬 타입 | 비탄창 / 전장 광역 / 파티 보호 결전기 |
| 피해 속성 | 신성 |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 기본 신성 피해 | 58 |
| 주문력 계수 | 2.4 |
| 타격 범위 | 전장 전체 |
| 모든 아군 방어막 | 50 + 주문력 * 1.6 |
| 방어막 지속시간 | 6.0초 |
| 쿨타임 | 17.0초 |
| 치명타 적용 | 가능 |

## 3. 피해 계산

| 항목 | 값 |
|---|---|
| 계산식 | `58 + 주문력 * 2.4` |
| 참조 저항 | 신성 저항 |
| 치명타 적용 | 저항 계산 이후 |

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 위력 +30% |
| 특성 2 | 방어막량 +30% |
| 특성 3 | 쿨타임 -20% |
| 특성 4 | 신성 노출 대상에게 위력 +50% |
| 특성 5 | 모든 아군의 현재 방어막 지속시간 +3초 |

## 5. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 천상의 성역 | 강림 후 5초 동안 모든 아군이 받는 피해 -18% |
| 심판의 광휘 | 신성 피해 +70%, 방어막량 -30% |

## 6. 액티브 스킬 각성

각성 후보 2개는 각각 별도로 강화할 수 있다.

| 각성 후보 | 강화되는 항목 | 1단계 | 2단계 | 3단계 | 4단계 | 5단계 |
|---|---|---|---|---|---|---|
| 천상의 성역 | 받는 피해 감소 / 지속시간 | 받는 피해 -8%, 3초 | -10%, 4초 | -13%, 4초 | -16%, 5초 | -20%, 5초 |
| 심판의 광휘 | 신성 피해 / 방어막 보정 | 신성 피해 +30%, 방어막 -10% | +45%, -15% | +60%, -20% | +75%, -25% | +90%, -30% |
