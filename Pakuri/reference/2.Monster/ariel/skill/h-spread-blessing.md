# 아리엘 패시브 - 축복 전파

> 축복의 파동 대응 패시브. 축복 효과를 파티의 지속 화력으로 연결한다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 패시브명 | 축복 전파 |
| 슬롯 | H |
| 대응 액티브 | 축복의 파동 |
| 해금 조건 | 축복의 파동 습득 |

## 2. 기본 효과

| 항목 | 값 |
|---|---:|
| 축복을 받은 아군의 신성 피해 | +15% |
| 축복을 받은 아군의 쿨타임 충전 속도 | +10% |

## 3. 특성 3종

| 특성 | 효과 |
|---|---|
| 특성 1 | 신성 피해 증가량 +7% |
| 특성 2 | 쿨타임 충전 속도 +5% |
| 특성 3 | 축복의 파동 지속시간 +2초 |
