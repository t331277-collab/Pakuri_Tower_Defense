# 아리엘 스킬 - 천상의 낙인

> 가장 강한 적에게 신성 낙인을 새겨 파티의 집중 공격 대상으로 만든다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 천상의 낙인 |
| 사용 주체 | 아리엘 타워 |
| 분류 | 액티브 D |
| 스킬 타입 | 비탄창 / 단일 표식 / 신성 노출 |
| 피해 속성 | 신성 |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 기본 신성 피해 | 40 |
| 주문력 계수 | 1.8 |
| 대상 수 | 1 |
| 신성 노출 | +18% |
| 신성 노출 지속시간 | 6.0초 |
| 쿨타임 | 10.0초 |
| 치명타 적용 | 가능 |

## 3. 피해 계산

| 항목 | 값 |
|---|---|
| 계산식 | `40 + 주문력 * 1.8` |
| 참조 저항 | 신성 저항 |
| 치명타 적용 | 저항 계산 이후 |

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 위력 +30% |
| 특성 2 | 신성 노출 +8% |
| 특성 3 | 지속시간 +3초 |
| 특성 4 | 대상 수 +1, 위력 -20% |
| 특성 5 | 방어막을 가진 아군이 낙인 대상에게 주는 피해 +10% |

## 5. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 성흔 각인 | 낙인 대상이 받는 치명타 피해 +25% |
| 계시의 창 | 낙인이 끝날 때 누적 신성 피해의 20%만큼 추가 신성 피해 |
