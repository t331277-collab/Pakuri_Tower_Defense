# 아리엘 타워

![[ariel_tower.png]]
## 1. 설계 기준
- 아리엘은 파티 강화, 방어막, 신성 피해를 주축으로 하는 서포터 타워다.
- 외형과 설정은 신관/천족 계열에 맞춰, 공격보다 보호와 축복을 먼저 떠올리게 만든다.
- 주축은 모든 아군의 신성 피해와 생존력을 끌어올리는 파티 강화다.
- 보조축은 신성 투사체, 신성 장판, 광역 심판 피해다.
- 아리엘은 순수 폭딜러가 아니라, 아군이 오래 싸우면서 신성 피해를 누적하도록 돕는 후방 지원형으로 둔다.
