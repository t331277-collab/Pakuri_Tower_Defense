# Dungeon Squad 캐릭터 스킬 구조 패턴

> 목적: 신규 타워/캐릭터를 만들 때 Dungeon Squad 원작의 캐릭터별 스킬 구성, 역할 분배, 패시브 설계 비율을 참고하기 위한 내부 가이드다.

## 1. 사용 원칙
- 신규 캐릭터를 만들 때는 먼저 이 문서의 `원작 캐릭터 구조 요약`과 `신규 캐릭터 적용 기준`을 확인한다.
- 원작의 문장이나 스킬명을 그대로 복사하지 않고, 역할 분배와 효과 구조를 참고한다.
- 한 캐릭터는 보통 액티브 5개, 패시브 5개로 구성한다.
- 액티브는 `기본 투사체 / 보조 투사체 / 범위 또는 지속 피해 / 제어 또는 보호 / 광역 또는 결전기`처럼 역할을 나눈다.
- 패시브는 자기 스킬 강화만 두지 않고, 자동 발동, 아군 전체 강화, 상태 대상 보너스, 저항 감소, 전투 시작 효과를 섞는다.

## 2. 원작 공통 구조

| 구분 | 원작에서 자주 보이는 구조 |
|---|---|
| 액티브 1번 | 탄창형 기본 투사체. 탄창, 재장전, 발사 간격, 관통/도탄/추가 투사체가 붙는다. |
| 액티브 2~3번 | 보조 투사체, 설치물, 트랩, 오브, 연쇄 투사체, 보호막 등 캐릭터의 두 번째 축을 만든다. |
| 액티브 4번 | 지속 피해 영역, 보호막, 장판, 중거리 제어, 상태 누적 등 전투 리듬을 바꾼다. |
| 액티브 5번 | 광역, 전장 전체, 강한 제어, 회복, 결전기 성격이 많다. |
| 액티브 특성 | 위력, 탄창, 재장전/충전, 발사 속도, 범위, 상태 부여량, 구조 교환을 5개 정도 제공한다. |
| 마스터 스킬 | 속성 추가, 상태 추가, 폭발/흡혈/빙결/유혹/되돌아오기처럼 스킬의 성격을 바꾼다. |
| 패시브 | 대응 액티브를 강화하되, 아군 피해 트리거, 특정 상태 보너스, 전투 시작 효과, 저항 감소, 스택 공유가 섞인다. |

## 3. 액티브 역할 비율

| 역할 | 권장 비율 | 설명 |
|---|---:|---|
| 기본 탄창형 공격 | 1/5 | A 스킬. 캐릭터의 주 속성/상태/탄창 리듬을 결정한다. |
| 보조 공격 또는 설치 | 1~2/5 | 오브, 트랩, 연쇄 투사체, 추가 투사체, 지연 타격. |
| 범위/지속 피해 | 1/5 | 장판, 소용돌이, 지속 피해, 주기 피해. |
| 제어/보호/회복 | 0~1/5 | 빙결, 유혹, 기절, 보호막, 회복. 캐릭터 성격에 따라 생략 가능. |
| 광역/결전기 | 1/5 | 전장 전체, 넓은 범위, 강한 상태 부여, 고쿨타임 비탄창. |

신규 캐릭터를 만들 때 액티브 5개가 전부 단일 피해 또는 전부 광역 피해가 되지 않게 한다.

## 4. 패시브 효과 비율

| 패시브 유형 | 권장 비율 | 설명 |
|---|---:|---|
| 자기/대응 스킬 강화 | 1~2/5 | 특정 액티브의 위력, 범위, 지속시간, 탄창, 쿨타임을 강화한다. |
| 아군 전체 강화 | 1~2/5 | 모든 아군의 속성 피해, 행동속도, 공격력, 주문력, 스킬 가속 등을 강화한다. |
| 아군 피해 트리거 | 1/5 | 아군이 특정 속성/피해 타입으로 공격하면 대응 스킬이 확률 발동한다. |
| 상태 대상 보너스/저항 감소 | 1/5 | 특정 상태 대상 피해 증가, 특정 저항 감소, 스택 비례 강화. |
| 전투 시작/방어/처치 보상 | 0~1/5 | 전투 시작 보호막, 피해 차단 보상, 처치 시 스택/쿨타임 회복. |

패시브 기본 효과는 보통 1개, 필요하면 2개까지 작성한다.
트리거형 효과는 원칙적으로 패시브에만 두고, 캐릭터마다 많아야 1개만 쓴다.

## 5. 원작 몬스터별 구조 요약

> 메인 몬스터 로스터 기준 분석이다. Corrupted Hero/Acolyte 계열은 별도 확장 로스터로 보고, 여기서는 원작 패턴 참고용으로만 사용한다.

| 몬스터 | 캐릭터 편향 | 액티브 역할 분배 | 패시브 성향 | 신규 설계 참고 |
|---|---|---|---|---|
| Cerberus | 탄창 화력 / 화염+물리 공격 특화 | 폭격형 탄창 공격, 충격파 제어, 화염/냉기 가시, 광역 제압 | 자기 화력과 탄창 운용 비중이 높고, 상태 제어는 보조축 | 순수 공격형 캐릭터는 기본 공격과 보조 공격을 모두 탄창형으로 두고, 제어는 1개만 넣어도 원작 느낌이 난다. |
| Kraken | 상태 누적 / 촉수 장판 / 광역 제어 특화 | 냉기 탄창, 오브 지속 피해, 촉수 타격, 촉수 장판, 전장 쓰나미 | Wet/Freeze/Stun 대상 보너스, 물리/냉기 트리거, 모든 아군 냉기 피해 | 상태 누적형은 `상태 부여 A + 지속 피해 영역 + 전장 광역 E` 구조가 잘 맞는다. |
| Titan | 번개 연쇄 / 속성 엔진 특화 | 번개 탄창, 번개 파동, 구슬/코드, 보호막성 스킬 | 번개 스킬 수 비례 강화, 번개 피해 트리거, 전투 시작 보호막, 번개 저항 감소 | 속성 통일형은 `속성 스킬 수 비례 강화 + 아군 속성 피해 트리거`를 핵심 패시브로 둔다. |
| Medusa | 물리/산성/석화 제어 특화 | 촉수 화살, 촉수 파동, 독/산성 안개, 석화 눈, 석화 저주 | 석화/쾌락/산성 상태 보너스, 물리+신성 추가 피해, 대상 고정/집중 공격 | 제어형 캐릭터는 E에 강한 행동 제한을 두고, 패시브는 제어 대상에게 아군 피해를 붙이면 좋다. |
| Stheno | 어둠 지속 피해 / 처형 명령 특화 | 어둠 DOT, 부패/속삭임, 죽음 명령, 광역 지속 피해 | 어둠 피해 가속, 처치 시 다음 명령 강화, 죽음/부패 누적 | 지속 피해 딜러는 DOT 스킬 2~3개와 처치 보상 1개를 섞는다. |
| Chimera | 다속성 혼합 / 속성 변환 특화 | 신성 검, 번개 검, 화염/어둠/산성 계열 공격이 분산 | 속성별 저항 감소, 물리 피해에 속성 추가, 여러 속성 피해 증폭 | 다속성 캐릭터는 스킬마다 속성이 달라도 되며, 패시브는 `속성 추가 피해`와 `저항 감소`로 묶는다. |
| HellHound | 화염 공세 / 아군 속도 보조 특화 | 화염 탄환, 돌진형 화염 피해, 세례/낙인, 하울링, 무리 사냥 | 화염 피해 트리거, 모든 아군 행동속도/스킬 가속, 물리 피해에 화염 추가 | 공격 지원형은 자기 화염 딜과 아군 행동속도 버프를 같이 갖는다. |
| Dark Pegasus | 투사체/트랩/보호막 특화 | 빠른 깃털 투사체, 깃털 보호막, 깃털 트랩, 관통 투사체, 지속 범위 피해 | 아군 스킬 발동 기반 누적, 자동 트랩 설치, 전투 시작 보호막, 스킬 가속 공유 | 투사체 특화 캐릭터는 `빠른 A + 설치 B/C + 보호 D + 지속 E`로 구성하면 원작감이 강하다. |
| Diablo | 어둠/화염 장판 / 공포 제어 특화 | 화염 지속 피해, 공포 영역, 어둠 보석, 종말 광역, 영혼 보호막 | 어둠 피해 전체 강화, 공포 확산, 저항/보호막 보조 | 제어+광역형은 장판과 공포/후퇴 제어를 중심에 두고, 패시브는 아군 어둠 피해를 크게 올린다. |
| Jormungand | 산성/물리 생존 / 재생 공유 특화 | 산성 포자, 산성 장판, 사냥/포식, 산성 비늘 보호, 그림자 뱀 | 산성/물리 피해 트리거, 재생 공유, 저항 감소, 처치/사망 스택 | 생존형 딜러는 피해 트리거와 보호막/재생 패시브를 같이 둔다. |
| Baphomet | 저주 스택 / 실현 폭발 / 전체 약화 특화 | 저주 탄환, 영혼 방출, 영혼 폭풍, 오망성 저주, 광역 실현 | 저주 실현, 모든 저항 감소, 전체 스탯 증가, 영혼/저주 스택 공유 | 저주형은 `스택 축적 + 일정 시간 후 실현 + 저항 감소 + 처치 보상`이 핵심이다. |
| Beholder | 시선/노출/약점 저격 특화 | 시선 투사체, 관통 시선, 약점 노출, 상태 기반 피해 | 노출/쾌락 기반 치명타 보너스, 물리 저항 감소, 집중 대상 약화 | 저격형은 단일 대상 디버프를 깊게 쌓고 아군 치명타/피해 보너스로 연결한다. |
| Gumiho | 신성/번개 혼합 / 회복·쾌락 보조 특화 | 부적 투사체, 영혼 구슬, 여우불, 묶기/꼬리 계열 상태 보조 | 신성 피해 아군 강화, 신성 피해 트리거, 신성↔번개 추가 피해, 회복/쾌락 보조 | 혼합 보조형은 두 속성 간 추가 피해와 아군 트리거를 연결한다. |

## 6. 캐릭터 편향 분류

| 편향 | 원작 예시 | 액티브 구성 | 패시브 구성 |
|---|---|---|---|
| 순수 공격형 | Cerberus, Titan | 탄창형/연쇄형/광역형 공격이 많고 제어가 적다. | 자기 화력, 속성 피해, 탄창/재장전, 저항 감소 중심. |
| 상태 누적형 | Kraken, Medusa, Baphomet | 상태를 부여하는 공격이 여러 개 있고 E가 상태를 크게 활용한다. | 상태 대상 피해 증가, 상태 스택 비례, 상태 트리거 중심. |
| 설치/트랩형 | Dark Pegasus | 투사체와 설치물이 섞이고, 지속 피해 영역을 가진다. | 아군 스킬 발동 시 자동 설치, 누적 카운터, 보호막. |
| 장판/제어형 | Diablo, Stheno | 지속 피해 영역, 공포/제어, DOT가 많다. | 지속 피해 가속, 공포/어둠 피해 강화, 저항 감소. |
| 생존 보조형 | Jormungand, HellHound 일부 | 보호막, 회복, 재생, 아군 속도 보조가 섞인다. | 회복/재생 공유, 행동속도, 스킬 가속, 피해 트리거. |
| 다속성 혼합형 | Chimera, Gumiho | 스킬마다 속성이 다르거나 두 속성이 강하게 연결된다. | 속성 추가 피해, 속성 저항 감소, 속성 보유 수 비례 강화. |

## 7. 원작식 액티브 세트 템플릿

| 슬롯 | 기본 역할 | 예시 구조 |
|---|---|---|
| A | 기본 탄창형 공격 | 주 속성 피해, 탄창, 재장전, 발사 간격, 관통/도탄/추가 투사체 |
| B | 보조 탄창/설치/오브 | 낮은 탄창, 높은 계수, 지속 피해, 자동 발동 패시브와 연결 |
| C | 상태/제어/보조 공격 | 상태 부여, 지연 타격, 트랩, 광역 보조 |
| D | 비탄창 지속/보호/영역 | 쿨타임 기반, 장판/보호막/범위 지속 피해 |
| E | 광역/결전기 | 전장 범위, 강한 상태 부여, 회복, 처형, 큰 쿨타임 |

## 8. 원작식 패시브 세트 템플릿

| 슬롯 | 대응 | 기본 방향 |
|---|---|---|
| F | A | 기본 공격의 속성/상태를 아군 전체 시너지로 확장한다. |
| G | B | B 스킬이 만든 상태/설치/오브를 강화하거나 아군 피해 트리거를 붙인다. |
| H | C | 특정 피해 타입을 줄 때 C 스킬 자동 발동, 또는 상태 대상 보너스. |
| I | D | 지속 영역/보호/장판의 범위, 가속, 저항 감소, 아군 방어 보조. |
| J | E | 결전기 발동 후 아군 가속/회복/쿨타임 충전, 또는 처치 보상. |

## 9. 신규 캐릭터 작성 체크리스트
- A 스킬이 캐릭터의 주 속성, 피해 타입, 핵심 상태를 보여주는가?
- B~D 중 최소 1개는 지속 피해, 설치, 보호, 제어, 장판 중 하나인가?
- E 스킬은 다른 액티브보다 명확하게 광역/결전/처형/회복 역할을 갖는가?
- 패시브 5개 중 자기 스킬 강화만 하는 패시브가 2개를 넘지 않는가?
- 패시브 5개 중 최소 2개는 아군 전체 강화 또는 아군 피해 트리거인가?
- 패시브 5개 중 최소 1개는 상태 대상 보너스 또는 저항 감소인가?
- 마스터 스킬은 단순 수치 증가가 아니라 속성 추가, 상태 추가, 작동 방식 변경 중 하나를 제공하는가?

## 10. 신규 캐릭터 설계 시 선택할 축

새 캐릭터는 아래 축 중 1개를 주축, 1개를 보조축으로 고른다. 모든 축을 한 캐릭터에 넣지 않는다.

| 주축 | 보조축 후보 |
|---|---|
| 순수 공격형 | 저항 감소, 탄창 강화, 처치 보상 |
| 상태 누적형 | 상태 대상 피해, 자동 발동, 광역 실현 |
| 설치/트랩형 | 보호막, 아군 스킬 트리거, 지속 피해 |
| 장판/제어형 | 저항 감소, 행동속도 감소, DOT 가속 |
| 생존 보조형 | 회복/재생, 보호막, 아군 행동속도 |
| 다속성 혼합형 | 속성 추가 피해, 속성 보유 수 비례 강화, 저항 감소 |

## 11. 참고한 원작 패턴
- Release Notes: Cerberus, Kraken, Titan, Medusa, Stheno, Chimera, HellHound, Dark Pegasus, Diablo, Jormungand의 스킬/특성/마스터 조정 내역.
- Mechanics: 몬스터는 보통 1~2개 피해 타입에 특화되고, Chimera는 예외적으로 액티브마다 피해 타입이 다르게 분산된다는 구조.
- Status Effect: 각 몬스터가 어떤 상태를 액티브/패시브로 사용하는지 확인.
- Element pages: 속성별 기본 피해 스킬, 마스터 피해 스킬, 피해 증가, 저항 감소, 자동 발동 패턴 확인.
