# 이브 스킬 - 플라즈마 필드

> 지정 범위에 검은 드론들을 전개하고, 드론들이 지속시간 동안 플라즈마 필드를 유지해 주기적으로 번개 공격을 하는 장판형 설치 스킬.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 플라즈마 필드 |
| 사용 주체 | 이브 타워 |
| 분류 | 액티브 |
| 스킬 타입 | 범위 / 비탄약 / 지속시간 / 피해 주기 |
| 피해 속성 | 번개 |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 기본 번개 피해 | 14 |
| 주문력 계수 | 0.9 |
| 공격력 계수 | 0 |
| 범위 | 3.2 |
| 필드 지속시간 | 5.0초 |
| 피해 주기 | 0.8초 |
| 쿨다운 | 10.0초 |
| 취약 부여량 | 1스택 |
| 취약 최대 스택 | 10 |
| 취약 지속시간 | 영구 지속 |
| 치명타 적용 | 가능 |

## 3. 피해 계산

| 항목 | 값 |
|---|---:|
| 1회 계산식 | `14 + 주문력 * 0.9` |
| 참조 저항 | 번개 저항 |
| 피해 적용 | 플라즈마 필드가 주기마다 범위 안 모든 적에게 적용 |
| 치명타 적용 순서 | 저항 계산 이후 |

취약 상태는 [`buff-debuff.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F3.combat%2Fbuff-debuff) 참고

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 범위 +25%, 지속시간 +20% |
| 특성 2 | 피해 주기 속도 +25%, 취약 부여량 +1 |
| 특성 3 | 위력 +30%, 쿨다운 -15% |
| 특성 4 | 범위 -20%, 위력 +80% |
| 특성 5 | 취약 5스택 이상 대상 번개 피해 +40% |

## 5. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 플라즈마 붕괴 | 플라즈마 필드 종료 후 0.5초 뒤, 종료된 위치에 원본 필드 최종 반경의 60% 크기로 3.0초 동안 플라즈마 필드를 1회 재시전 |
| 약점 고정 | 취약 최대 스택 +5, 취약 스택당 받는 치명타 피해 +1% 추가 |

`플라즈마 붕괴`로 재시전된 필드는 원본 필드가 종료될 때 확정된 피해, 피해 주기,
치명타, 취약 부여량을 이어받는다. 재시전 지속시간은 3.0초로 고정하며,
재시전 필드가 종료되어도 `플라즈마 붕괴`를 다시 발생시키지 않는다.

## 6. 액티브 스킬 각성

각성 후보 2개는 각각 별도로 강화할 수 있다.

| 각성 후보 | 강화되는 항목 | 1단계 | 2단계 | 3단계 | 4단계 | 5단계 |
|---|---|---|---|---|---|---|
| 플라즈마 붕괴 | 재시전 지연 / 지속시간 / 반경 | 0.5초 후, 3.0초, 반경 65% | 0.5초 후, 3.5초, 반경 70% | 0.4초 후, 4.0초, 반경 75% | 0.3초 후, 4.5초, 반경 85% | 0.2초 후, 5.0초, 반경 100% |
| 약점 고정 | 취약 최대 스택 / 치명타 피해 | 취약 최대 +2 | +3 | +4, 스택당 치명타 피해 +0.5% | +5, +0.7% | +6, +1.0% |
