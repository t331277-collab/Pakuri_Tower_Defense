# 이브 스킬 - 플라즈마 필드

> 지정 범위에 검은 드론들을 전개하고, 드론들이 지속시간 동안 플라즈마 필드를 유지해 주기적으로 번개 공격을 하는 장판형 설치 스킬.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 플라즈마 필드 |
| 사용 주체 | 이브 타워 |
| 분류 | 액티브 |
| 스킬 타입 | 탄창 / 드론 / 표식 / 디버프 |
| 피해 속성 | 번개 |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 기본 번개 피해 | 14 |
| 주문력 계수 | 0.9 |
| 공격력 계수 | 0 |
| 드론 지속시간 | 5.0초 |
| 공격 주기 | 0.8초 |
| 탄창 수 | 3 |
| 재장전 시간 | 6.0초 |
| 취약 부여량 | 1스택 |
| 취약 최대 스택 | 10 |
| 취약 지속시간 | 영구 지속 |
| 치명타 적용 | 가능 |

## 3. 피해 계산

| 항목 | 값 |
|---|---:|
| 1회 계산식 | `14 + 주문력 * 0.9` |
| 참조 저항 | 번개 저항 |
| 피해 적용 | 플라즈마 필드가 주기마다 범위 안 적 1명에게 적용 |
| 치명타 적용 순서 | 저항 계산 이후 |

취약 상태는 [`buff-debuff.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F3.combat%2Fbuff-debuff) 참고

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 탄창 수 +1, 드론 지속시간 +20% |
| 특성 2 | 공격 주기 속도 +25%, 취약 부여량 +1 |
| 특성 3 | 위력 +30% |
| 특성 4 | 재장전 속도 +30%, 플라즈마 필드 동시 전개 수 +1 |
| 특성 5 | 취약 5스택 이상 대상 번개 피해 +40% |

## 5. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 감시 드론망 | 플라즈마 필드 동시 전개 수 +2, 공격 주기 속도 +30% |
| 약점 고정 | 취약 최대 스택 +5, 취약 스택당 받는 치명타 피해 +1% 추가 |

## 6. 액티브 스킬 각성

각성 후보 2개는 각각 별도로 강화할 수 있다.

| 각성 후보 | 강화되는 항목 | 1단계 | 2단계 | 3단계 | 4단계 | 5단계 |
|---|---|---|---|---|---|---|
| 감시 드론망 | 동시 전개 수 / 공격 주기 | 동시 전개 +1 | +1, 공격 주기 속도 +10% | +1, +20% | 동시 전개 +2, +20% | +2, +35% |
| 약점 고정 | 취약 최대 스택 / 치명타 피해 | 취약 최대 +2 | +3 | +4, 스택당 치명타 피해 +0.5% | +5, +0.7% | +6, +1.0% |
