# 이브 스킬 - 드론 비컨

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 드론 비컨 |
| 사용 주체 | 이브 타워 |
| 분류 | 액티브 |
| 스킬 타입 | 탄창 / 드론 / 표식 / 디버프 |
| 피해 속성 | 얼음 |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 기본 얼음 피해 | 14 |
| 주문력 계수 | 0.9 |
| 공격력 계수 | 0 |
| 사거리 | 9.0 |
| 비컨 지속시간 | 5.0초 |
| 공격 주기 | 0.8초 |
| 탄창 수 | 3 |
| 재장전 시간 | 6.0초 |
| 취약 부여량 | 1스택 |
| 취약 최대 스택 | 10 |
| 취약 지속시간 | 영구 지속 |

## 3. 피해 계산

| 항목 | 값 |
|---|---:|
| 1회 계산식 | `14 + 주문력 * 0.9` |
| 참조 저항 | 얼음 저항 |
| 피해 적용 | 비컨이 주기마다 범위 안 적 1명에게 적용 |

취약 상태는 [`buff-debuff.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F3.combat%2Fbuff-debuff) 참고

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 탄창 수 +1, 비컨 지속시간 +20% |
| 특성 2 | 공격 주기 속도 +25%, 취약 부여량 +1 |
| 특성 3 | 위력 +30%, 사거리 +20% |
| 특성 4 | 재장전 속도 +30%, 비컨 동시 설치 수 +1 |
| 특성 5 | 취약 5스택 이상 대상 얼음 피해 +40% |

## 5. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 감시 드론망 | 비컨 동시 설치 수 +2, 공격 주기 속도 +30% |
| 약점 고정 | 취약 최대 스택 +5, 취약 스택당 받는 치명타 피해 +1% 추가 |
