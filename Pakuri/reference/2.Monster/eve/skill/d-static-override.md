# 이브 스킬 - 스태틱 오버라이드

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 스태틱 오버라이드 |
| 사용 주체 | 이브 타워 |
| 분류 | 액티브 |
| 스킬 타입 | 전체 필드 탐색 / 대상별 범위 폭발 / 비탄창 / 감전 연계 |
| 피해 속성 | 번개 |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 기본 번개 피해 | 10 |
| 주문력 계수 | 0.7 |
| 공격력 계수 | 0 |
| 폭발 반경 | 1.8 |
| 쿨다운 | 7.0초 |
| 스택당 피해 증가 | 35% |
| 최소 발동 스택 | 1 |
| 발동 대상 | 맵 전체의 감전 상태 적 전부 |
| 감전 스택 처리 | 폭발 후 유지 |
| 중첩 피해 | 가능 |
| 치명타 적용 | 가능 |

스킬 발동 시 맵 전체를 한 번 스캔한다. 감전이 1스택 이상인 적이 있으면
해당 적 각각의 위치에서 폭발을 1회씩 발생시킨다. 감전 대상이 없으면 폭발하지 않는다.

각 폭발은 서로 독립된 판정이다. 여러 감전 대상이 가까이 있어 폭발 반경이 겹치면,
겹친 위치의 적은 각 폭발의 피해를 모두 받을 수 있다.

## 3. 피해 계산

| 항목 | 값 |
|---|---:|
| 기본 계산식 | `10 + 주문력 * 0.7` |
| 최종 계산식 | `기본 계산식 * (1 + 감전 스택 * 0.35)` |
| 참조 저항 | 번개 저항 |
| 피해 기준 | 폭발마다 개별 계산 |
| 치명타 적용 순서 | 저항 계산 이후 |

감전 상태는 [`buff-debuff.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F3.combat%2Fbuff-debuff) 참고

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 폭발 반경 +15% |
| 특성 2 | 스택당 피해 증가 +15% |
| 특성 3 | 쿨다운 -20%, 위력 +15% |
| 특성 4 | 폭발 후 감전 1스택 추가 부여 |
| 특성 5 | 감전 3스택 이상 대상 폭발 위력 +50% |

## 5. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 연쇄 과부하 | 폭발에 맞은 적이 감전 상태면 추가 폭발 1회 발생, 추가 폭발 피해 50% |
| 전자기 붕괴 | 폭발 반경 +40%, 감전 스택당 피해 증가 +25%, 쿨다운 +20% |

## 6. 액티브 스킬 각성

각성 후보 2개는 각각 별도로 강화할 수 있다.

| 각성 후보 | 강화되는 항목 | 1단계 | 2단계 | 3단계 | 4단계 | 5단계 |
|---|---|---|---|---|---|---|
| 연쇄 과부하 | 추가 폭발 횟수 / 피해 | 추가 폭발 1회, 35% 피해 | 1회, 45% 피해 | 1회, 60% 피해 | 2회, 각 45% 피해 | 2회, 각 60% 피해 |
| 전자기 붕괴 | 폭발 반경 / 스택 피해 | 반경 +15%, 스택당 피해 +8%p | 반경 +25%, +10%p | 반경 +35%, +13%p | 반경 +45%, +17%p | 반경 +60%, +22%p |
