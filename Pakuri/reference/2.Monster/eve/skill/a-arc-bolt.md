# 이브 스킬 - 아크 볼트

|---|---:|
| 스킬명 | 아크 볼트 |
| 사용 주체 | 이브 타워 |
| 분류 | 액티브 |
| 스킬 타입 | 투사체 / 탄창형 |

## 4. 용어 설명

| 용어 | 설명 |
|---|---|
| 갈래 | 아크 볼트가 적에게 적중한 뒤, 양쪽으로 퍼지는 보조 번개 |
| 갈래 수 | 갈래가 발생하면 항상 2갈래로 퍼진다. |
| 갈래 피해 | 갈래가 한 번 퍼질 때마다 이전 타격 피해의 70%로 감소한다. 예: 100 > 70 > 49 |
| 갈래 확률 | 아크 볼트나 갈래가 적중했을 때 다시 2갈래로 퍼질 확률 |
| 갈래 방향 | 적중 대상 기준 가까운 적 2명 방향을 우선 사용한다. 갈래를 보낼 적이 부족하면 남은 갈래는 오른쪽 방향을 기준으로 적당히 랜덤하게 뻗는다. |

갈래는 아크 볼트의 탄창을 추가로 소모하지 않는 추가 타격이다. 갈래로 발생한 피해도 번개 피해로 계산하며, 감전 부여 여부는 아크 볼트의 기본 감전 규칙을 따른다. 갈래로 발생한 타격도 적중 시 갈래 확률을 다시 판정해 추가 갈래를 만들 수 있다.

## 5. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 탄창 수 +4, 위력 +20% |
| 특성 2 | 재장전 속도 +30%, 관통 수 +1 |
| 특성 3 | 추가 투사체 수 +1, 재장전 시간 +20% |
| 특성 4 | 추가 투사체 수 +2, 발사 속도 -25% |
| 특성 5 | 위력 +25%, 번개 갈래 확률 +35% |
