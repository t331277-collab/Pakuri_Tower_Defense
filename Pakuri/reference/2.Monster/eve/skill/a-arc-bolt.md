# 이브 스킬 - 아크 볼트

> 이브 타워의 기본 액티브 스킬.

## 1. 기본 정보

| 항목 | 값 |
|---|---:|
| 스킬명 | 아크 볼트 |
| 사용 주체 | 이브 타워 |
| 분류 | 액티브 |
| 스킬 타입 | 투사체 / 탄창형 |
| 피해 속성 | 번개 |
| 보조 연계 속성 | 얼음 |

## 2. 기본 수치

| 항목       |     값 |
| -------- | ----: |
| 기본 번개 피해 |    24 |
| 주문력 계수   |  0.95 |
| 투사체 속도   |  15.0 |
| 관통 수     |     0 |
| 추가 투사체 수 |     0 |
| 탄창 수     |     6 |
| 재장전 시간   |  4.0초 |
| 발사 간격    | 0.35초 |
| 치명타 적용   |    가능 |
| 감전 확률    |   15% |
| 감전 부여량   |   1스택 |

## 3. 피해 계산

| 항목 | 값 |
|---|---:|
| 계산식 | `24 + 주문력 * 0.95` |
| 참조 저항 | 번개 저항 |
| 치명타 적용 순서 | 저항 계산 이후 |

속성 계산은 [`combat-attribute-and-damage-system.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F3.combat%2Fcombat-attribute-and-damage-system) 참고  
감전 상태는 [`buff-debuff.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F3.combat%2Fbuff-debuff) 참고

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 탄창 수 +4, 위력 +20% |
| 특성 2 | 재장전 속도 +30%, 관통 수 +1 |
| 특성 3 | 추가 투사체 수 +1, 재장전 시간 +20% |
| 특성 4 | 추가 투사체 수 +2, 발사 속도 -25% |
| 특성 5 | 위력 +25%, 번개 분기 확률 +35% |

## 5. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 분기 회로 | 적중 시 갈래 번개 2개 생성, 갈래 피해 60%, 추적 반경 4.5, 위력 +35%, 탄창 수 +2 |
| 과충전 일제사격 | 관통 수 +2, 추가 투사체 수 +2, 발사 속도 -20%, 위력 +45%, 적중 시 감전 2스택 |

## 6. 액티브 스킬 각성

각성 후보 2개는 각각 별도로 강화할 수 있다.

| 각성 후보 | 강화되는 항목 | 1단계 | 2단계 | 3단계 | 4단계 | 5단계 |
|---|---|---|---|---|---|---|
| 분기 회로 | 갈래 번개 수 / 갈래 피해 | 갈래 1개, 35% 피해 | 갈래 1개, 45% 피해 | 갈래 2개, 45% 피해 | 갈래 2개, 60% 피해 | 갈래 3개, 60% 피해 |
| 과충전 탄두 | 추가 투사체 / 감전 부여 | 추가 투사체 +1, 피해 40% | 추가 투사체 +1, 감전 +1스택 | 추가 투사체 +2, 피해 45% | 추가 투사체 +2, 감전 +1스택 | 추가 투사체 +2, 피해 70%, 감전 +2스택 |
