# 이브 스킬 - 프로스트 필드

> 지정 범위에 하얀 드론을 전개하고, 드론들이 냉기 필드를 유지해 범위 안 적에게 주기적으로 얼음 피해를 주는 장판 스킬.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 프로스트 필드 |
| 사용 주체 | 이브 타워 |
| 분류 | 액티브 |
| 스킬 타입 | 범위 / 비탄약 / 지속시간 / 피해 주기 |
| 피해 속성 | 얼음 |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 기본 얼음 피해 | 8 |
| 주문력 계수 | 0.8 |
| 공격력 계수 | 0 |
| 범위 | 3.2 |
| 지속시간 | 4.0초 |
| 피해 주기 | 0.5초 |
| 쿨다운 | 8.0초 |
| 추위 부여량 | 1스택 |
| 치명타 적용 | 가능 |

## 3. 피해 계산

| 항목 | 값 |
|---|---:|
| 1틱 계산식 | `8 + 주문력 * 0.8` |
| 참조 저항 | 얼음 저항 |
| 피해 적용 | 범위 안 적에게 피해 주기마다 적용 |
| 치명타 적용 순서 | 저항 계산 이후 |

추위 / 빙결 상태는 [`buff-debuff.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F3.combat%2Fbuff-debuff) 참고

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 범위 +25%, 지속시간 +15% |
| 특성 2 | 피해 주기 속도 +25%, 추위 부여량 +1 |
| 특성 3 | 위력 +30%, 쿨다운 -15% |
| 특성 4 | 범위 -20%, 위력 +80% |
| 특성 5 | 빙결 지속시간 +1.0초, 얼음 피해 +20% |

## 5. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 절대영도 구역 | 추위 4스택 이상 적을 즉시 빙결, 빙결 지속시간 +1.5초 |
| 결정 폭풍 | 필드 종료 시 범위 안 적에게 `24 + 주문력 * 1.5` 얼음 피해 |

## 6. 액티브 스킬 각성

각성 후보 2개는 각각 별도로 강화할 수 있다.

| 각성 후보 | 강화되는 항목 | 1단계 | 2단계 | 3단계 | 4단계 | 5단계 |
|---|---|---|---|---|---|---|
| 절대영도 구역 | 빙결 조건 / 빙결 시간 | 추위 5스택 이상 빙결 0.8초 | 5스택 이상 1.0초 | 4스택 이상 1.0초 | 4스택 이상 1.3초 | 3스택 이상 1.5초 |
| 결정 폭풍 | 종료 폭발 피해 / 범위 | 종료 시 35% 피해 폭발 | 45% 피해 | 55% 피해, 범위 +10% | 65% 피해, 범위 +20% | 80% 피해, 범위 +30% |
