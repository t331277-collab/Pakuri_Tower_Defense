# 이브 패시브 - 냉각 알고리즘

> 프로스트 필드 대응 패시브. 추위와 빙결 대상을 아군 전체가 더 쉽게 제압하게 한다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 패시브명 | 냉각 알고리즘 |
| 슬롯 | H |
| 대응 액티브 | 프로스트 필드 |
| 해금 조건 | 프로스트 필드 습득 |

## 2. 기본 효과

| 항목 | 값 |
|---|---:|
| 모든 아군이 추위/빙결 대상에게 주는 피해 | +14% |
| 모든 아군이 추위/빙결 대상에게 상태이상을 부여할 확률 | +10% |

프로스트 필드는 [`c-frost-field.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F2.Monster%2Feve%2Fskill%2Fc-frost-field) 참고
