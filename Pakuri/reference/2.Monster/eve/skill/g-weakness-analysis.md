# 이브 패시브 - 입자 분리

> 프리즘 레이 대응 패시브. 아군의 번개/얼음 피해를 프리즘 레이 자동 발동으로 연결한다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 패시브명 | 입자 분리 |
| 슬롯 | G |
| 대응 액티브 | 프리즘 레이 |
| 해금 조건 | 프리즘 레이 습득 |

## 2. 기본 효과

| 항목 | 값 |
|---|---:|
| 아군이 번개/얼음 피해를 줄 때 프리즘 레이 자동 발동 확률 | 4%, 재발동 대기시간 1.5초 |
| 모든 아군의 번개/얼음 피해 | +8% |

프리즘 레이는 [`b-prism-ray.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F2.Monster%2Feve%2Fskill%2Fb-prism-ray) 참고

## 3. 특성 3종

| 특성 | 효과 |
|---|---|
| 특성 1 | 프리즘 레이 자동 발동 확률 +3% |
| 특성 2 | 모든 아군의 번개/얼음 피해 +5% |
| 특성 3 | 프리즘 레이가 보호막 대상에게 300% 추가 피해 |
