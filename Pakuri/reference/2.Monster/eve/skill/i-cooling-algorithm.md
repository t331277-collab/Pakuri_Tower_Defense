# 이브 패시브 - 과전류 회로

> 스태틱 오버라이드 대응 패시브. 감전 대상에게 아군 전체의 번개 화력을 집중시킨다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 패시브명 | 과전류 회로 |
| 슬롯 | I |
| 대응 액티브 | 스태틱 오버라이드 |
| 해금 조건 | 스태틱 오버라이드 습득 |

## 2. 기본 효과

| 항목 | 값 |
|---|---:|
| 모든 아군이 감전 대상에게 주는 번개 피해 | +18% |
| 감전 5스택 대상의 번개 저항 | -12 |

스태틱 오버라이드는 [`d-static-override.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F2.Monster%2Feve%2Fskill%2Fd-static-override) 참고

## 3. 특성 3종

| 특성 | 효과 |
|---|---|
| 특성 1 | 모든 아군이 감전 대상에게 주는 번개 피해 +8% |
| 특성 2 | 감전 5스택 대상의 번개 저항 추가 -6 |
| 특성 3 | 스태틱 오버라이드 폭발 반경 +25% |
