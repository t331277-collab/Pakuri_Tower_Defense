# 몬스터 기본 규칙

> 목적: 몬스터의 액티브 / 패시브 스킬 구성과 해금 규칙을 정리한다.

신규 캐릭터 스킬을 작성할 때 원작식 효과 패턴은 [`monster-skill-patterns.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F2.Monster%2Fmonster-skill-patterns) 참고.

## 1. 기본 스킬 구성

| 구분 | 슬롯 | 개수 |
|---|---|---:|
| 액티브 스킬 | A, B, C, D, E | 5개 |
| 패시브 스킬 | F, G, H, I, J | 5개 |

## 2. 런 중 습득 제한

| 구분 | 최대 습득 |
|---|---:|
| 액티브 스킬 | 3개 |
| 패시브 스킬 | 3개 |

- 액티브 A는 기본 습득 상태이므로, 런 중 추가로 고르는 액티브는 보통 2개다.
- 패시브는 5개 후보 중 런마다 3개까지만 선택한다.

## 3. 기본 습득 규칙

| 슬롯 | 규칙 |
|---|---|
| 액티브 A | 전투 시작 시 기본으로 배워져 있다. |
| 액티브 B~E | 런 중 선택으로 습득한다. |
| 패시브 F | 런 중 선택으로 습득한다. 기본 스탯 강화 또는 기본 공격 강화 계열이다. |
| 패시브 G~J | 대응하는 액티브 스킬을 배워야 해금된다. |

- 몬스터는 액티브 A를 습득한 상태로 시작한다.
- 몬스터는 패시브를 아무것도 배우지 않은 상태로 시작한다.

## 4. 액티브 / 패시브 대응 규칙

| 액티브 | 대응 패시브 | 규칙 |
|---|---|---|
| A | F | 기본 패시브. 액티브 A 또는 기본 전투 성능을 강화한다. |
| B | G | 액티브 B 습득 후 해금된다. |
| C | H | 액티브 C 습득 후 해금된다. |
| D | I | 액티브 D 습득 후 해금된다. |
| E | J | 액티브 E 습득 후 해금된다. |

## 5. 패시브 설계 기준
- 패시브 F는 몬스터의 기본 방향성을 강화하되, 가능하면 아군 전체 강화 효과를 포함한다.
- 패시브 F는 특정 액티브 해금 조건 없이 사용할 수 있다.
- 패시브 G~J는 각각 대응 액티브를 강화하는 전용 패시브로 두되, 아군 전체 버프나 파티 시너지 효과를 우선 검토한다.
- 대응 액티브를 배우지 않은 상태에서는 해당 패시브가 선택지에 나오지 않는다.
- 패시브의 기본 효과는 보통 1개만 작성하고, 필요할 때만 2개까지 작성한다.
- 기본 효과를 3개 이상 나열하지 않는다.
- `모든 아군의 공격력 증가`, `모든 아군의 행동속도 증가`, `특정 상태 대상에게 모든 아군 피해 증가`처럼 팀 전체에 영향을 주는 효과를 적극적으로 사용한다.
- 트리거형 효과는 원칙적으로 패시브에만 둔다.
- 한 캐릭터의 패시브 세트에서 트리거형 패시브는 많아야 1개만 사용한다.

## 6. 공통 전투 규칙

### 6.1 기본 타게팅
- 자동 조준에서 특별한 명시가 없는 모든 스킬은 화면 안에 있는 가장 가까운 적을 우선 대상으로 사용한다.
- 자동 조준에서 범위 지정, 직선, 관통, 광역 스킬도 별도 타게팅 규칙이 없으면 화면 안에 있는 가장 가까운 적을 기준점으로 삼는다.
- 수동 조준에서는 플레이어가 화면 안에서 누른 지점을 공격 기준점으로 삼는다.
- 자동 조준과 수동 조준 모두 화면 안의 적 또는 화면 안의 입력 지점만 공격 기준으로 삼는다.
- 스킬에는 별도 거리 제한을 두지 않는다.
- 자동 조준에서 화면 안에 적이 없으면 스킬은 사용되지 않는다.
- 수동 조준에서 입력 지점이 없으면 스킬은 사용되지 않는다.
- 자동 조준과 수동 조준의 세부 규칙은 [`aiming-system.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F3.combat%2Faiming-system) 문서를 따른다.

### 6.2 치명타
- 모든 액티브 스킬의 피해는 치명타가 적용될 수 있다.
- 버프, 방어막, 표식처럼 직접 피해가 없는 스킬도 마스터 효과나 각성 효과로 피해가 발생하면 그 피해에는 치명타가 적용될 수 있다.

### 6.3 탄창 스킬
- 탄창 스킬은 재장전이 끝나면 현재 탄창 수만큼 연속 발사한 뒤 다시 재장전한다.
- 자동 조준에서는 발사 중에도 화면 안에 적이 있어야 하며, 화면 안에 적이 없으면 다음 발사를 보류한다.
- 수동 조준에서는 발사 중에도 화면 안의 입력 지점이 있어야 하며, 입력 지점이 없으면 다음 발사를 보류한다.

### 6.4 비탄창 스킬
- 비탄창 스킬은 쿨타임이 끝날 때마다 1회 시전한다.
- 자동 조준에서는 시전 시점에 화면 안에 적이 있어야 하며, 화면 안에 적이 없으면 시전하지 않는다.
- 수동 조준에서는 시전 시점에 화면 안의 입력 지점이 있어야 하며, 입력 지점이 없으면 시전하지 않는다.
