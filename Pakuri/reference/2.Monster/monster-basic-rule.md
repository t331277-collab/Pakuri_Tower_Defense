# 몬스터 기본 규칙

> 목적: 몬스터의 액티브 / 패시브 스킬 구성과 해금 규칙을 정리한다.

신규 캐릭터 스킬을 작성할 때 원작식 효과 패턴은 [`dungeon-squad-skill-patterns.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2Fdungeon-squad-skill-patterns) 참고.

## 1. 기본 스킬 구성

| 구분 | 슬롯 | 개수 |
|---|---|---:|
| 액티브 스킬 | A, B, C, D, E | 5개 |
| 패시브 스킬 | F, G, H, I, J | 5개 |

## 2. 런 중 습득 제한

| 구분 | 최대 습득 |
|---|---:|
| 액티브 스킬 | 3개 |
| 패시브 스킬 | 3개 |

- 액티브 A는 기본 습득 상태이므로, 런 중 추가로 고르는 액티브는 보통 2개다.
- 패시브는 5개 후보 중 런마다 3개까지만 선택한다.

## 3. 기본 습득 규칙

| 슬롯 | 규칙 |
|---|---|
| 액티브 A | 전투 시작 시 기본으로 배워져 있다. |
| 액티브 B~E | 런 중 선택으로 습득한다. |
| 패시브 F | 런 중 선택으로 습득한다. 기본 스탯 강화 또는 기본 공격 강화 계열이다. |
| 패시브 G~J | 대응하는 액티브 스킬을 배워야 해금된다. |

- 몬스터는 액티브 A를 습득한 상태로 시작한다.
- 몬스터는 패시브를 아무것도 배우지 않은 상태로 시작한다.

## 4. 액티브 / 패시브 대응 규칙

| 액티브 | 대응 패시브 | 규칙 |
|---|---|---|
| A | F | 기본 패시브. 액티브 A 또는 기본 전투 성능을 강화한다. |
| B | G | 액티브 B 습득 후 해금된다. |
| C | H | 액티브 C 습득 후 해금된다. |
| D | I | 액티브 D 습득 후 해금된다. |
| E | J | 액티브 E 습득 후 해금된다. |

## 5. 패시브 설계 기준
- 패시브 F는 몬스터의 기본 방향성을 강화하되, 가능하면 아군 전체 강화 효과를 포함한다.
- 패시브 F는 특정 액티브 해금 조건 없이 사용할 수 있다.
- 패시브 G~J는 각각 대응 액티브를 강화하는 전용 패시브로 두되, 아군 전체 버프나 파티 시너지 효과를 우선 검토한다.
- 대응 액티브를 배우지 않은 상태에서는 해당 패시브가 선택지에 나오지 않는다.
- 패시브의 기본 효과는 보통 1개만 작성하고, 필요할 때만 2개까지 작성한다.
- 기본 효과를 3개 이상 나열하지 않는다.
- `모든 아군의 공격력 증가`, `모든 아군의 행동속도 증가`, `특정 상태 대상에게 모든 아군 피해 증가`처럼 팀 전체에 영향을 주는 효과를 적극적으로 사용한다.

| 슬롯 | 스킬 |
|---|---|
| 액티브 A | 아크 볼트 |
| 패시브 F | 기본 주문력 / 번개 피해 / 탄창 계열 강화 |
| 액티브 B~E | 후속 액티브 후보 |
