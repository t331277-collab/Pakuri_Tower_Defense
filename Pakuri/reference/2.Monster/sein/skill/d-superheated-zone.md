# 세인 스킬 - 초열 지대

> 지정 범위에 지속 화염 피해를 주는 비탄창 장판 스킬.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 초열 지대 |
| 사용 주체 | 세인 타워 |
| 분류 | 액티브 D |
| 스킬 타입 | 범위 / 비탄창 / 지속시간 / 피해 주기 |
| 피해 속성 | 화염 |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 기본 화염 피해 | 12 |
| 공격력 계수 | 0.55 |
| 주문력 계수 | 0 |
| 범위 | 3.2 |
| 지속시간 | 4.0초 |
| 피해 주기 | 0.5초 |
| 쿨타임 | 9.0초 |
| 치명타 적용 | 가능 |

## 3. 피해 계산

| 항목 | 값 |
|---|---|
| 1틱 계산식 | `12 + 공격력 * 0.55` |
| 참조 저항 | 화염 저항 |
| 피해 적용 | 범위 안 적에게 피해 주기마다 적용 |

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 지속시간 +25% |
| 특성 2 | 피해 주기 속도 +25% |
| 특성 3 | 범위 +30% |
| 특성 4 | 쿨타임 -20% |
| 특성 5 | 같은 대상에게 4회 이상 피해를 주면 이후 피해 +35% |

## 5. 마스터 스킬

| 선택지 | 효과 |
