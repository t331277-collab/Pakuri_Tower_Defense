# 세인 스킬 - 열풍 화살

> 세인 타워의 기본 액티브 스킬. 고온의 상승기류를 두른 화살을 발사한다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 열풍 화살 |
| 사용 주체 | 세인 타워 |
| 분류 | 액티브 A |
| 스킬 타입 | 투사체 / 탄창형 / 기본 공격 |
| 피해 속성 | 화염 |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 기본 화염 피해 | 22 |
| 공격력 계수 | 1.1 |
| 주문력 계수 | 0 |
| 투사체 속도 | 18.0 |
| 관통 수 | 1 |
| 탄창 수 | 8 |
| 재장전 시간 | 4.4초 |
| 발사 간격 | 0.32초 |
| 치명타 적용 | 가능 |

## 3. 피해 계산

| 항목 | 값 |
|---|---|
| 계산식 | `22 + 공격력 * 1.1` |
| 참조 저항 | 화염 저항 |
| 치명타 적용 | 저항 계산 이후 |

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 위력 +25% |
| 특성 2 | 탄창 수 +4 |
| 특성 3 | 재장전 속도 +30% |
| 특성 4 | 관통 수 +1, 위력 +10% |
| 특성 5 | 발사 간격 -20%, 위력 -10% |

## 5. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 백열 화살 | 위력 +55%, 관통 수 +1 |
| 폭염 화살 | 적중 시 작은 폭발 발생, 폭발은 50% 화염 피해 |

## 6. 액티브 스킬 각성

각성 후보 2개는 각각 별도로 강화할 수 있다.

| 각성 후보 | 강화되는 항목 | 1단계 | 2단계 | 3단계 | 4단계 | 5단계 |
|---|---|---|---|---|---|---|
| 백열 화살 | 위력 / 관통 | 위력 +20% | +30% | +40%, 관통 +1 | +50%, 관통 +1 | +60%, 관통 +2 |
| 폭염 화살 | 적중 폭발 피해 / 범위 | 폭발 30% 피해 | 40% 피해 | 50% 피해, 범위 +10% | 60% 피해, 범위 +15% | 75% 피해, 범위 +25% |
