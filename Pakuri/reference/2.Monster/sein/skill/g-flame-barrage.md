# 세인 패시브 - 불꽃 탄막

> 작열 난사 대응 패시브. 아군의 화염 피해를 작열 난사 자동 발동으로 연결한다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 패시브명 | 불꽃 탄막 |
| 슬롯 | G |
| 대응 액티브 | 작열 난사 |
| 해금 조건 | 작열 난사 습득 |

## 2. 기본 효과

| 항목 | 값 |
|---|---:|
| 아군이 화염 피해를 줄 때 작열 난사 자동 발동 확률 | 4%, 재발동 대기시간 1.5초 |
| 자동 발동 작열 난사 위력 | 60% |

## 3. 특성 3종

| 특성 | 효과 |
|---|---|
| 특성 1 | 자동 발동 확률 +3% |
| 특성 2 | 자동 발동 작열 난사 위력 +20% |
| 특성 3 | 자동 발동 시 열풍 화살 재장전 시간 10% 감소 |
