# 세인 스킬 - 종말의 사선

> 디아블로의 종말 계열을 참고한 세인의 광역 결전기. 전장을 가로지르는 거대한 화염 사선을 떨어뜨린다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 종말의 사선 |
| 사용 주체 | 세인 타워 |
| 분류 | 액티브 E |
| 스킬 타입 | 비탄창 / 전장 광역 / 결전기 |
| 피해 속성 | 화염 |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 기본 화염 피해 | 70 |
| 공격력 계수 | 3.2 |
| 주문력 계수 | 0 |
| 타격 범위 | 전장 직선 3줄 |
| 쿨타임 | 16.0초 |
| 화염 저항 감소 | 10 |
| 저항 감소 지속시간 | 5.0초 |
| 치명타 적용 | 가능 |

## 3. 피해 계산

| 항목 | 값 |
|---|---|
| 계산식 | `70 + 공격력 * 3.2` |
| 참조 저항 | 화염 저항 |
| 치명타 적용 | 저항 계산 이후 |

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 위력 +30% |
| 특성 2 | 쿨타임 -20% |
| 특성 3 | 화염 저항 감소 +8 |
| 특성 4 | 타격 줄 수 +1, 위력 -15% |
| 특성 5 | 초열 지대 안의 적에게 위력 +50% |

## 5. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 붉은 종말 | 위력 +80%, 쿨타임 +25% |
| 잿빛 하늘 | 종말의 사선 이후 전장에 3초 동안 초열 지대 3개 생성 |
