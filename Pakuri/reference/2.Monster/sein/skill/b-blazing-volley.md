# 세인 스킬 - 작열 난사

> 짧은 시간에 화염 화살을 몰아치는 탄창형 보조 공격 스킬.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 작열 난사 |
| 사용 주체 | 세인 타워 |
| 분류 | 액티브 B |
| 스킬 타입 | 투사체 / 탄창형 / 연사 |
| 피해 속성 | 화염 |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 기본 화염 피해 | 14 |
| 공격력 계수 | 0.65 |
| 주문력 계수 | 0 |
| 투사체 속도 | 20.0 |
| 탄환 수 | 5 |
| 탄창 수 | 4 |
| 재장전 시간 | 6.0초 |
| 발사 간격 | 0.18초 |
| 치명타 적용 | 가능 |

## 3. 피해 계산

| 항목 | 값 |
|---|---|
| 탄환 계산식 | `14 + 공격력 * 0.65` |
| 참조 저항 | 화염 저항 |
| 치명타 적용 | 저항 계산 이후 |

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 탄환 수 +2 |
| 특성 2 | 위력 +25% |
| 특성 3 | 재장전 속도 +30% |
| 특성 4 | 발사 간격 -25% |
| 특성 5 | 같은 대상에게 연속 적중 시 피해 +8%, 최대 +40% |

## 5. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 포화 사격 | 탄환 수 +4, 위력 -20% |
| 집중 사격 | 탄환 수 -2, 위력 +90%, 치명타 확률 +20% |

## 6. 액티브 스킬 각성

각성 후보 2개는 각각 별도로 강화할 수 있다.

| 각성 후보 | 강화되는 항목 | 1단계 | 2단계 | 3단계 | 4단계 | 5단계 |
|---|---|---|---|---|---|---|
| 포화 사격 | 탄환 수 / 피해 보정 | 탄환 +2, 위력 -10% | 탄환 +3, 위력 -10% | 탄환 +4, 위력 -15% | 탄환 +5, 위력 -15% | 탄환 +6, 위력 -20% |
| 집중 사격 | 위력 / 치명타 확률 | 탄환 -1, 위력 +35% | 위력 +50% | 탄환 -2, 위력 +65% | 위력 +80%, 치명타 확률 +10% | 위력 +100%, 치명타 확률 +20% |
