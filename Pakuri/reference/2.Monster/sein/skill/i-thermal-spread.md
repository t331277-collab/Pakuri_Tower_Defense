# 세인 패시브 - 열압 확산

> 초열 지대 대응 패시브. 초열 지대 안의 적을 아군 전체 화염 피해의 집중 대상으로 만든다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 패시브명 | 열압 확산 |
| 슬롯 | I |
| 대응 액티브 | 초열 지대 |
| 해금 조건 | 초열 지대 습득 |

## 2. 기본 효과

| 항목 | 값 |
|---|---:|
| 초열 지대에 피해를 받은 적에게 모든 아군 화염 피해 | +15%, 4초 |
| 초열 지대 피해 주기 속도 | +20% |

## 3. 특성 3종

| 특성 | 효과 |
|---|---|
| 특성 1 | 모든 아군 화염 피해 증가량 +7% |
| 특성 2 | 효과 지속시간 +2초 |
| 특성 3 | 초열 지대 범위 +25% |
