# 베가 패시브 - 각인 심화

> 삼검난무 대응 패시브. 이름표식 대상을 아군 전체의 집중 공격 대상으로 만든다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 패시브명 | 각인 심화 |
| 슬롯 | F |
| 대응 액티브 | 삼검난무 |
| 해금 조건 | 없음 |
| 상태 연계 | 이름표식: [`buff-debuff.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F3.combat%2Fbuff-debuff) |

## 2. 기본 효과

| 항목 | 값 |
|---|---:|
| 모든 아군이 이름표식 대상에게 주는 피해 | +10% |
| 이름표식 10스택 이상 대상의 물리 저항 | -8 |

## 3. 특성 3종

| 특성 | 효과 |
|---|---|
| 특성 1 | 모든 아군이 이름표식 대상에게 주는 피해 +5% |
| 특성 2 | 이름표식 10스택 이상 대상의 물리 저항 추가 -4 |
| 특성 3 | 삼검난무 마지막 탄환 이름표식 부여량 +1스택 |
