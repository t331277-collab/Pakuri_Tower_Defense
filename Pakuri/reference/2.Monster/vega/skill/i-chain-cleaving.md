# 베가 패시브 - 연쇄 참결

> 검은 명부 개방 대응 패시브. 명부 참격 이후 아군의 광역 화력을 집중시킨다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 패시브명 | 연쇄 참결 |
| 슬롯 | I |
| 대응 액티브 | 검은 명부 개방 |
| 해금 조건 | 검은 명부 개방 습득 |
| 상태 연계 | 이름표식: [`buff-debuff.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F3.combat%2Fbuff-debuff) |

## 2. 기본 효과

| 항목 | 값 |
|---|---:|
| 검은 명부 개방에 피해를 받은 적에게 모든 아군 범위 피해 | +15%, 4초 |
| 아군이 범위 피해를 줄 때 검은 명부 개방 쿨타임 충전 | +3%, 재발동 대기시간 1초 |

## 3. 특성 3종

| 특성 | 효과 |
|---|---|
| 특성 1 | 모든 아군 범위 피해 증가량 +7% |
| 특성 2 | 효과 지속시간 +2초 |
| 특성 3 | 이름표식 10스택 이상 대상은 모든 아군 범위 피해를 추가로 +10% 받음 |
