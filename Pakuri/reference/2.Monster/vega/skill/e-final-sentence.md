# 베가 스킬 - 최종선고

> 표식이 가장 많은 적 1개체에게 표식 스택에 비례한 막대한 단일 피해를 주는 비탄창 액티브 스킬.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 최종선고 |
| 사용 주체 | 베가 타워 |
| 분류 | 액티브 E |
| 스킬 타입 | 비탄창 / 단일 피해 / 표식 연계 |
| 피해 속성 | 물리 |
| 상태 연계 | 이름표식: [`buff-debuff.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F3.combat%2Fbuff-debuff) |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 대상 수 | 1 |
| 대상 기준 | 이름표식이 가장 많은 적 |
| 발동 조건 | 이름표식 보유 적 1명 이상 |
| 탄창 사용 | 없음 |
| 표식 비례 피해 | 있음 |
| 기본 물리 피해 | 55 |
| 공격력 계수 | 2.0 |
| 표식 1스택당 추가 피해 | `6 + 공격력 * 0.18` |
| 사거리 | 9.5 |
| 쿨타임 | 15.0초 |
| 적중 후 표식 처리 | 대상의 이름표식 50% 소모 |
| 소모 스택 반올림 | 소수점 이하 버림 |
| 치명타 적용 | 가능 |

## 3. 피해 계산

| 항목 | 값 |
|---|---|
| 기본 계산식 | `55 + 공격력 * 2.0` |
| 표식 추가 피해 | `이름표식 스택 수 * (6 + 공격력 * 0.18)` |
| 최종 계산식 | `기본 계산식 + 표식 추가 피해` |
| 참조 방어 | 방어력 |
| 치명타 적용 | 방어력 계산 이후 |

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 기본 위력 +25% |
| 특성 2 | 표식 1스택당 추가 피해 +25% |
| 특성 3 | 쿨타임 -20% |
| 특성 4 | 이름표식 20스택 이상인 대상에게 치명타 확률 +35% |
| 특성 5 | 최종선고로 적을 처치하면 소모한 이름표식의 25%를 주변 적에게 분배 |

## 5. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 이름 없는 죽음 | 표식 소모량 100%, 표식 1스택당 추가 피해 +80% |
| 연속 선고 | 기본 위력 -20%, 처치 시 최종선고 쿨타임 70% 반환 |
