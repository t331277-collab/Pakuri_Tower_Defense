# 베가 패시브 - 사형 집행인

> 최종선고 대응 패시브. 처형 성공을 아군 전체의 다음 공격 기회로 바꾼다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 패시브명 | 사형 집행인 |
| 슬롯 | J |
| 대응 액티브 | 최종선고 |
| 해금 조건 | 최종선고 습득 |
| 상태 연계 | 이름표식: [`buff-debuff.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F3.combat%2Fbuff-debuff) |

## 2. 기본 효과

| 항목 | 값 |
|---|---:|
| 최종선고로 처치 시 모든 아군 쿨타임 충전 | +20% |
| 최종선고 대상이 생존하면 해당 대상에게 모든 아군 피해 | +10%, 5초 |

## 3. 특성 3종

| 특성 | 효과 |
|---|---|
| 특성 1 | 최종선고 처치 시 모든 아군 쿨타임 충전 +10% |
| 특성 2 | 최종선고 대상이 생존할 때 모든 아군 피해 증가량 +5% |
| 특성 3 | 최종선고로 적을 처치하면 검은 명부 개방 쿨타임 20% 감소 |
