# 베가 패시브 - 처형 준비

> 몰살 허가 대응 패시브. 베가의 처형 준비 상태를 아군 전체의 공세 타이밍으로 확장한다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 패시브명 | 처형 준비 |
| 슬롯 | H |
| 대응 액티브 | 몰살 허가 |
| 해금 조건 | 몰살 허가 습득 |
| 버프 참조 | 몰살 허가: [`buff-debuff.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F3.combat%2Fbuff-debuff) |

## 2. 기본 효과

| 항목 | 값 |
|---|---:|
| 몰살 허가 중 모든 아군의 행동속도 | +12% |
| 몰살 허가 지속시간 | +20% |

## 3. 특성 3종

| 특성 | 효과 |
|---|---|
| 특성 1 | 몰살 허가 중 모든 아군의 행동속도 +6% |
| 특성 2 | 몰살 허가 중 모든 아군의 공격력 +8% |
| 특성 3 | 몰살 허가 중 모든 아군이 이름표식 대상에게 주는 피해 +10% |
