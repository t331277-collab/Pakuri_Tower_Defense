# 베가 스킬 - 몰살 허가

> 일정 시간 동안 베가의 행동속도와 공격력을 증가시키는 자기 강화 액티브 스킬.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 몰살 허가 |
| 사용 주체 | 베가 타워 |
| 분류 | 액티브 C |
| 스킬 타입 | 버프 / 자기 강화 |
| 피해 속성 | 없음 |
| 버프 | 몰살 허가: [`buff-debuff.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F3.combat%2Fbuff-debuff) |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 지속시간 | 6.0초 |
| 행동속도 증가량 | +25% |
| 공격력 증가량 | +20% |
| 쿨타임 | 14.0초 |
| 치명타 적용 | 강화 중 발생하는 피해에 가능 |

## 3. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 지속시간 +2초 |
| 특성 2 | 행동속도 증가량 +10% |
| 특성 3 | 공격력 증가량 +10% |
| 특성 4 | 몰살 허가 중 삼검난무 재장전 속도 +30% |
| 특성 5 | 몰살 허가 중 이름표식이 있는 적에게 베가가 주는 피해 +15% |

## 4. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 처형 영장 | 지속시간 +2초, 몰살 허가 중 삼검난무가 이름표식 1스택 추가 부여 |
| 살육 절차 | 행동속도 증가량 +25%, 공격력 증가량 +25%, 지속시간 -2초 |

## 5. 액티브 스킬 각성

각성 후보 2개는 각각 별도로 강화할 수 있다.

| 각성 후보 | 강화되는 항목 | 1단계 | 2단계 | 3단계 | 4단계 | 5단계 |
|---|---|---|---|---|---|---|
| 처형 영장 | 지속시간 / 표식 추가 부여 | 지속시간 +1초 | +1.5초 | +2초, 삼검난무 표식 +1 | +2.5초, 표식 +1 | +3초, 표식 +2 |
| 살육 절차 | 행동속도 / 공격력 | 행동속도 +10%p, 공격력 +8%p | +15%p, +12%p | +20%p, +16%p, 지속시간 -1초 | +25%p, +20%p, 지속시간 -1초 | +30%p, +25%p, 지속시간 -2초 |
