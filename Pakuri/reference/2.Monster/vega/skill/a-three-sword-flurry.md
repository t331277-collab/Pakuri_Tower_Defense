# 베가 스킬 - 삼검난무

> 베가 타워의 기본 액티브 스킬. 제자리에서 세 발의 검기를 순서대로 발사한다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 삼검난무 |
| 사용 주체 | 베가 타워 |
| 분류 | 액티브 A |
| 스킬 타입 | 투사체 / 탄창형 / 기본 공격 |
| 피해 속성 | 물리 |
| 상태 연계 | 이름표식: [`buff-debuff.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F3.combat%2Fbuff-debuff) |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 기본 물리 피해 | 9 |
| 공격력 계수 | 0.4 |
| 주문력 계수 | 0 |
| 공격 범위 | 8.5 |
| 투사체 속도 | 16.0 |
| 탄환 수 | 3 |
| 관통 | 무한 관통 |
| 1번째 탄환 피해 배율 | 100% |
| 2번째 탄환 피해 배율 | 100% |
| 3번째 탄환 피해 배율 | 200% |
| 탄창 수 | 5 |
| 재장전 시간 | 4.8초 |
| 발사 간격 | 0.55초 |
| 탄환 간격 | 0.12초 |
| 이름표식 부여량 | 피해를 받은 적마다 1스택 |
| 치명타 적용 | 가능 |

## 3. 피해 계산

| 항목 | 값 |
|---|---|
| 기본 탄환 계산식 | `9 + 공격력 * 0.4` |
| 마지막 탄환 계산식 | `(9 + 공격력 * 0.4) * 2.0` |
| 참조 방어 | 방어력 |
| 치명타 적용 | 방어력 계산 이후 |

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 위력 +20% |
| 특성 2 | 탄창 수 +2 |
| 특성 3 | 재장전 속도 +25% |
| 특성 4 | 마지막 탄환 피해 배율 +50% |
| 특성 5 | 삼검난무가 이름표식 10스택 이상인 적에게 주는 피해 +25% |

## 5. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 검은 잔상 | 삼검난무 발사 후 같은 궤도에 잔상 검기 1개가 지연 발사된다. 잔상 검기는 45% 피해, 이름표식 1스택 부여 |
| 단죄 연쇄 | 삼검난무로 적을 처치하면 가장 가까운 적 1명에게 이름표식 3스택을 이전하고 작은 참격 피해를 준다 |
