# 베가 스킬 - 침묵의 대태도

> 베가가 제자리에서 대태도 형상의 거대한 참격을 날리는 비탄창 액티브 스킬.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 침묵의 대태도 |
| 사용 주체 | 베가 타워 |
| 분류 | 액티브 B |
| 스킬 타입 | 비탄창 / 참격 |
| 피해 속성 | 물리 |
| 상태이상 | 침묵: [`buff-debuff.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F3.combat%2Fbuff-debuff) |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 기본 물리 피해 | 30 |
| 공격력 계수 | 1.4 |
| 주문력 계수 | 0 |
| 참격 폭 | 1.8 |
| 침묵 지속시간 | 3.0초 |
| 탄창 사용 | 없음 |
| 쿨타임 | 8.0초 |
| 치명타 적용 | 가능 |

## 3. 피해 계산

| 항목 | 값 |
|---|---|
| 계산식 | `30 + 공격력 * 1.4` |
| 참조 방어 | 방어력 |
| 치명타 적용 | 방어력 계산 이후 |

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 위력 +25% |
| 특성 2 | 침묵 지속시간 +1초 |
| 특성 3 | 쿨타임 -20% |
| 특성 4 | 참격 폭 +30% |
| 특성 5 | 침묵의 대태도에 맞은 적에게 이름표식 2스택 부여 |

## 5. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 두 번째 봉인 | 침묵의 대태도 사용 후 0.4초 뒤 같은 경로에 2차 참격 발생. 2차 참격은 45% 피해, 침묵 1초 |
| 단두대 참격 | 위력 +70%, 참격 폭 -25%, 이름표식 10스택 이상인 적에게 침묵 지속시간 +1초 |

## 6. 액티브 스킬 각성

각성 후보 2개는 각각 별도로 강화할 수 있다.

| 각성 후보 | 강화되는 항목 | 1단계 | 2단계 | 3단계 | 4단계 | 5단계 |
|---|---|---|---|---|---|---|
| 두 번째 봉인 | 2차 참격 피해 / 침묵 | 2차 참격 30%, 침묵 0.5초 | 40%, 0.7초 | 50%, 1.0초 | 60%, 1.2초 | 75%, 1.5초 |
| 단두대 참격 | 위력 / 표식 대상 보너스 | 위력 +25% | +40% | +55%, 표식 10스택 이상 침묵 +0.5초 | +70%, 침묵 +0.8초 | +90%, 침묵 +1.2초 |
