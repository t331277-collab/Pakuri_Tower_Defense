# 베가 스킬 - 검은 명부 개방

> 표식이 있는 모든 적에게 원거리 범위 참격을 발생시키는 비탄창 액티브 스킬.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 검은 명부 개방 |
| 사용 주체 | 베가 타워 |
| 분류 | 액티브 D |
| 스킬 타입 | 비탄창 / 범위 참격 / 표식 연계 |
| 피해 속성 | 물리 |
| 상태 연계 | 이름표식: [`buff-debuff.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F3.combat%2Fbuff-debuff) |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 발동 대상 | 이름표식이 있는 모든 적 |
| 탄창 사용 | 없음 |
| 범위 피해 중첩 | 가능 |
| 기본 물리 피해 | 18 |
| 공격력 계수 | 0.85 |
| 주문력 계수 | 0 |
| 참격 반경 | 1.25 |
| 쿨타임 | 11.0초 |
| 치명타 적용 | 가능 |
| 표식 스택 피해 보정 | 없음 |

## 3. 피해 계산

| 항목 | 값 |
|---|---|
| 계산식 | `18 + 공격력 * 0.85` |
| 참조 방어 | 방어력 |
| 치명타 적용 | 방어력 계산 이후 |

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 위력 +25% |
| 특성 2 | 참격 반경 +25% |
| 특성 3 | 쿨타임 -20% |
| 특성 4 | 이름표식 10스택 이상인 적 위치의 참격 위력 +30% |
| 특성 5 | 검은 명부 개방에 피해를 받은 적에게 이름표식 1스택 부여 |

## 5. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 명부 난도질 | 각 표식 대상 위치에 범위 참격 2회 발생, 각 참격 위력 -35% |
| 흑색 처형장 | 참격 반경 +50%, 위력 +30%, 쿨타임 +20% |

## 6. 액티브 스킬 각성

각성 후보 2개는 각각 별도로 강화할 수 있다.

| 각성 후보 | 강화되는 항목 | 1단계 | 2단계 | 3단계 | 4단계 | 5단계 |
|---|---|---|---|---|---|---|
| 명부 난도질 | 참격 횟수 / 피해 보정 | 참격 2회, 각 45% 피해 | 2회, 55% | 2회, 65% | 3회, 각 50% | 3회, 각 65% |
| 흑색 처형장 | 참격 반경 / 위력 | 반경 +20%, 위력 +10% | 반경 +30%, 위력 +15% | 반경 +40%, 위력 +20% | 반경 +50%, 위력 +25% | 반경 +65%, 위력 +35% |
