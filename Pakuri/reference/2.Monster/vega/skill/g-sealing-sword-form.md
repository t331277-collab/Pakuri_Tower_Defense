# 베가 패시브 - 봉인검식

> 침묵의 대태도 대응 패시브. 침묵 상태의 적을 아군 전체가 공략하기 쉽게 만든다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 패시브명 | 봉인검식 |
| 슬롯 | G |
| 대응 액티브 | 침묵의 대태도 |
| 해금 조건 | 침묵의 대태도 습득 |
| 상태 참조 | 침묵 / 이름표식: [`buff-debuff.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F3.combat%2Fbuff-debuff) |

## 2. 기본 효과

| 항목 | 값 |
|---|---:|
| 모든 아군이 침묵 대상에게 주는 피해 | +14% |
| 침묵의 대태도 이름표식 부여 | 2스택 |

## 3. 특성 3종

| 특성 | 효과 |
|---|---|
| 특성 1 | 모든 아군이 침묵 대상에게 주는 피해 +6% |
| 특성 2 | 침묵 지속시간 +1초 |
| 특성 3 | 침묵 대상이 이름표식을 보유하면 모든 아군 치명타 확률 +10% |
