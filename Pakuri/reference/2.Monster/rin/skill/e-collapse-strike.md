# 린 스킬 - 붕괴 타격

> 지정 범위에 거대한 주먹 충격을 떨어뜨려 강한 물리 피해를 1회 입히는 비탄창 스킬.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 붕괴 타격 |
| 사용 주체 | 린 타워 |
| 분류 | 액티브 |
| 스킬 타입 | 범위 지정 / 비탄창 / 1회 피해 |
| 피해 속성 | 물리 |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 기본 물리 피해 | 40 |
| 공격력 계수 | 2.0 |
| 주문력 계수 | 0 |
| 지정 사거리 | 8.0 |
| 피해 범위 | 2.4 |
| 쿨다운 | 8.0초 |
| 피해 횟수 | 1회 |
| 치명타 적용 | 가능 |

## 3. 피해 계산

| 항목 | 값 |
|---|---:|
| 계산식 | `40 + 공격력 * 2.0` |
| 참조 방어 | 방어력 |
| 피해 적용 | 지정 범위 안의 모든 적에게 1회 적용 |

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 위력 +30% |
| 특성 2 | 피해 범위 +25% |
| 특성 3 | 쿨다운 -20% |
| 특성 4 | 중심부 대상 위력 +50% |
| 특성 5 | 적중한 적 3명 이상이면 하울링 쿨다운 20% 반환 |

## 5. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 압살 지점 | 피해 범위 -20%, 위력 +100%, 중심부 적중 시 100% 화염 추가 피해 |
| 균열 확산 | 피해 범위 +50%, 위력 +35%, 적중한 적 이동 속도 2초간 -25%, 45% 어둠 추가 피해 |
