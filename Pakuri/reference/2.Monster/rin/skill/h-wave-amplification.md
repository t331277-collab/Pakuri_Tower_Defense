# 린 패시브 - 파문 증폭

> 린의 충격파를 아군 물리 공세와 연결해, 전열 제어와 연쇄 압박을 동시에 만든다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 패시브명 | 파문 증폭 |
| 슬롯 | H |
| 대응 액티브 | C. 충격파 |
| 해금 조건 | 충격파 습득 |

## 2. 기본 효과

| 항목 | 값 |
|---|---:|
| 아군이 물리 피해를 10회 줄 때 충격파 자동 발동 | 1회, 내부 대기시간 3.0초 |
| 자동 발동 충격파 위력 | 75% |

## 3. 특성 3종

| 특성 | 효과 |
|---|---|
| 특성 1 | 자동 발동에 필요한 물리 피해 누적 횟수 -2 |
| 특성 2 | 자동 발동 충격파 위력 +20% |
| 특성 3 | 충격파 자동 발동 시 30% 번개 추가 피해 적용 |
