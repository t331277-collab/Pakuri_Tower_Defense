# 린 패시브 - 마무리 본능

> 약해진 적을 향한 린의 살의가 아군 전체의 집중 화력을 끌어내는 처형 연계 패시브.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 패시브명 | 마무리 본능 |
| 슬롯 | I |
| 대응 액티브 | D. 종결 일격 |
| 해금 조건 | 종결 일격 습득 |

## 2. 기본 효과

| 항목 | 값 |
|---|---:|
| 현재 체력 35% 이하 적이 받는 모든 아군 피해 | +16% |
| 종결 일격으로 적 처치 시 모든 아군의 행동속도 | +10%, 4.0초 |

## 3. 특성 3종

| 특성 | 효과 |
|---|---|
| 특성 1 | 낮은 체력 대상 피해 증가 +8% |
| 특성 2 | 종결 일격 처치 시 모든 아군의 치명타 피해 +25%, 4.0초 |
| 특성 3 | 종결 일격이 처형 기준 대상을 적중하면 붕괴 타격 쿨다운 12% 충전 |
