# 린 패시브 - 양손잡이

> 린의 모든 공격에 반 박자 늦은 추가 일격을 덧붙여, 묵직한 연타형 브루저 리듬을 완성하는 패시브.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 패시브명 | 양손잡이 |
| 슬롯 | F |
| 대응 액티브 | A. 파쇄권 |
| 해금 조건 | 없음 |

## 2. 기본 효과

| 항목 | 값 |
|---|---:|
| 모든 아군의 물리 피해 | +12% |
| 린의 스킬 적중 시 추가타 | 최종 피해의 35% 물리 피해 1회 |
| 추가타 적용 대상 | 파쇄권, 하울링을 제외한 직접 피해 액티브 전부 |

## 3. 특성 3종

| 특성 | 효과 |
|---|---|
| 특성 1 | 모든 아군의 물리 피해 +6% |
| 특성 2 | 추가타 피해 +15% |
| 특성 3 | 추가타에 30% 번개 추가 피해 적용 |
