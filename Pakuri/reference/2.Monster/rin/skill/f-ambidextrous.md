# 린 패시브 - 양손잡이

> 린의 연속 타격 리듬을 아군 전체의 물리 공세로 확장하는 패시브.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 패시브명 | 양손잡이 |
| 슬롯 | F |
| 대응 액티브 | 린의 모든 스킬 |
| 해금 조건 | 없음 |

## 2. 기본 효과

| 항목 | 값 |
|---|---:|
| 모든 아군의 물리 피해 | +12% |
| 아군이 물리 피해를 줄 때 파쇄권 자동 발동 확률 | 4%, 재발동 대기시간 1.5초 |

## 3. 특성 3종

| 특성 | 효과 |
|---|---|
| 특성 1 | 모든 아군의 물리 피해 +6% |

| 특성 3 | 파쇄권 자동 발동 시 충격파 쿨타임 10% 충전 |
