# 린 패시브 - 전장의 공명

> 린의 함성이 전장 전체의 전투 리듬을 맞추며, 하울링을 아군 공세의 핵심 버프로 확장한다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 패시브명 | 전장의 공명 |
| 슬롯 | G |
| 대응 액티브 | B. 하울링 |
| 해금 조건 | 하울링 습득 |

## 2. 기본 효과

| 항목 | 값 |
|---|---:|
| 하울링 중 모든 아군의 공격력 | +14% |
| 하울링 중 모든 아군의 행동속도 | +8% |
