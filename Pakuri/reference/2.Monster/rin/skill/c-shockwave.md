# 린 스킬 - 충격파

> 파쇄권보다 묵직한 직선 충격파를 발사해 적을 살짝 뒤로 밀어낸다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 충격파 |
| 사용 주체 | 린 타워 |
| 분류 | 액티브 |
| 스킬 타입 | 직선 / 비탄창 / 넉백 |
| 피해 속성 | 물리 |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 기본 물리 피해 | 28 |
| 공격력 계수 | 1.35 |
| 주문력 계수 | 0 |
| 사거리 | 8.5 |
| 충격파 폭 | 1.6 |
| 쿨다운 | 5.5초 |
| 넉백 거리 | 0.6 |
| 치명타 적용 | 가능 |

## 3. 피해 계산

| 항목 | 값 |
|---|---:|
| 계산식 | `28 + 공격력 * 1.35` |
| 참조 방어 | 방어력 |
| 피해 적용 | 충격파에 닿은 적마다 1회 적용 |

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 위력 +25% |
| 특성 2 | 충격파 폭 +25% |
| 특성 3 | 넉백 거리 +40% |
| 특성 4 | 쿨다운 -20% |
| 특성 5 | 적중한 적 1명당 파쇄권 재장전 시간 0.25초 감소 |

## 5. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 압축 충격파 | 폭 -25%, 위력 +80%, 넉백 거리 +50%, 60% 번개 추가 피해 |
| 광역 진탕 | 폭 +60%, 위력 +25%, 적중한 적에게 1.5초간 이동 속도 -20% |

## Runtime implementation note

- Rin non-magazine skills use the whole battlefield map as their target/search range.
- Shockwave keeps its beam width and effects, but runtime target acquisition and beam length use the battlefield-wide range.
