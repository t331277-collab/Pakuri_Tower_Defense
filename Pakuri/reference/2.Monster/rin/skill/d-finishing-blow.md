# 린 스킬 - 종결 일격

> 체력이 낮아진 적을 거대한 충격권으로 마무리하는 처형형 물리 스킬.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 종결 일격 |
| 사용 주체 | 린 타워 |
| 분류 | 액티브 |
| 스킬 타입 | 단일 / 비탄창 / 처형 |
| 피해 속성 | 물리 |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 기본 물리 피해 | 45 |
| 공격력 계수 | 2.4 |
| 주문력 계수 | 0 |
| 사거리 | 7.5 |
| 쿨다운 | 9.0초 |
| 처형 기준 체력 | 30% 이하 |
| 처형 추가 피해 | 80% |
| 처치 시 쿨다운 반환 | 35% |
| 치명타 적용 | 가능 |

## 3. 피해 계산

| 항목 | 값 |
|---|---:|
| 기본 계산식 | `45 + 공격력 * 2.4` |
| 처형 대상 계산식 | `기본 계산식 * 1.8` |
| 참조 방어 | 방어력 |
| 치명타 적용 순서 | 방어력 계산 이후 |

## 4. 발동 규칙
- 사거리 안에서 현재 체력 비율이 가장 낮은 적을 우선 대상으로 삼는다.
- 대상의 현재 체력이 처형 기준 이하라면 처형 추가 피해를 적용한다.
- 종결 일격으로 대상을 처치하면 이 스킬의 남은 쿨다운 일부를 반환한다.
- 처형 기준을 만족하지 않아도 기본 물리 피해는 적용된다.

## 5. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 위력 +30% |
| 특성 2 | 처형 기준 체력 +10% |
| 특성 3 | 처치 시 쿨다운 반환 +20% |
| 특성 4 | 치명타 피해 +40% |
| 특성 5 | 보스 대상 위력 +25% |

## 6. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 확정 종결 | 처형 대상에게 치명타 확률 +50%, 처치 시 쿨다운 완전 초기화 |
| 파멸권 | 위력 +90%, 처형 기준 체력 -10%, 쿨다운 +25% |
