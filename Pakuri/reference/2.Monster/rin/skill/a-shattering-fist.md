# 린 스킬 - 파쇄권

> 린 타워의 기본 액티브 스킬. 거대 기계 건틀릿에서 주먹 모양의 충격파를 탄환처럼 발사한다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 파쇄권 |
| 사용 주체 | 린 타워 |
| 분류 | 액티브 |
| 스킬 타입 | 투사체 / 탄창형 / 기본 공격 |
| 피해 속성 | 물리 |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 기본 물리 피해 | 17 |
| 공격력 계수 | 1.0 |
| 주문력 계수 | 0 |
| 투사체 속도 | 13.0 |
| 관통 수 | 0 |
| 추가 투사체 수 | 0 |
| 탄창 수 | 10 |
| 재장전 시간 | 4.0초 |
| 발사 간격 | 0.34초 |
| 치명타 적용 | 가능 |

## 3. 피해 계산

| 항목 | 값 |
|---|---:|
| 계산식 | `17 + 공격력 * 1.0` |
| 참조 방어 | 방어력 |
| 치명타 적용 순서 | 방어력 계산 이후 |

물리 피해와 방어력 계산은 [`combat-attribute-and-damage-system.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F3.combat%2Fcombat-attribute-and-damage-system) 참고  
전투 스탯 정의는 [`combat-stat-system.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F3.combat%2Fcombat-stat-system) 참고

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 위력 +25% |
| 특성 2 | 탄창 수 +4 |
| 특성 3 | 재장전 속도 +25% |
| 특성 4 | 관통 수 +1, 위력 -10% |
| 특성 5 | 치명타 확률 +10%, 치명타 피해 +25% |

## 5. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 철권 연사 | 탄창 수 +6, 발사 간격 -18%, 위력 +12% |
| 뇌격 건틀릿 | 적중 시 40% 번개 추가 피해, 3번째 적중마다 대상 주변 2명에게 번개 연쇄 |

## 6. 액티브 스킬 각성

각성 후보 2개는 각각 별도로 강화할 수 있다.

| 각성 후보 | 강화되는 항목 | 1단계 | 2단계 | 3단계 | 4단계 | 5단계 |
|---|---|---|---|---|---|---|
| 철권 연사 | 탄창 / 발사 간격 | 탄창 +2 | 탄창 +3, 발사 간격 -5% | 탄창 +4, -8% | 탄창 +5, -12% | 탄창 +6, -18% |
| 뇌격 건틀릿 | 번개 추가 피해 / 연쇄 대상 | 25% 번개 추가 피해 | 35% 추가 피해 | 40% 추가 피해, 3번째 적중마다 1명 연쇄 | 50% 추가 피해, 2명 연쇄 | 60% 추가 피해, 3명 연쇄 |
