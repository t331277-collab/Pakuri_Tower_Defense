# 린 스킬 - 하울링

> 린이 전장 전체에 전투 함성을 내질러 아군 전체의 공격 속도를 끌어올린다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 하울링 |
| 사용 주체 | 린 타워 |
| 분류 | 액티브 |
| 스킬 타입 | 버프 / 비탄창 / 아군 전체 |
| 피해 속성 | 없음 |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 공격 속도 증가 | 20% |
| 지속시간 | 5.0초 |
| 쿨다운 | 12.0초 |
| 적용 대상 | 모든 아군 타워 |

## 3. 발동 규칙
- 발동 즉시 모든 아군 타워에게 하울링 버프를 부여한다.
- 하울링 버프를 받은 아군은 지속시간 동안 공격 속도가 증가한다.
- 공격 속도 증가는 탄창형 스킬의 발사 간격 감소로 해석한다.
- 재장전 시간, 쿨다운, 지속 피해 주기에 적용할지는 스킬별로 별도 지정한다.
- 하울링은 물리 피해를 주지 않는다.

## 4. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 지속시간 +25% |
| 특성 2 | 공격 속도 증가 +10% |
| 특성 3 | 쿨다운 -20% |
| 특성 4 | 린의 공격력 +15% 추가 증가 |
| 특성 5 | 하울링 중 아군 치명타 확률 +8% |

## 5. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 전장의 포효 | 공격 속도 증가 +15%, 지속시간 +20% |
| 전열 고양 | 공격 속도 증가량 -5%, 아군 전체 공격력 +18% 추가 |
