# 린 스킬 - 하울링

> 린이 전장 전체에 전투 함성을 내질러 아군 전체의 행동속도를 끌어올린다.

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 스킬명 | 하울링 |
| 사용 주체 | 린 타워 |
| 분류 | 액티브 |
| 스킬 타입 | 버프 / 비탄창 / 아군 전체 |
| 피해 속성 | 없음 |

## 2. 기본 수치

| 항목 | 값 |
|---|---:|
| 행동속도 증가 | 20% |
| 지속시간 | 5.0초 |
| 쿨다운 | 12.0초 |
| 적용 대상 | 모든 아군 타워 |
| 치명타 적용 | 발생하는 추가 피해에 가능 |

## 3. 특성 5종

| 특성 | 효과 |
|---|---|
| 특성 1 | 지속시간 +25% |
| 특성 2 | 행동속도 증가 +10% |
| 특성 3 | 쿨다운 -20% |
| 특성 4 | 린의 공격력 +15% 추가 증가 |
| 특성 5 | 하울링 중 아군 치명타 확률 +8% |

## 4. 마스터 스킬

| 선택지 | 효과 |
|---|---|
| 전장의 포효 | 행동속도 증가 +15%, 지속시간 +20%, 아군 전체 물리 피해 +18% 추가 |
| 심연 군가 | 행동속도 증가량 -5%, 아군 전체 물리 피해에 25% 어둠 추가 피해 |

## 5. 액티브 스킬 각성

각성 후보 2개는 각각 별도로 강화할 수 있다.

| 각성 후보 | 강화되는 항목 | 1단계 | 2단계 | 3단계 | 4단계 | 5단계 |
|---|---|---|---|---|---|---|
| 전장의 포효 | 행동속도 / 물리 피해 | 행동속도 +5%p | +8%p | +10%p, 물리 피해 +8% | +12%p, 물리 피해 +12% | +15%p, 물리 피해 +18% |
| 심연 군가 | 어둠 추가 피해 / 지속시간 | 물리 피해에 10% 어둠 추가 | 15% 어둠 추가 | 20% 어둠 추가, 지속시간 +1초 | 25% 어둠 추가, +1초 | 30% 어둠 추가, +2초 |
