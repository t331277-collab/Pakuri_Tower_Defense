# 스킬 선택지 풀 규칙

> 목적: 런 중 캐릭터 강화 선택지가 어떻게 구성되는지 정리한다.

## 1. 전투 보상 선택 규칙
전투 후 포로를 `공양`에 사용하면 캐릭터 강화 선택지가 열린다.
포로 사용 방식 전체는 [`prisoner-choice-system.md`](obsidian://open?vault=towerdefense_pakuri_docs&file=docs%2Freference%2F4.run%2Fprisoner-choice-system) 참고.

| 항목 | 규칙 |
|---|---|
| 선택지 개수 | 무작위 3개 |
| 선택 개수 | 1개 |
| 중복 등장 | 이미 선택한 항목은 다시 등장하지 않음 |
| 후보 부족 | 남은 후보 수만큼만 표시 |

## 2. 선택지 풀 구성

강화 선택지가 열릴 때, 아래 후보를 모두 하나의 선택지 풀에 넣는다.

| 후보 | 포함 조건 |
|---|---|
| 신규 액티브 스킬 | 아직 배우지 않았고, 액티브 최대 습득 수를 넘지 않을 때 |
| 신규 패시브 스킬 | 아직 배우지 않았고, 패시브 최대 습득 수를 넘지 않을 때 |
| 액티브 스킬 특성 | 해당 액티브를 배웠고, 아직 선택 가능한 특성이 남아 있을 때 |
| 마스터 스킬 | 해당 액티브의 마스터 해금 조건을 만족했고, 아직 마스터를 고르지 않았을 때 |

## 3. 선택지 생성 순서

1. 현재 캐릭터가 배울 수 있는 신규 액티브를 확인한다.
2. 현재 캐릭터가 배울 수 있는 신규 패시브를 확인한다.
3. 이미 배운 액티브에서 추가 가능한 특성을 확인한다.
4. 해금 조건을 만족한 마스터 스킬을 확인한다.
5. 모든 후보를 하나의 풀에 섞는다.
6. 무작위 3개를 제시한다.

## 4. 제외 규칙
- 후보가 3개보다 적으면 남은 후보만 제시한다.
- 선택한 후보는 이후 선택지 풀에서 제거한다.
- 해금 조건을 만족하지 않은 패시브는 선택지 풀에 들어가지 않는다.
- 배우지 않은 액티브의 특성은 선택지 풀에 들어가지 않는다.
- 마스터 조건을 만족하지 않은 마스터 스킬은 선택지 풀에 들어가지 않는다.

## 5. 스킬 강화 규칙

| 구분 | 강화 후보 | 런 중 선택 |
|---|---:|---:|
| 액티브 스킬 1개 | 5개 | 3개 |
| 패시브 스킬 1개 | 5개 | 1개 |

- 런 중 액티브 스킬 특성은 5개 후보 중 3개를 골라 완성한다.
- 패시브 강화는 5개 후보 중 1개만 고른다.
- 선택한 강화는 다시 등장하지 않는다.

## 6. 마스터 스킬 선택 규칙

| 항목 | 규칙 |
|---|---|
| 해금 조건 | 액티브 스킬 특성 3개 선택 |
| 선택지 | 2개 |
| 선택 개수 | 1개 |
| 등장 조건 | 해당 액티브 기준으로만 판단 |

- 한 액티브의 특성 3개를 모두 고르면 해당 액티브의 마스터 스킬 후보가 열린다.
- 다른 액티브의 진행 상태와 무관하게 해금된다.
- 마스터 스킬은 반복 강화가 아니라 최종 분기 선택으로 둔다.
