# GAMEDESIGNER_IMPLEMENTATION.md

## Purpose

Use this file for Implementation Design.

Implementation Design describes what must be built, what files or Unity objects are relevant, what constraints apply, and what verification Code Builder must provide.

## Checks

- Verify target files or Unity objects exist, or clearly state that they do not exist.
- Identify the approved behavior and the current behavior from inspected evidence.
- Identify expected public APIs, data flow, UI flow, or scene-object flow.
- Identify configuration and tuning values that should live in data files instead of code.
- Identify edge cases, failure states, and degenerate strategies.
- Define local non-gameplay verification expected from Code Builder.

## Output

Implementation handoff must include:

- goal;
- inspected evidence;
- relevant files or Unity objects;
- constraints;
- expected implementation surface;
- tuning and data ownership notes;
- edge cases;
- acceptance criteria;
- verification expected from Code Builder;
- related board files that must be updated.
