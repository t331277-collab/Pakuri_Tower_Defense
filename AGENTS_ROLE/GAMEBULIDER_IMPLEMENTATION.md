# GAMEBULIDER_IMPLEMENTATION.md

## Purpose

Use this file for direct implementation.

Implementation means writing or editing approved files, connecting systems, and producing evidence that local non-gameplay checks passed.

## Before Writing Code

Verify:

- target files, scene objects, assets, or data files exist, or state that they do not exist;
- the current behavior from inspected code or Unity-MCP output;
- the relevant board files selected by `MDTREE.md`;
- whether the task is approved implementation or a Designer handoff;
- expected public APIs, data flow, and ownership boundaries;
- configuration or tuning values that should live in data files instead of code.

## After Implementation

Record:

- changed files;
- verification commands and results;
- Unity-MCP editor, compile, console, or scene evidence where relevant;
- board updates required by hierarchy rules;
- interface or data-flow changes;
- any deviation from the Designer handoff or existing architecture;
- performance, memory, load-time, or UI risks noticed during implementation;
- remaining test gaps or user-only Play Mode verification needs.
